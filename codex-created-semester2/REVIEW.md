# 교육 콘텐츠 검토 · 2학기 1~4주차

2026-11-04 · Codex · 초등 5~6학년 소그룹, 주 1회 110분 기준

사용자 요청: 교육 콘텐츠 제작자 관점으로 검토하고 확인 후 커밋·푸시한다. 기존 1학기 작업과 분리한다는 앞선 요청을 유지해 수정·검토 기록은 이 폴더에만 둔다.

| 확인한 부분 | 발견한 문제 | 반영한 조치 |
|---|---|---|
| 완성 목표 | 터틀 그림이 글로만 설명돼 있었다. | 미니 코드의 이동 명령으로 정적 인라인 SVG를 생성한다. 앱 캡처로 표기하지 않고 외부 그림 파일·스크립트를 쓰지 않는다. |
| 첫 주 설명 | 채우기·점·펜·방향 지정 설명이 부족했다. | 처음 쓰는 단계에 짧은 설명을 보강했다. |
| 단계별 힌트 | 성공 문구를 반복해 오류 해결에 도움이 적었다. | 콜론·들여쓰기·좌표·회전·중첩 반복의 확인 지점을 명시했다. |
| 바꾸기 발판 | 기존 코드 수정과 추가가 모호하고 예시가 필수 조건을 모두 충족하지 못했다. | 수정 위치·방법을 안내하고 mini_change_solution.py에 필수 세 가지를 충족하는 교사용 실행 예시를 추가했다. |
| 2주차 난이도 | 날개 수 변경이 필수와 선택에 섞여 있었다. | 필수는 네 날개와 90도 회전의 이유 설명이다. 다른 날개 수는 선택이며 중첩 반복은 3주차까지 도입하지 않는다. |
| 3주차 설명 | 진분홍 점으로 덮는데 같은 색으로 덮는다고 설명했다. | 코드와 일치하게 수정했다. |
| 4주차 순서 | remove·pop을 설명 전에 예측 문제에서 요구했다. | 도구 설명 → 조건을 고정한 예측 → 실행 순서로 옮기고 정답지도 맞췄다. |
| 설문 해석 | 큰 값·다른 응답 수는 화면 밖으로 나가고 막대별 자료 대응이 약했다. | 축척·간격을 자동 계산하고 번호별 값을 콘솔 기록표로 보여 준다. 0은 시작점으로 표시한다. 빈 목록·음수는 안내 후 통계를 건너뛴다. write()는 8주차 이전에 도입하지 않는다. |
| 평균 의미 | 정수 몫의 의미가 그래프 출력에서 빠졌다. | 평균의 소수 부분을 버린 값임을 표시했다. |
| 인쇄 | 설명 추가로 예측 표·친구 의견 칸이 다음 쪽에 홀로 남았다. | 반복 안내·설계 예시를 줄이고 인쇄 간격을 조정했다. 쓰기 칸 최소 크기는 유지했다. |
| 유지보수 | build.py가 lesson_spec.py의 수정을 덮어썼다. | 설계 파일을 유일한 주차 내용 원본으로 읽고 저장소 상대 경로로 실행한다. 설계 보존·반복 생성·수정 반영 검사도 추가했다. |

검증: 단계별 누적 실행, 문법, 교안·README·실습 코드 일치, 기본·바꾸기·도전 결과, 워밍업 오류 순서와 수정 출력을 확인했다. 설문은 빈 목록·음수·전부 0·1440분·응답 6개도 검사했다. 원본 구조 검사와 모바일 375px·노트북 1024px 검사를 통과했다. 인쇄는 10·11·10·10쪽이다. 실제 터틀 창에서도 바꾸기 그림 3개와 수정한 설문 시작·정답 코드를 실행했다. 자세한 검증 범위는 VALIDATION.md에 있다.

코드·문서·레이아웃 검토에서 남은 필수 수정 사항은 없다. 학생 대상 시범 수업은 아직 하지 않았다. 첫 수업에서는 1주차 좌표·방향 설명 시간, 3주차 중첩 반복의 독립 수행 여부, 4주차 새 도구 여러 개를 배우는 부담을 관찰해야 한다. 시간 부족 시 도전·새로 만들기는 생략하고 필수 세 가지를 완성 기준으로 삼는다.

이 기록은 원본 docs의 초안 상태를 확정으로 바꾸거나 다른 학기 제작을 승인하지 않는다.
