🧰 도구 카드 · 반복할 때 바뀌는 숫자

range(3)의 숫자는 0, 1, 2가 돼요. 위치 계산에 써요.

for number in range(3):    print(number * 10)

→ 0, 10, 20이 차례로 나와요.

import turtle as tt.penup()for number in range(3):    t.goto(-150 + number * 150, 40)    t.dot(60, "pink")

그림 창을 유지하려면 맨 아래에 t.done()을 한 번 써요. 다음 단계는 그 줄 바로 위에 이어 써요. 실행을 마친 창은 닫고 다시 실행해요.

▶️ 실행하고 확인: 달라진 모습을 적거나 그려요.
  • 가로로 사탕 세 개가 나왔어요.

🧰 도구 카드 · 반복 속에서 크기 바꾸기

반복 숫자에 20씩 곱해서 차이를 만들어요.

for number in range(3):    print(40 + number * 20)

→ 40, 60, 80이 나와요.

# 단계 1 코드 아래에 이어서 써요.for number in range(3):    t.goto(-150 + number * 150, 40)    t.dot(60 + number * 20, "hotpink")    t.pendown()    t.goto(-150 + number * 150, -100)    t.penup()

t.done() 바로 위에 이어 써요. 그림 창을 닫고 다시 실행해요.

▶️ 실행하고 확인: 달라진 모습을 적거나 그려요.

🧰 도구 카드 · 반복 안에 반복

사탕 하나마다 장식을 세 번 찍어요. 안쪽은 8칸 들여써요.

for row in range(2):    for col in range(3):        print("*", end="")    print()

→ 별 3개짜리 줄이 2줄 나와요. end=""는 줄바꿈을 미뤄요.

# 단계 2 코드 아래에 이어서 써요.for number in range(3):    for spot in range(3):        t.goto(-165 + number * 150 + spot * 15, 40)        t.dot(8, "white")

t.done() 바로 위에 이어 써요. 그림 창을 닫고 다시 실행해요.

▶️ 실행하고 확인: 달라진 모습을 적거나 그려요.

number가 0, 1, 2일 때 -150 + number * 150을 계산해요. 세 x는 -150, 0, 150이에요.

단계 2●○○

크기는 60 + number * 20, 막대 끝의 y는 -100이에요. 다음 사탕으로 가기 전에 penup()을 써요.

단계 3●○○

안쪽 for와 그 안의 goto·dot 들여쓰기를 비교해요. 사탕 하나마다 spot이 다시 0부터 시작해요.

바꾸기·새로 만들기 1●○○

바꿀 위치나 값을 먼저 찾아요. 한 번에 하나만 바꿔 실행해요.

바꾸기·새로 만들기 2●●○

바깥 number는 사탕 위치, 안쪽 spot은 장식 위치에 써요.

바꾸기·새로 만들기 3●●●

단계 3 아래, t.done() 바로 위에 넣어요.

for number in range(3):    for spot in range(3):        t.goto(-165 + number * 150 + spot * 15, 55)        t.dot(8, "white")

row는 y 좌표에, col은 x 좌표에 써요. 크기는 size라는 상자에 뽑아 담아요.
