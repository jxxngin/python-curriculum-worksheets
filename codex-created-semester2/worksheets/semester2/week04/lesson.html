🧰 도구 카드 · 개수와 대표 값

빈 목록에서는 max(), min(), 평균을 구할 수 없어요.

scores = [2, 4, 6]print(len(scores), sum(scores))print(max(scores), min(scores))

→ 개수 3, 합계 12 / 가장 큰 값 6, 가장 작은 값 2예요.

# 단계 2 코드 아래에 이어서 써요.print(f"산 개수: {len(heights)}")print(f"가장 높은 산: {max(heights)}m")print(f"가장 낮은 산: {min(heights)}m")total = sum(heights)print(f"높이 합계: {total}m")print(f"평균 높이: {total // len(heights)}m (정수 몫)")
▶️ 실행하고 확인: 달라진 모습을 적거나 그려요.

🧰 도구 카드 · 값 빼기와 마지막 값 꺼내기

remove(값)는 같은 값을 하나 지워요. pop()은 마지막 값을 꺼내 돌려줘요. 둘 다 원래 목록을 바꿔요.

numbers = [10, 20, 30]numbers.remove(20)last = numbers.pop()

→ numbers는 [10], last는 30이에요.

🔍 따라가기: 위 도구 카드의 remove()와 pop()을 살펴본 뒤 예상해요. 단계 2 직후 heights=[8516, 8586, 8849]에서 remove(8586) → pop()을 차례로 실행해요.
remove 뒤 목록pop이 꺼낸 값마지막 목록

처음 세 높이에서 시작해요. remove → sort → pop은 한 번씩만 추가하고, 남은 목록으로 통계를 다시 계산해요.

★ 꼭 하기 · 세 가지가 오늘의 완성 기준이에요.
  • remove(8586)으로 산 하나를 뺀 뒤 다시 sort() 했어요.
  • pop()으로 마지막 높이를 꺼내 별도 변수에 담아 보여 줬어요.
  • 남은 목록의 개수와 최댓값·최솟값·합계·평균을 다시 보여 줬어요.
