🧰 도구 카드 · 그림 펜과 채우기

선을 닫으면 그 안을 색으로 채울 수 있어요.

import turtle as tt.color("skyblue")t.circle(30)

→ 하늘색 원을 그려요. begin_fill()과 end_fill() 사이에 닫힌 도형을 그리면 속도 채워요.

import turtle as tt.color("gold")t.begin_fill()t.circle(80)t.end_fill()t.penup()

begin_fill() 뒤에 원을 그리고 end_fill()로 채워요. penup()은 펜을 들어 이동선을 남기지 않아요.

그림 창을 유지하려면 맨 아래에 t.done()을 한 번 써요. 다음 단계는 그 줄 바로 위에 이어 써요. 실행을 마친 창은 닫고 다시 실행해요.

  • 노란 얼굴 바탕이 나왔어요.

🧰 도구 카드 · 좌표로 이동하기

가운데는 (0, 0), 오른쪽은 x가 커지고 위쪽은 y가 커져요.

t.penup()t.goto(40, 60)t.dot(10, "blue")

→ 선을 남기지 않고 오른쪽 위에 파란 점을 찍어요.

# 단계 1 코드 아래에 이어서 써요.t.goto(-30, 100)t.dot(14, "black")t.goto(30, 100)t.dot(14, "black")

dot(크기, 색)은 현재 위치에 점을 찍어요. 두 눈의 y가 같으면 나란히 놓여요.

t.done() 바로 위에 이어 써요. 그림 창을 닫고 다시 실행해요.

▶️ 실행하고 확인: 달라진 모습을 적거나 그려요.
  • 같은 높이에 검은 눈이 두 개 나왔어요.

🧰 도구 카드 · 방향과 둥근 선

0도는 오른쪽, 90도는 위쪽이에요. circle(반지름, 각도)는 원의 일부를 그려요.

t.setheading(0)t.forward(25)t.left(90)

→ 오른쪽으로 25 움직인 뒤 위를 봐요. backward()는 뒤로, right()는 오른쪽으로 돌아요.

# 단계 2 코드 아래에 이어서 써요.t.goto(-35, 65)t.setheading(-90)t.pencolor("black")t.pendown()t.circle(35, 180)t.penup()

pencolor()는 선 색, pendown()은 펜 내리기예요. setheading(-90)은 아래쪽을 보게 해요.

t.done() 바로 위에 이어 써요. 그림 창을 닫고 다시 실행해요.

▶️ 실행하고 확인: 달라진 모습을 적거나 그려요.
  • 양 끝이 올라간 웃는 입이 생겼어요.

입에 선이 없으면 pendown()을 확인해요. 아래쪽을 본 뒤 반지름 35인 반원을 그려요.

바꾸기·새로 만들기 1●○○

바꿀 위치나 값을 먼저 찾아요. 한 번에 하나만 바꿔 실행해요.

바꾸기·새로 만들기 2●●○

얼굴 색은 color(), 눈은 dot(크기, 색), 입 모양은 circle(반지름, 각도)의 숫자를 고쳐요.

바꾸기·새로 만들기 3●●●

도전 2●●○
