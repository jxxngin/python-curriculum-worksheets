## 🎯 오늘의 미션
기본 완성 모습: 노란 원 얼굴 → 같은 높이의 검은 눈 두 개 → 웃는 입

## 🔧 워밍업
| 줄 | 오류 이름 또는 메시지 | 고친 방법 |
|---|---|---|
| 7 | NameError: name 'nam' is not defined | nam → name |
| 8 | TypeError: can only concatenate str (not "int") to str | score = 10으로 바꾼다. |
| 9 | SyntaxError: unterminated string literal | 닫는 큰따옴표를 추가한다. |

9번 줄의 SyntaxError → 7번 줄의 NameError → 8번 줄의 TypeError. 고친 출력: 하린 / 15 / 이모지 준비 완료.

## ⭐ 내 것으로 바꾸기
학생별 답이 다르다. 필수 세 가지를 충족하는 실행 가능한 예시는 mini_change_solution.py에 있다. 기존 코드 수정과 새 코드 추가를 구별한다. 필수 세 가지와 실제 변화가 일치하는지 확인한다. 더 해 보기는 필수가 아니다.

## 💡 새로 만들기
그리기·계획·친구의 한마디·자랑할 점은 열린 답이다. 계획한 변화가 실행 결과에 나타나고 친구가 설명을 이해하는지 확인한다.
