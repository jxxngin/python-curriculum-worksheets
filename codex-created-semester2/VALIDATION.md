주차 내용은 lesson_spec.py에서 수정한다. build.py는 원본 tools/lesson_gen.py의 공통 HTML 부품을 읽고 이 별도 폴더의 생성 파일만 쓴다. 원본 생성기에 이 폴더의 설계 파일을 직접 넣는 방식은 사용하지 않는다.

## 내용·실행 검사: 통과

- 미니 단계별 누적 실행, 단계당 새 코드 3~6줄, 주석만 있는 시작 파일, 모든 정상 Python 파일의 문법을 확인했다.
- HTML과 README의 단계 코드가 미니 코드와 일치한다.
- 네 주차의 미니·바꾸기·도전 시작·도전 정답 파일을 실행했다. 무작위 자료는 seed 0·1·2를 사용했다.
- 눈 좌표·입의 반원, 날개 네 개와 제자리 복귀, 흰 장식 9개, 정렬·합계·평균, remove·pop 뒤 목록을 확인했다.
- 바꾸기 예시의 눈 크기·입 각도, 네 날개의 다른 색, 사탕별 장식 수, 산 목록 제거·꺼내기·요약 결과를 확인했다.
- 워밍업은 의도한 오류 순서대로 고친 뒤 출력이 정답지와 같은지 확인했다. 오류 메시지는 Python 버전에 따라 다름을 교사 가이드에 안내했다.
- 설문은 일반 값, [0], 전부 0, 1440분, 응답 6개, 빈 목록, 음수를 검사했다. 유효 자료 좌표가 그리기 범위에 있고 번호별 기록과 응답 수가 일치한다.
- 임시 복사본에서 설계 파일 해시 보존, 두 번 생성한 결과 동일, 설계 제목 변경의 HTML 반영을 확인했다.
- 원본 check_worksheet.py의 구조·공통 스타일·외부 리소스·편집기 표현 검사를 통과했다.

자동 코드 검사의 터틀은 preview.Pen 기록기를 사용한다. 최종 검토에서 바꾸기 예시 3개와 수정한 4주차 도전 시작·정답은 실제 tkinter/turtle로도 실행했다. 종료 대기만 update와 창 닫기로 바꿨다. 기존 미니와 기존 도전 그림의 실제 터틀 실행은 최초 제작 검증에서 완료했다.
