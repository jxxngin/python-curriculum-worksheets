# 2학기 1주차 교사 가이드: 기분 이모지

## 수업 목표

- 터틀 그래픽을 처음 쓴다. 거북이를 이동·회전시키고(`forward()`, `right()`, `left()`), 좌표로 옮기고(`goto()`), 펜을 들고 내리고(`penup()`, `pendown()`), 색을 칠한다(`color()`, `begin_fill()`, `end_fill()`).
- 원(`circle()`)과 점(`dot()`)으로 얼굴을 그린다.
- 코드 한 줄이 그림의 어느 부분을 만드는지 연결하는 습관을 시작한다(따라가기: 펜과 방향).

## 110분 시간 배분

교안: `lesson.html`. 시간은 기준 기본값(15/40/10/30/15분, ±5분)을 따른다.

| 시간 | 활동 | 비고 |
| --- | --- | --- |
| 0~15분 | 미션(완성 그림 보여 주며 오늘 만들 것 소개) + 워밍업 | 2학기 첫 시간: 그림 창이 따로 뜨고, 창을 닫으면 프로그램이 끝난다는 것을 먼저 보여 준다 |
| 15~55분 | 단계 1~3 (도구 카드는 필요한 순간에 짧게) | 단계마다 실행해서 그림을 칸에 따라 그린다 |
| 55~65분 | 쉬는 시간 |  |

## 핵심 설명 포인트

- 블록 코딩의 "펜 내리기·펜 올리기·이동하기·회전하기" 블록과 같다. 처음 5분은 블록 코딩 비유로 빠르게 넘어간다.
- 좌표: 그림 창 가운데가 (0, 0), 오른쪽이 x+, 위쪽이 y+. 칠판에 십자 좌표를 그리고 눈 두 개 자리 (-35, 130), (35, 130)을 찍어 보인다. 음수 좌표는 "가운데에서 왼쪽(아래)"으로 설명한다.
- `circle(100)`은 거북이 자리가 가운데가 아니라 원의 맨 아래다. 원은 거북이 왼쪽(처음에는 위쪽)에 생긴다. 그래서 얼굴 가운데가 (0, 100)이고 눈과 입의 y 좌표가 0보다 크다.
- 처음에는 펜이 내려가 있다. `goto()` 전에 `penup()`을 쓰지 않으면 가는 길에 선이 생긴다(워밍업 셋째 오류, 단계 2).
- `right()`·`left()`는 그 자리에서 도는 것이고 움직이지 않는다. 따라가기 표에서 "돌기만 하는 줄은 선이 안 생긴다"를 짚는다.
- 끝에 보이는 화살표가 거북이다. 거북이를 숨기는 `hideturtle()`은 바꾸기의 "더 해 보기"에만 둔다. 화살표 방향으로 따라가기 답을 확인할 수 있어서 단계에서는 숨기지 않는다.
- 2학기 1~8주는 `turtle.forward()`처럼 `turtle.`을 붙여 쓴다. 거북이를 여럿 만드는 `turtle.Turtle()`은 9주 명령 카드에서 배운다. 학생이 인터넷에서 `t = turtle.Turtle()` 모양을 보고 와도 이번 주는 `turtle.`을 붙이는 모양으로 쓴다.
- 색 이름은 영어로 쓴다. 터틀이 모르는 이름(예: `"yelow"`)은 `TurtleGraphicsError: bad color string`이 난다. 이 오류는 메시지 맨 아래 줄 번호가 turtle 내부를 가리키므로, "메시지 위쪽에서 내 파일 이름이 나온 줄"을 찾게 한다.
- 도전 국기 비율은 실제 규정을 따랐다(근거는 `answer_key.md`). 일본은 가로:세로 3:2, 원 지름은 세로의 3/5. 스위스는 정사각형.

## 자주 나오는 오류와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| `SyntaxError: unterminated string literal` | 색 이름 따옴표를 닫지 않음 | 같은 종류의 따옴표로 닫는다 |
| `AttributeError: module 'turtle' has no attribute 'fowrard'` | 명령 이름 철자 틀림 | 메시지의 `Did you mean`을 읽게 한다 |
| `NameError: name 'Turtle' is not defined` | `turtle`을 대문자로 씀 | 파이썬은 대소문자를 구분한다 |
| `turtle.TurtleGraphicsError: bad color string` | 터틀이 모르는 색 이름 | 철자를 보고, 도구 카드의 색 이름으로 바꾼다 |
| 원이 칠해지지 않음 | `end_fill()` 빠짐, 또는 `begin_fill()`이 `circle()` 아래 | 칠할 모양을 `begin_fill()`과 `end_fill()` 사이에 둔다 |
| 얼굴에서 눈·입까지 선이 생김 | `penup()` 빠짐 | `goto()` 위에 `penup()` |
| 입이 안 그려짐 | `pendown()` 빠짐 | 입 시작점으로 간 뒤 `pendown()` |
| 그림 창이 바로 닫힘 | 맨 아래 `turtle.done()`을 지움, 또는 그 아래에 코드를 씀 | `turtle.done()`은 늘 맨 아래에 둔다 |
| 그림 창이 안 닫히고 다음 실행이 안 됨 | 이전 그림 창이 열려 있음 | 그림 창을 닫고 다시 실행한다 |

## 워밍업 정답

1. 8번째 줄: `turtle.color("orange", "yellow)` → 닫는 따옴표 `"` 추가 (`SyntaxError`)
2. 16번째 줄: `fowrard` → `forward` (`AttributeError`)
3. 14번째 줄 위: `turtle.penup()` 추가 (메시지 없음: 해 아래에서 햇살까지 선이 하나 더 생긴다)

참고: 순서는 8번(실행 전) → 16번(해를 그린 뒤 창이 닫힘) → 14번(메시지 없이 그림만 틀림)이다. 셋째는 메시지가 없어서 "다 고치면 보여야 할 그림"(파일 맨 위 주석)과 비교하게 한다. `penup()`은 단계 2에서 배우므로 막히면 힌트 카드의 `워밍업` 카드를 보게 한다.

## 단계별 확인

- 단계 1: 검은 테두리의 노란 원 / 단계 2: 눈 두 개, 얼굴에서 눈까지 선 없음 / 단계 3: V 모양 웃는 입, 화살표가 ↗. 자세한 답은 `answer_key.md`.
- 그리기 칸은 정확히 그리지 않아도 된다. 무엇이 어디에 생겼는지(원, 눈 자리, 화살표 방향)가 보이면 된다.

## 진도 차이 대응

- 빠른 학생: 새로 만들기(모자) → 도전 국기. 국기는 스위스까지 하고 시간이 남으면 줄무늬 국기를 하나 더 고른다. 태극기·영국은 "더 해 보기"라 끝내지 못해도 된다.
- 느린 학생: 단계 3까지 실행 + ★ 1~2개(얼굴 색, 입 모양)를 최소 목표로 한다. 좌표가 어려우면 단계 2의 좌표를 그대로 쓰고 숫자를 하나씩만 바꿔 보게 한다.
- 인쇄: 양면 인쇄를 권장한다.
