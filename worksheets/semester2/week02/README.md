## 🪜 단계 1: 막대 손잡이 그리기

📌 목표: 굵은 갈색 막대가 가운데에서 아래로 나온다.

> 🧰 **뒤로 가기와 선 굵기: backward()·pensize()**: `backward(거리)`는 보는 쪽의 반대로 가요. 보는 쪽은 그대로예요. `pensize(굵기)`는 선 굵기를 정해요. 숫자가 클수록 굵어요.
>
> ```python
> turtle.pensize(8)
> turtle.forward(80)
> turtle.backward(40)
> ```
> → 80 갔다가 40 돌아와서 거북이가 선 가운데에 있어요

① 기능 추가하기: `mini_starter.py`의 `# 단계 1` 아래에 입력

```python
turtle.pensize(6)
turtle.color("brown")
turtle.right(90)
turtle.forward(200)
turtle.backward(200)
turtle.left(90)
```

② 실행하고 확인: 나온 그림을 칸에 따라 그리기

✅ 굵은 갈색 막대가 아래로 나왔어요. / 거북이가 가운데로 돌아와 → 쪽을 봐요.

## 🪜 단계 2: 날개 자리 그리기

📌 목표: 가운데에서 막대 4개가 + 모양으로 나온다.

> 🧰 **되풀이하기: for와 range()**: `for i in range(3):` 아래에 앞을 4칸 띄운 줄들을 3번 되풀이해요. 줄 끝의 `:`을 잊지 말아요. `i`에는 0, 1, 2가 차례로 들어가요.
>
> ```python
> for i in range(3):
>     turtle.forward(60)
>     turtle.left(120)
> ```
> → 앞으로 60, 왼쪽으로 120도를 3번: 세모

> 🧰 **도는 각도: 360 ÷ 횟수**: 한 바퀴는 360도예요. 같은 각도로 5번 돌아 처음 쪽을 보려면 360 ÷ 5 = 72도씩 돌아요.
>
> ```python
> for i in range(5):
>     turtle.forward(50)
>     turtle.left(72)
> ```
> → 72도씩 5번: 오각형

① 기능 추가하기: `mini_starter.py`의 `# 단계 2` 아래에 입력

```python
turtle.pensize(2)
turtle.color("black", "red")
for i in range(4):
    turtle.forward(100)
    turtle.backward(100)
    turtle.left(90)
```

② 실행하고 확인: 나온 그림을 칸에 따라 그리기

✅ 막대 4개가 + 모양으로 나왔어요. / 거북이가 가운데에서 → 쪽을 봐요.

## 🪜 단계 3: 날개 칠하기

📌 목표: 막대마다 빨간 반원 날개가 하나씩 붙는다.

> 🧰 **반원 그리기: circle(반지름, 180)**: `circle()`에 숫자를 하나 더 주면 원을 그 각도만큼만 그려요. 180이면 반원이에요. 다 그리면 거북이는 처음과 반대쪽을 봐요.
>
> ```python
> turtle.circle(40, 180)
> ```
> → 반지름 40인 반원. 거북이가 ← 쪽을 봐요

① 기능 추가하기: `mini_starter.py`의 `# 단계 3` 아래에 입력

```python
for i in range(4):
    turtle.begin_fill()
    turtle.circle(50, 180)
    turtle.left(90)
    turtle.forward(100)
    turtle.end_fill()
```

② 실행하고 확인: 나온 그림을 칸에 따라 그리기

✅ 빨간 날개 4개가 나왔어요. / 날개가 막대마다 하나씩 붙었어요.

③ 따라가기: for가 한 번 돌 때마다 날개가 붙는 막대(위 / 오른쪽 / 아래 / 왼쪽)와, 날개를 다 그린 뒤 거북이가 보는 쪽(→ ↓ ← ↑ 중 하나) 적기. 시작: 거북이는 가운데에서 → 쪽을 봐요. 끝나면 그림 속 화살표와 비교해요.

## 🚀 도전 프로젝트: 스피로그래프 만다라

**왜 만들까?** 스피로그래프는 톱니바퀴를 돌려 겹친 원 무늬를 그리는 장난감이에요. 같은 모양을 조금씩 돌려 되풀이하면 복잡한 무늬가 나와요. 미니 프로젝트보다 반복 횟수와 각도를 더 많이 계산해요.

📌 목표: 원 개수와 도는 각도를 바꿔 무늬를 꽉 채우고, 크기가 다른 무늬를 하나 더 겹친 만다라를 만든다.

> 🧰 **빠르게 그리기: speed()**: 원을 많이 그리면 오래 걸려요. 시작 파일 맨 위의 `turtle.speed(0)`은 가장 빠르게 그리라는 뜻이에요.

① 실행해 보기: `extension_starter.py`를 그대로 실행

② 설계하기: 무늬마다 반지름, 개수, 도는 각도를 표에 먼저 적기. 개수 × 각도가 360이면 한 바퀴를 꼭 맞게 채워요

완성 예시: 원 36개 무늬 + 작은 주황 원 12개 무늬

(그림은 `lesson.html`에서 본다)

| 무늬 | 원 반지름 | 개수 | 도는 각도 | 개수 × 각도 |
| --- | --- | --- | --- | --- |
| 시작 파일 | 80 | 12 | 30 | 360 |
| 무늬 1 (바꾼 것) |   |   |   |   |
| 무늬 2 (겹친 것) |   |   |   |   |

③ 바꾸고 체크하기

- [ ] 원 개수와 도는 각도를 바꿨고, 개수 × 각도가 360이에요.
- [ ] 반지름이 다른 원으로 두 번째 무늬를 겹쳐 그렸어요.
- [ ] 선 색이나 굵기를 바꿨어요.

**➕ 더 해 보기**

- `turtle.circle(80, steps=6)`처럼 쓰면 원 대신 육각형으로 무늬 만들기
- `turtle.bgcolor("black")`으로 검은 바탕에 밝은 색 선

<summary>[워밍업] for 줄에서 오류가 날 때 ●○○</summary>

`for` 줄 끝에는 `:`을 붙이고, 되풀이할 줄은 앞에 4칸을 똑같이 띄워요. 막대 4개가 같은 각도로 한 바퀴를 돌려면 360 ÷ 4도씩 돌아요.

</details>

<details>
<summary>[단계 1] 막대가 가늘거나 검은색일 때 ●○○</summary>

`turtle.pensize(6)`과 `turtle.color("brown")`을 `forward()`보다 먼저 썼는지 봐요.

</details>

<details>
<summary>[단계 2] for 줄에서 오류가 나거나 막대가 하나만 나올 때 ●○○</summary>

for 줄 끝에 `:`이 있는지, 아래 세 줄 앞에 4칸을 똑같이 띄웠는지 봐요.

</details>

<details>
<summary>[단계 3] 날개가 엉뚱한 곳에 생길 때 ●○○</summary>

단계 3을 시작할 때 거북이가 가운데에서 → 쪽을 봐야 해요. 단계 2의 `turtle.left(90)`이 for 안(4칸 띄움)에 있는지 봐요.

</details>

<details>
<summary>[바꾸기] 날개 8개는 몇 도를 더 돌까요 ●○○</summary>

날개 하나를 그리고 나면 거북이는 오른쪽으로 90도 돌아 있어요(시작 → , 끝 ↓). 날개 8개는 날개 사이가 360 ÷ 8 = 45도라서, 90도에서 45도를 되돌리면 돼요.

</details>

<details>
<summary>[새로 만들기] 날개 끝 점 · 무엇부터 할지 모를 때 ●○○</summary>

날개 끝은 가운데에서 100만큼 떨어진 곳이에요. 단계 2처럼 날개마다 끝까지 갔다가 돌아오면서 점을 찍어요. 날개 수만큼 되풀이해요.

</details>

<details>
<summary>[새로 만들기] 날개 끝 점 · 쓸 도구가 떠오르지 않을 때 ●●○</summary>

단계 2와 같은 모양의 for를 하나 더 써요. `forward(100)`과 `backward(100)` 사이에 `turtle.dot(15, "yellow")`를 넣어요. 선이 덧그려지지 않게 먼저 `turtle.penup()`을 써요. 횟수와 각도는 내 날개 수에 맞춰요: 날개 8개면 `range(8)`, 360 ÷ 8 = 45도씩.

</details>

<details>
<summary>[새로 만들기] 날개 끝 점 · 거의 다 됐는데 안 될 때 ●●●</summary>

`turtle.done()` 줄 위에 입력해요. 날개 8개일 때예요. 날개가 4개면 `range(4)`, `left(90)`으로 바꿔요.

```python
turtle.penup()
for i in range(8):
    turtle.forward(100)
    turtle.dot(15, "yellow")
    turtle.backward(100)
    turtle.left(45)
```

</details>

<details>
<summary>[도전] 만다라 · 무엇부터 할지 모를 때 ●○○</summary>

시작 파일을 실행하고 `range()`의 숫자와 `left()`의 각도를 표에 적어요. 두 수를 곱하면 360이에요.

</details>

<details>
<summary>[도전] 만다라 · 쓸 도구가 떠오르지 않을 때 ●●○</summary>

개수를 정하면 각도는 360 ÷ 개수예요(36개면 10도). 두 번째 무늬는 같은 모양의 for를 하나 더 쓰고 `circle()`의 반지름만 바꿔요.

</details>

<details>
<summary>[도전] 만다라 · 거의 다 됐는데 안 될 때 ●●●</summary>

`turtle.done()` 줄 위에 입력해요. 작은 주황 원 12개 무늬예요.

```python
turtle.color("orange")
for i in range(12):
    turtle.circle(40)

```
