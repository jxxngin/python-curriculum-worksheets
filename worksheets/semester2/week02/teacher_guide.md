# 2학기 2주차 교사 가이드: 바람개비

## 수업 목표

- `for`와 `range()`로 같은 그림을 정한 횟수만큼 되풀이한다.
- 한 바퀴 360도를 횟수로 나눠 도는 각도를 정한다(4개면 90도, 8개면 45도).
- `backward()`, `pensize()`, 반원 `circle(반지름, 180)`을 쓴다.

## 핵심 설명 포인트

- 블록 코딩의 "○번 반복하기" 블록 = `for i in range(○):`. 블록의 안쪽 = 파이썬에서는 앞에 4칸 띄운 줄들이다. 들여쓰기가 끝나면 반복도 끝난다.
- 줄 끝 `:`은 "아래 줄들이 반복할 내용"이라는 표시다. 1학기의 `if`·`while`과 같다.
- `range(4)`는 0, 1, 2, 3이다. 1부터가 아니다. 이번 주는 `i`를 따라가기에서 몇 번째인지 셀 때만 쓰고, `i`를 계산에 쓰는 것은 다음 주(반복 속 변수)에 한다.
- 도는 각도: 한 바퀴 360도 ÷ 횟수. 도구 카드의 세모(120도), 오각형(72도), 단계 2의 + 모양(90도)으로 같은 규칙을 세 번 본다.
- 단계 3의 날개는 따로 돌지 않는다. 날개 하나를 그리면 거북이가 왼쪽으로 180도(반원) + 90도 = 270도 돌아, 오른쪽으로 90도 돈 것과 같아진다. 따라가기 표의 "다 그린 뒤 보는 쪽"이 ↓ ← ↑ →로 바뀌는 것으로 확인시킨다.
- 날개 8개(★ 둘째): 날개 사이는 360 ÷ 8 = 45도다. 날개가 이미 오른쪽으로 90도 돌려 놓으니 날개마다 `turtle.left(45)`로 45도를 되돌린다. 바로 답을 주지 말고 따라가기 표를 다시 보게 한다. 막히면 힌트 카드의 `바꾸기` 카드.
- 단계 1에서 막대를 그린 뒤 `backward(200)`, `left(90)`으로 가운데에서 → 쪽을 보게 되돌려 둔다. 다음 단계가 이 위치·방향에서 시작한다는 것을 짚는다.
- 도전의 `turtle.speed(0)`은 가장 빠르게 그린다. 0이 가장 느린 것이 아니라는 점이 헷갈리기 쉽다.

## 자주 나오는 오류와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| `SyntaxError: expected ':'` | for 줄 끝 `:` 빠짐 | 줄 끝에 `:` |
| `IndentationError: expected an indented block after 'for' statement` | 반복할 줄 앞을 띄우지 않음 | 4칸 띄운다 |
| `IndentationError: unexpected indent` | 반복이 아닌 줄을 띄움, 또는 띄운 칸 수가 줄마다 다름 | 같은 묶음은 같은 칸 수(4칸)로 맞춘다 |
| 막대가 하나만 나옴 | `left(90)`을 for 밖(띄우지 않음)에 씀 | 반복할 줄은 모두 4칸 띄운다 |
| 날개가 막대에 안 붙고 엉뚱한 곳에 생김 | 단계 2가 끝났을 때 거북이가 → 쪽이 아님(단계 1·2의 돌기 빠짐) | 단계 1의 마지막 `left(90)`, 단계 2의 for 안 `left(90)`을 확인 |
| 날개 8개가 겹치거나 4개 자리에만 생김 | `left(45)`를 for 밖에 씀, 또는 각도 계산이 틀림 | `left(45)`도 for 안(4칸)에 |
| 그림이 너무 오래 걸림(도전) | 원을 많이 그림 | `turtle.speed(0)`을 맨 위에 |

## 워밍업 정답

1. 10번째 줄: `for i in range(4)` → 끝에 `:` 추가 (`SyntaxError`)
2. 19번째 줄: `turtle.forward(50)` 앞에 4칸 띄우기 (`IndentationError`)
3. 21번째 줄: `turtle.left(60)` → `turtle.left(90)` (메시지 없음: 360 ÷ 4 = 90)

참고: 1·2는 둘 다 실행 전에 나오고, 10번을 고쳐야 19번이 보인다. 셋째는 메시지 없이 십자가 위쪽 반에만 몰린다. "다 고치면 보여야 할 그림"(파일 맨 위 주석)과 비교하게 한다.

## 단계별 확인

- 단계 1: 갈색 막대가 아래로 / 단계 2: + 모양 막대 4개 / 단계 3: 막대마다 빨간 반원 날개. 세 단계 모두 끝나면 거북이는 가운데에서 → 쪽이다. 자세한 답은 `answer_key.md`.
- 그리기 칸은 정확히 그리지 않아도 된다. 날개가 붙는 쪽과 화살표 방향이 보이면 된다.

## 진도 차이 대응

- 빠른 학생: 새로 만들기(날개 끝 점) → 도전 만다라. 만다라는 표의 "개수 × 각도"를 먼저 계산하고 실행해 맞는지 본다.
- 느린 학생: 단계 3까지 실행 + ★ 1~2개(날개 색, 손잡이)를 최소 목표로 한다. for의 `:`·들여쓰기에서 오래 막히면 단계 2 코드를 같이 보며 한 줄씩 띄운다.
- 인쇄: 양면 인쇄를 권장한다.
