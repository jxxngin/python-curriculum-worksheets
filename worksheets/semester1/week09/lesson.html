②화면 흐름 그리기 상자 3개 이상(시작 화면 → 되풀이되는 화면 → 끝 화면), 화면에 나올 글자도 적기
  • 주제를 골랐어요.

단계 2 변수·리스트 표와 순서도

📌 목표: 바뀌는 값(변수)과 모아 둘 값(리스트)을 정하고, 반복과 판정의 순서를 그린다.
🧰 순서도 기호

네모 [ ]는 "하는 일", 마름모 < >는 "묻는 조건"이에요. 조건에서 예/아니요로 갈라지고, 반복은 화살표가 위로 돌아가요.

[펫 이름 묻기]<턴이 10 이하?> 예 → [행동 고르기] → 다시 위로               아니요 → [행복도로 판정]

→ 반복이 어디서 시작하고 끝나는지 보여요

①변수 표 화면에 숫자로 보이는 것 = 변수
이름 (영어)뜻처음 값언제 바뀌나요?
예) lives목숨3틀릴 때 1 줄어요
②리스트 표 여러 개를 모아 두는 것 = 리스트
이름 (영어)처음 내용언제 append / in?
예) keys[ ] (빈 리스트)방을 나갈 때 append
③순서도 그리기 반복이 시작·끝나는 곳, 성공·실패를 판정하는 곳 표시
  • 변수마다 처음 값을 적었어요.
  • 순서도에 반복이 끝나는 조건이 있어요.

⭐ 설계도 점검 오늘의 완성 기준

📌 목표: 설계도가 최소 완성 기준을 모두 담았는지 점검하고, 쓸 개념을 고른다.
①사용할 개념 체크 설계도에서 쓸 개념에 모두 표시
  • print() · input() · 변수 · f-string
  • if / elif / else · == · .strip()
  • int() · 산술 연산자 · %
  • import random · random.randint() · abs()
  • and / or / not · 깃발 변수 (True / False)
  • while · break · continue · 누적 변수
  • 리스트 · append() · in · random.choice()
②설계도 점검하기 ★ 3개를 하면 완성
  • ★ 고른 주제의 최소 완성 기준을 설계도에 하나도 빠짐없이 넣었어요.
  • ★ 반복(while)이 언제 끝나는지 조건을 적었어요.
  • ★ 변수마다 처음 값을 정했어요. (누적 변수는 반복 전에)
➕ 더 해 보기
  • 최소 기준보다 더 만들고 싶은 기능을 따로 적었어요.
  • time.sleep()(10주 명령 카드)으로 넣을 기다리는 연출 자리를 표시했어요.
