## 🎯 오늘의 미션

기말 프로젝트 주제를 하나 고르고, 코드를 쓰기 전에 설계도를 그려요. 설계를 마치면 보충 문제로 1~8주에 배운 것을 다시 써 봐요.

**오늘의 목표**

- 기말 주제를 고르고 최소 완성 기준을 말할 수 있다.
- 화면 흐름, 변수·리스트 표, 순서도로 설계도를 그릴 수 있다.
- 작은 프로그램을 바꾸며 헷갈리는 개념을 다시 써 볼 수 있다.

10~11주에 만들 프로그램 예시: 수학 문제 방탈출:

```
🔐 수학 문제 방탈출 🔐
방 3개를 모두 지나 열쇠 3개를 모으면 탈출이에요. 목숨은 3개!

=== 1번 방: 덧셈의 방 ➕ ===
23 + 41 = 64
철컥! 🔑 1번 열쇠를 얻었어요.

=== 2번 방: 구구단의 방 ✖️ ===
7 × 8 = 54
땡! 정답은 56. 남은 목숨 ❤️❤️🤍
6 × 4 = 24
철컥! 🔑 2번 열쇠를 얻었어요.

=== 3번 방: 나머지의 방 ➗ ===
38 ÷ 5의 나머지는? 3
철컥! 🔑 3번 열쇠를 얻었어요.

문을 확인하는 중...
모은 열쇠: ['1번 열쇠', '2번 열쇠', '3번 열쇠']
🎉 탈출 성공! 바깥 공기가 상쾌해요.
등급: 🥈 침착한 탐험가
```

## 🪜 단계 1: 주제 고르고 화면 흐름 그리기

📌 목표: 기말 주제 하나를 고르고, 시작 → 되풀이되는 화면 → 끝 화면을 그린다.

① 주제 고르기: 수학 문제 방탈출(방 3개, 방마다 무작위 문제를 맞힐 때까지 반복, 목숨 3개, 열쇠 리스트) / 펫과 함께하는 하루(10턴, 행동 3개, 배고픔·기분 수치 2개, 행복도로 성공·실패 판정) / 청소년 창업 시뮬레이션 🚀 어려움(7일 영업, 돈·평판 수치 2개, 판매 상품 리스트, 무작위 사건 3개, 목표 금액 달성 여부 판정) / 1~8주 프로젝트를 교과 주제로 키우기(`while`, 리스트, 조건, `random`을 모두 쓰기)

② 화면 흐름 그리기: 시작 화면 → 되풀이되는 화면(한 턴·한 방·하루) → 끝 화면을 상자 3개 이상으로 그리고, 화면에 나올 글자도 적는다.

✅ 주제를 골랐어요. / 되풀이되는 화면에 나올 글자를 적었어요.

## 🪜 단계 2: 변수·리스트 표와 순서도

📌 목표: 바뀌는 값(변수)과 모아 둘 값(리스트)을 정하고, 반복과 판정의 순서를 그린다.

> 🧰 **순서도 기호**: 네모 `[ ]`는 "하는 일", 마름모 `< >`는 "묻는 조건"이에요. 조건에서 예/아니요로 갈라지고, 반복은 화살표가 위로 돌아가요.
>
> ```python
> [펫 이름 묻기]
> <턴이 10 이하?> 예 → [행동 고르기] → 다시 위로
>                아니요 → [행복도로 판정]
> ```
> → 반복이 어디서 시작하고 끝나는지 보여요

① 변수 표: 이름(영어) | 뜻 | 처음 값 | 언제 바뀌나요? (예: `lives` | 목숨 | 3 | 틀릴 때 1 줄어요)

② 리스트 표: 이름(영어) | 처음 내용 | 언제 append / in? (예: `keys` | 빈 리스트 | 방을 나갈 때 append)

③ 순서도 그리기: 반복이 시작·끝나는 곳, 성공·실패를 판정하는 곳을 표시한다.

✅ 변수마다 처음 값을 적었어요. / 순서도에 반복이 끝나는 조건이 있어요.

## ⭐ 설계도 점검 (오늘의 완성 기준)

📌 목표: 설계도가 최소 완성 기준을 모두 담았는지 점검하고, 쓸 개념을 고른다.

① 사용할 개념 체크: 설계도에서 쓸 개념에 모두 표시한다(1~8주 개념: print·input·변수·f-string / if·elif·else·==·strip / int·산술·% / random.randint·abs / and·or·not·깃발 변수 / while·break·continue·누적 변수 / 리스트·append·in·random.choice).

**★ 꼭 하기**

- [ ] 고른 주제의 최소 완성 기준을 설계도에 하나도 빠짐없이 넣었어요.
- [ ] 반복(`while`)이 언제 끝나는지 조건을 적었어요.
- [ ] 변수마다 처음 값을 정했어요. (누적 변수는 반복 전에)

**➕ 더 해 보기**

- [ ] 최소 기준보다 더 만들고 싶은 기능을 따로 적었어요.
- [ ] `time.sleep()`(10주 명령 카드)으로 넣을 기다리는 연출 자리를 표시했어요.

👀 친구에게 설계도 설명하기: 1분 동안 설명하고 친구의 한마디 받기
