## 📐 기말 설계도 (오늘의 미니 프로젝트)

### 1. 주제 고르기

| 구분 | 주제 | 최소 완성 기준 (이보다 더 만든 것은 추가 기능) |
| --- | --- | --- |
| 미니 | 🔐 수학 문제 방탈출 | 방 3개, 방마다 무작위 문제를 맞힐 때까지 반복, 목숨 3개, 열쇠 리스트 |
| 미니 | 🐶 펫과 함께하는 하루 | 10턴, 행동 3개(밥, 놀기, 재우기), 배고픔·기분 수치 2개, 행복도로 성공·실패 판정 |
| 확장 | 🏪 청소년 창업 시뮬레이션 | 7일 영업, 돈·평판 수치 2개, 판매 상품 리스트, 무작위 사건 3개, 목표 금액 달성 여부 판정 |

또는 1~8주 미니·확장 프로젝트를 교과 주제로 바꿔 키워도 돼요. 이때도 **while, 리스트, 조건, random을 모두** 쓰는 것이 기준이에요.

### 2. 설계도 칸 (워크시트에 손으로 채워요)

1. **화면 흐름**: 시작 화면 → 반복되는 화면(한 턴/한 방/하루) → 끝 화면을 상자 3개 이상으로 그려요. 화면에 나올 글자도 적어요.
2. **변수 표**: 이름(영어), 뜻, 처음 값, 언제 바뀌는지
3. **리스트 표**: 이름, 처음 내용, 언제 `append()` 하거나 `in`으로 검사하는지
4. **사용할 개념 체크**: `print/input`, `if/elif/else`, `int()`, f-string, `random`, `and/or/not`, 깃발 변수, `while`, `break/continue`, 누적 변수, 리스트, `append()`, `in`, `random.choice()`
5. **순서도**: 반복이 어디서 시작하고 어디서 끝나는지, 성공·실패 판정이 어디서 일어나는지

### 3. 설계도 점검 체크리스트

- [ ] 최소 완성 기준을 하나도 빠짐없이 설계도에 넣었어요.
- [ ] 반복(while)이 **언제 끝나는지** 조건을 적었어요.
- [ ] 변수마다 처음 값을 정했어요. (누적 변수는 반복 전에!)
- [ ] 친구나 선생님에게 설계도를 설명했어요.

<details>
<summary>힌트 1 (방향)</summary>

기말 프로그램은 대부분 "준비 → 큰 반복 → 결과" 모양이에요. 한 턴(한 방, 하루) 안에서 일어나는 일만 먼저 적어 보세요.

</details>

<details>
<summary>힌트 2 (사용할 개념)</summary>

턴 수가 정해져 있으면 `while turn <= 10:` + 누적 변수, 맞힐 때까지면 `while True:` + `break`. 열쇠·상품은 리스트 + `append()`, 무작위 사건은 `random.randint()`나 `random.choice()`.

</details>
