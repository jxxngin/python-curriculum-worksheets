# 9주차 교사 가이드: 설계와 보충 (기말 설계도)

## 수업 목표

- 기말 주제를 정하고 최소 완성 기준을 이해한다.
- 화면 흐름, 변수·리스트, 사용할 개념, 순서도로 설계도를 완성한다.
- 1~8주 개념 중 부족한 부분을 보충 문제로 연습한다.

## 110분 시간 배분

| 시간 | 활동 | 비고 |
| --- | --- | --- |
| 0~10분 | 워밍업 (1~8주 오류 종합) | |
| 10~25분 | 기말 주제 소개, 최소 완성 기준 설명 | 세 주제 실행 시연이 있으면 좋다(10~11주 solution) |
| 25~40분 | 설계도 ①: 주제 선택, 화면 흐름 | |
| 40~50분 | 쉬는 시간 | |
| 50~75분 | 설계도 ②: 변수·리스트 표, 개념 체크, 순서도 | 학생별 순회 점검 |
| 75~100분 | 설계도 발표(1분씩) → 보충 문제 / 설계 다듬기 | 진도별로 나눔 |
| 100~110분 | 체크리스트, 다음 주 예고(구현 시작, time.sleep 명령 카드) | |

## 핵심 설명 포인트

- 새 개념이 없는 완충 주간이다. 진도가 늦은 학생은 보충 문제, 빠른 학생은 설계를 깊게.
- 기말 최소 완성 기준은 커리큘럼 그대로 제시한다. "이보다 더 만든 것은 추가 기능"이므로 설계 단계에서 최소 기준을 먼저 채우고 추가 기능은 따로 적게 한다.
  - 수학 문제 방탈출: 방 3개, 방마다 무작위 문제를 맞힐 때까지 반복, 목숨 3개, 열쇠 리스트
  - 펫과 함께하는 하루: 10턴, 행동 3개(밥, 놀기, 재우기), 배고픔·기분 수치 2개, 행복도로 성공·실패 판정
  - 청소년 창업 시뮬레이션: 7일 영업, 돈·평판 수치 2개, 판매 상품 리스트, 무작위 사건 3개, 목표 금액 달성 여부 판정
- 1~8주 프로젝트를 교과 주제로 키우는 경우에도 while, 리스트, 조건, random이 들어가도록 안내한다.
- 화면 흐름은 "시작 → 반복 화면 → 끝" 3칸이 최소. 반복 화면에는 한 턴에 보일 글자를 실제로 쓰게 한다.
- 변수 표에서 "처음 값"과 "언제 바뀌나"를 꼭 쓰게 한다. 누적 변수 초기화 위치 오류(7주)를 설계에서 미리 막는다.
- 순서도는 블록 코딩 경험을 살려 "반복 블록 안에 무엇이 들어가나"로 설명하면 쉽다. 마름모(조건), 네모(처리) 정도만 쓴다.
- len(), for, 함수(def)는 아직 배우지 않았다. 설계에서 필요해 보이면 while + 카운터 변수, 리스트 `in`으로 대신하도록 안내한다.

## 설계도 예시 (펫과 함께하는 하루, 교사 참고용)

- 화면 흐름: 펫 이름 입력·인사 → [n턴] 배고픔·기분 표시, 행동 1~3 선택, 무작위 반응 → 10턴 끝, 행복도와 성공/실패
- 변수: `turn`(턴, 1, 매 턴 +1), `hunger`(배고픔, 5, 밥 -3/매 턴 +1), `mood`(기분, 5, 놀기 +3/재우기 +1), `happy`(행복도, 끝에 계산)
- 리스트: `toys = ["공"]`(놀 때 random.choice, 이벤트로 append), `diary`(매 턴 행동 기록 append)
- 순서도: 시작 → turn ≤ 10? → 표시 → 입력 → 행동 분기 → 수치 범위 조정 → turn+1 → (반복) → 행복도 ≥ 기준? → 성공/실패

## 자주 나오는 문제와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| 설계도가 너무 거대함(맵, 상점, 레벨…) | 최소 기준과 추가 기능 구분 없음 | 최소 기준 칸과 추가 기능 칸을 나눠 쓰게 함 |
| 화면 흐름에 반복이 안 보임 | 시작·끝만 그림 | "몇 번 반복되는 화면은 어디?" 질문 |
| 변수 표가 비어 있음 | 무엇이 변하는지 모름 | 화면에 숫자로 보이는 것 = 변수 |
| 보충 문제 실행 시 SyntaxError | 안 푼 문제의 `___`가 남음 | 안 푼 문제는 Alt+3으로 주석 처리 |

## 워밍업 정답

1. 12번째 줄: `if pick = "금 열쇠":` → `==` (SyntaxError)
2. 15번째 줄: `"... 남은 기회: " + (3 - tries)` → `f"... 남은 기회: {3 - tries}"` (TypeError)
3. 17번째 줄: `tires` → `tries` (NameError)

## 보충 문제 정답

빈칸 1 `input`, 빈칸 2 `+`, 빈칸 3 `elif`, 빈칸 4 `%`, 빈칸 5 `or`, 빈칸 6 `saved`, 빈칸 7 `in`, 빈칸 8 `append`
(빈칸 2·3·4·5·7은 기호·키워드 자리라 채우기 전에는 SyntaxError가 나는 것이 정상이다. 그래서 안 푼 문제는 주석 처리하도록 안내한다.)

## 진도 차이 대응

- 1~8주 진도가 밀린 학생: 설계도는 펫 주제로 최소 기준만, 나머지 시간은 밀린 주차 미니 1단계 또는 보충 문제.
- 보통: 설계도 완성 → 보충 문제 중 틀리기 쉬운 4~6번.
- 빠른 학생·중고등: 청소년 창업 시뮬레이션 설계. 무작위 사건 3개의 효과 표, 목표 금액과 밸런스(하루 평균 수입 × 7일)를 숫자로 계산해 보게 한다.
