## 🗺️ 미니 퀘스트 카드 (셋 중 하나 고르기)

> 초등은 미니 퀘스트 카드 중 하나가 완성 기준이에요. 1~4주 미니 프로젝트(초대장, 밸런스 게임, 인생 숫자, 비밀의 문)를 교과 주제로 바꿔 키워도 좋아요. (예: 비밀의 문 → 수학 문제를 풀어야 열리는 문)

### 퀘스트 A. ➕ 수학 연산 퀴즈 (`midterm_math_starter.py`)

1단계 따라 하기: 빈칸 4개를 채워 덧셈·곱셈·나머지 문제 3개를 완성해요.

2단계 바꾸기 ⭐ 완성 기준
- [ ] 문제를 5개 이상으로 늘렸어요. (뺄셈, 몫 문제 포함)
- [ ] 난이도(쉬움/어려움)를 골라 숫자 범위가 바뀌어요.
- [ ] 틀리면 내 답과 정답의 차이를 `abs()`로 알려 줘요.
- [ ] 점수에 따라 등급이 나와요.

3단계 새로 만들기 (선택): 💡 뺄셈 답이 음수가 안 나오게 하기 💡 시간표처럼 "분 → 시간 몇 분" 바꾸기 문제 💡 문제마다 배점 다르게

### 퀘스트 B. 📜 역사 인물 퀴즈 (`midterm_history_starter.py`)

1단계 따라 하기: 빈칸 4개를 채워 무작위 인물 문제 + 객관식 문제를 완성해요.

2단계 바꾸기 ⭐ 완성 기준
- [ ] 무작위로 나오는 인물을 5명 이상으로 늘렸어요.
- [ ] 정답 뒤에 인물 한 줄 설명이 나와요.
- [ ] 라운드를 1개 이상 추가했어요. (O/X, 객관식 등)
- [ ] 점수에 따라 등급이 나와요.

3단계 새로 만들기 (선택): 💡 '힌트'를 입력하면 첫 글자를 보여 주고 점수 절반 💡 시대별(삼국·고려·조선) 라운드 💡 인물 대신 문화유산 퀴즈

### 퀘스트 C. 🔤 영어 단어 퀴즈 (`midterm_english_starter.py`)

1단계 따라 하기: 빈칸 4개를 채워 "뜻→영어", "영어→뜻" 문제를 완성해요.

2단계 바꾸기 ⭐ 완성 기준
- [ ] 문제마다 무작위 단어를 5개 이상으로 늘렸어요.
- [ ] 첫 글자 힌트를 보여 줘요.
- [ ] 문제 유형을 1개 이상 추가했어요. (숫자 영어, 반대말 등)
- [ ] 점수에 따라 등급이 나와요.

3단계 새로 만들기 (선택): 💡 오늘 배운 영어 교과서 단원 단어로 바꾸기 💡 반대말 퀴즈(big ↔ small) 💡 틀린 단어를 마지막에 다시 보여 주기

## 🚀 확장 퀘스트 카드 (둘 중 하나 고르기)

> 중고등은 확장 퀘스트가 완성 기준이에요. 1~4주 개념을 **모두** 섞어 써야 해요. 빈칸 없이 starter 파일을 실행해 보고 바꾸기부터 시작해요.

### 퀘스트 D. 🚀 화성 탐사 미션 센터 (`midterm_mars_starter.py`)

과학 연계: 지구와 화성 사이 거리(약 5,500만~4억 km), 속력 = 거리 ÷ 시간

바꾸기 ⭐ 완성 기준
- [ ] 대원 수를 입력받아 필요한 산소량을 다시 계산해요.
- [ ] 비행 기간을 `//`와 `%`로 "몇 주 며칠"로 보여 줘요.
- [ ] 무작위 우주 사건이 3가지 이상 일어나요.
- [ ] 착륙 목표와의 오차를 `abs()`로 계산해 착륙 결과를 판정해요.
- [ ] 미션 점수로 최종 평가가 나와요.

새로 만들기 (선택): 💡 연료 계산 추가 💡 화성 기지 건설 단계 💡 지구와 교신 지연 시간(빛의 속도) 계산

### 퀘스트 E. 🌏 지진 조기 경보 시스템 (`midterm_earthquake_starter.py`)

과학 연계: 지진파(P파는 빠르고 약함, S파는 느리고 강함), 규모와 피해

바꾸기 ⭐ 완성 기준
- [ ] 경보 단계를 4단계 이상으로 나눠요. (관심·주의·경계·심각 등)
- [ ] 규모를 `5.3`처럼 소수 한 자리로 보여 줘요. (힌트: 정수 두 개를 무작위로)
- [ ] 대피 시간이 60초 이상이면 "몇 분 몇 초"로 보여 줘요.
- [ ] 내 대피 시간과 경보 시간을 `abs()`로 비교해 대피 가능 여부를 알려 줘요.
- [ ] 마지막에 한 줄 보고서를 출력해요.

새로 만들기 (선택): 💡 무작위 여진 예보 💡 단계별 행동 요령 안내 💡 건물 층수에 따른 대피 시간 계산

<details>
<summary>힌트 1 (방향)</summary>

시뮬레이션은 "단계"로 나눠서 만들어요. 단계마다 입력 → 계산 → 판정 → 점수(또는 상태) 변화. 단계 하나씩 실행해서 확인하고 다음 단계를 붙여요.

</details>

<details>
<summary>힌트 2 (사용할 함수)</summary>

몇 주 며칠: `days // 7`, `days % 7`. 소수 규모: `random.randint(3, 7)`과 `random.randint(0, 9)`를 f-string에서 `{a}.{b}`로. 비교하기 쉽게 `a * 10 + b`로 10배 값을 만들어 `>= 50`처럼 비교해요.

</details>

<details>
<summary>힌트 3 (거의 코드)</summary>

```python
target = random.randint(0, 100)
land = int(input("착륙 좌표: "))
error = abs(land - target)
if error == 0:
    mission_score = mission_score + 20
elif error <= 10:
    print("안전한 착륙!")
else:
    mission_score = mission_score - 30
```

</details>

## 🎤 발표 안내 (한 사람당 3분)

1. 프로젝트 이름과 교과 연계 한 문장 (예: "수학 시간에 배운 나머지를 퀴즈로 만들었어요")
2. 실제로 실행해서 보여 주기 (친구가 직접 플레이해도 좋아요)
3. 내가 가장 자랑하고 싶은 코드 한 부분
4. 어려웠던 점과 고친 방법 (오류 메시지 이야기 환영!)

듣는 친구는 "좋았던 점 1개 + 이런 기능이 있으면 좋겠다 1개"를 말해 줘요.
