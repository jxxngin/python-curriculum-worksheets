## 🎯 오늘의 미션

수학·역사·영어 중 하나를 골라, 친구들이 풀어 볼 나만의 퀴즈 프로그램을 만들고 발표해요. 오늘은 수학 퀴즈로 뼈대를 함께 만들고, 내 교과로 바꿔요.

**오늘의 목표**

- 1~4주에 배운 것(입력, 조건, f-string, random)을 모아 퀴즈 하나를 처음부터 끝까지 만들 수 있다.
- "문제 → 채점 → 점수" 덩어리를 복사해 고른 교과의 문제로 바꿀 수 있다.
- 만든 퀴즈를 친구에게 시연하고 자랑할 점을 말할 수 있다.

완성하면 이렇게 돼요:

```
수학 연산 퀴즈
이름: 하린
하린님, 문제마다 맞히면 점수를 받아요!
1번. 7 x 8 = 56
정답! +10점
보너스 문제 (10점). 100 나누기 4 = 25
정답! +10점
하린님의 점수: 20점
등급: 퀴즈 박사
```

## 🪜 단계 1: 퀴즈 시작하기

📌 목표: 퀴즈 제목을 보여 주고 이름을 물어 점수 상자를 0으로 준비한다.

① 기능 추가하기: `mini_starter.py`의 `# 단계 1` 아래에 입력

```python
import random
print("수학 연산 퀴즈")
name = input("이름: ")
score = 0
print(f"{name}님, 문제마다 맞히면 점수를 받아요!")
```

② 실행하고 확인: 마지막 줄 적기

✅ 내 이름이 들어간 안내 문장이 나왔어요.

## 🪜 단계 2: 1번 문제 내고 채점하기

📌 목표: 정답이면 10점을 더하고, 틀리면 정답을 알려 준다.

> 🧰 **글자로 채점하기**: 대답을 `.strip()`으로 다듬고 정답 글자와 `==`로 비교해요. 숫자 문제도 낱말 문제도 같은 모양으로 채점할 수 있어요.
>
> ```python
> reply = "세종대왕"
> if reply == "세종대왕":
>     print("정답")
> ```
> → 정답

① 기능 추가하기: `mini_starter.py`의 `# 단계 2` 아래에 입력

```python
answer = input("1번. 7 x 8 = ").strip()
if answer == "56":
    print("정답! +10점")
    score = score + 10
else:
    print("아쉬워요. 정답은 56")
```

② 실행하고 확인: 맞는 답과 틀린 답을 한 번씩 넣어 보고 나온 말 적기

✅ 56을 넣으면 "정답!", 다른 수를 넣으면 정답을 알려 줬어요.

## 🪜 단계 3: 보너스 문제: 점수를 무작위로

📌 목표: 보너스 문제의 점수를 5·10·15점 중에서 새로 뽑아 맞히면 더한다.

> 🧰 **뽑은 수로 계산하기**: `random.randint(1, 3)`으로 1~3을 뽑고 곱하면, 뽑을 수 있는 값이 그 배수가 돼요.
>
> ```python
> coin = random.randint(1, 3) * 100
> print(coin)
> ```
> → 100, 200, 300 중 하나 (매번 새로 뽑아요)

① 기능 추가하기: `mini_starter.py`의 `# 단계 3` 아래에 입력

```python
bonus = random.randint(1, 3) * 5
answer = input(f"보너스 문제 ({bonus}점). 100 나누기 4 = ").strip()
if answer == "25":
    print(f"정답! +{bonus}점")
    score = score + bonus
```

② 실행하고 확인: 3번 실행하고 보너스 점수 적기

✅ 보너스 점수가 5, 10, 15 중에서 나왔어요. 같은 점수가 또 나와도 정상이에요.

## 🪜 단계 4: 점수와 등급 보여 주기

📌 목표: 마지막 점수를 보여 주고 점수에 따라 등급을 알려 준다.

① 기능 추가하기: `mini_starter.py`의 `# 단계 4` 아래에 입력

```python
print(f"{name}님의 점수: {score}점")
if score >= 20:
    print("등급: 퀴즈 박사")
elif score >= 10:
    print("등급: 퀴즈 탐험가")
else:
    print("등급: 다시 도전!")
```

② 실행하고 확인: 마지막 두 줄 적기

✅ 점수와 등급이 나왔어요.

③ 따라가기: 보너스 15점이 뽑혔고 지우 / 54 / 25를 넣으면?

## 🚀 도전 프로젝트: 화성 탐사 미션 센터 · 지진 조기 경보 시스템 중 택1

**왜 만들까?** 과학 시간에 배우는 거리·속력·시간 계산을 프로그램으로 직접 돌려 보는 연습이에요. 1~4주 개념을 모두 섞어 써요.

📌 목표: 하나를 골라 시작 파일을 실행해 보고, 과학 계산을 더해 나만의 시뮬레이션으로 키운다.

> 🧰 **몫과 나머지로 단위 바꾸기: //, %**: `days // 7`은 몇 주, `days % 7`은 남은 며칠이에요. 초를 분·초로 바꿀 때도 같아요(`// 60`, `% 60`).

① 실행해 보기: 하나를 골라 `midterm_mars_starter.py`(화성) 또는 `midterm_earthquake_starter.py`(지진)를 그대로 실행

| --- | --- | --- |
| □ 화성 탐사 □ 지진 경보 |   |   |

`input()`으로 받은 대답은 글자예요. 숫자와 비교하고 계산하려면 `int(input(...))`로 받아요.

</details>

<details>
<summary>[단계 1] 문장에 {name}이 그대로 나올 때 ●○○</summary>

따옴표 앞에 `f`를 붙여야 `{name}` 자리에 이름이 들어가요.

</details>

<details>
<summary>[단계 2] 정답을 넣어도 "아쉬워요"가 나올 때 ●○○</summary>

정답 글자를 따옴표로 감쌌는지(`"56"`), 대답 끝에 `.strip()`을 붙였는지 봐요.

</details>

<details>
<summary>[단계 3] 보너스 점수가 안 더해질 때 ●○○</summary>

`score = score + bonus`처럼 다시 넣었는지, 그 줄을 `if` 안(4칸)에 썼는지 봐요.

</details>

<details>
<summary>[단계 4] 등급이 늘 "다시 도전!"일 때 ●○○</summary>

큰 점수부터 `if` → `elif` 순서로 썼는지, `>=`의 방향을 봐요. 점수는 숫자라 따옴표 없이 비교해요.

</details>

<details>
<summary>[새로 만들기] 힌트 기회 · 무엇부터 할지 모를 때 ●○○</summary>

대답이 "힌트"면 첫 글자를 보여 주고 대답을 다시 받아요. 이때 받을 점수를 절반으로 줄여요.

</details>

<details>
<summary>[새로 만들기] 힌트 기회 · 쓸 도구가 떠오르지 않을 때 ●●○</summary>

새 상자 `points`(이번 문제 점수, 처음엔 10). `if answer == "힌트":` 안에서 힌트를 보여 주고 `answer = input(...)`로 다시 받은 뒤 `points = 5`.

</details>

<details>
<summary>[새로 만들기] 힌트 기회 · 거의 다 됐는데 안 될 때 ●●●</summary>

1번 문제의 `answer = input(...)` 줄 바로 아래에 넣어요. 그리고 1번 채점의 두 줄도 바꿔요: `print(f"정답! +{points}점")`, `score = score + points`. 그래야 힌트를 쓰면 화면에도 +5점이 나와요.

```python
points = 10
if answer == "힌트":
    print("힌트: 5로 시작해요")
    answer = input("다시 대답: ").strip()
    points = 5
```

</details>

<details>
<summary>[도전] 단위 바꾸기 · 무엇부터 할지 모를 때 ●○○</summary>

큰 단위로 몇 번 나누어떨어지는지(몫)와 남는 양(나머지)을 따로 구해요. 화성은 7일이 1주, 지진은 60초가 1분이에요.

</details>

<details>
<summary>[도전] 단위 바꾸기 · 쓸 도구가 떠오르지 않을 때 ●●○</summary>

몫은 `//`, 나머지는 `%`예요. 화성: `days // 7`, `days % 7` / 지진: `warning_time // 60`, `warning_time % 60`.

</details>

<details>
<summary>[도전] 단위 바꾸기 · 거의 다 됐는데 안 될 때 ●●●</summary>

화성은 예상 비행 기간을 보여 주는 줄(`print(f"🕒 …")`) 아래에 넣어요. 지진은 `days`를 `warning_time`으로, 7을 60으로, "주·일"을 "분·초"로 바꿔 대피 시간 줄 아래에 넣어요.

```python
weeks = days // 7
rest = days % 7
print(f"약 {weeks}주 {rest}일 걸려요.")
```

</details>
