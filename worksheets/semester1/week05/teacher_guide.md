# 5주차 교사 가이드: 중간 프로젝트 (교과 연계)

## 수업 목표

- 1~4주 개념만으로 교과 연계 프로그램을 기획·구현·발표한다.
- 완충 주간으로서 1~4주 진도가 늦은 학생이 따라잡을 기회를 준다.

| 구분 | 주제 | 시작 파일 | 교과 연계 |
| --- | --- | --- | --- |
| 미니 | 수학 연산 퀴즈 | `midterm_math_starter.py` (빈칸 4) | 수학: 사칙연산, 나눗셈의 몫과 나머지 |

| 미니 | 영어 단어 퀴즈 | `midterm_english_starter.py` (빈칸 4) | 영어: 교과서 기본 어휘 |

## 핵심 설명 포인트

- 1~4주 개념만 쓴다. while, 리스트, and/or, 중첩 if는 쓰지 않는다. 학생이 "다시 하기"나 "여러 번 기회"를 원하면 6~7주 예고로 돌린다.
- 예시 답안의 "힌트" 기능은 중첩 if 없이 `points` 변수로 구현했다. 학생이 if 안에 if를 쓰려 하면 이 방식을 보여 준다.
- 무작위 문제 고르기 패턴(`pick = random.randint(1, N)` → `if pick == 1:` 로 문제·정답 변수 지정)이 퀴즈 3종의 공통 핵심이다. 리스트(8주)를 배우기 전의 방식이라는 점을 의식하고, 8주에 random.choice()로 다시 만들어 보게 연결한다.
- 확장 지진: P파 약 6km/s, S파 약 3~3.5km/s를 3km/s로 단순화했다. 실제 규모는 소수이므로 정수 두 개로 표현하고, 비교는 10배 값으로 한다(float 미학습).
- 확장 화성: 지구-화성 거리는 공전 위치에 따라 약 5,500만~4억 km로 변한다. 실제 비행은 직선이 아니라는 점은 탐구 거리로 남긴다.
- 확장에서 round()를 쓰는 학생에게는 짝수 반올림(round(2.5) → 2)을 다시 상기시킨다.

## 자주 나오는 오류와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| 정답인데 오답 처리 | `int()` 누락 또는 문자열 정답에 공백 | int() 확인, `.strip()` |
| `NameError` (정답 변수) | if/elif 중 일부 갈래에서만 변수를 만듦 | 모든 갈래(else 포함)에서 같은 변수를 정하게 |
| `ValueError` | 숫자 질문에 글자 입력 | 질문에 "숫자로" 명시 |
| 점수가 안 오름 | `score + 10`만 쓰고 대입 안 함 | `score = score + 10` |
| 복사한 문제의 정답이 이전 문제 정답 | 변수 덮어쓰기 순서 | `print()`로 변수 값 확인 |
| `IndentationError` | 복사·붙여넣기 들여쓰기 | 블록 선택 후 Tab/Shift+Tab |

## 워밍업 정답

1. 11번째 줄: `if answer == a * b` → 끝에 `:` 추가 (SyntaxError)
2. 9번째 줄: `answer = input(...)` → `answer = int(input(...))` (정답을 넣어도 오답, 고치지 않으면 15번째 줄 abs에서 TypeError)
3. 17번째 줄: `점수` 변수 없음(NameError) + 글자와 숫자 `+` → 위에 `score = 0`, 정답일 때 `score = score + 10`, 마지막 줄 `print(f"퀴즈 끝! {score}점")`

## 미니 따라 하기 정답

- 수학: 빈칸 1 `randint`, 2 `int`, 3 `*`, 4 `%`
- 역사: 빈칸 1 `3`, 2 `strip`, 3 `==`, 4 `"1"`
- 영어: 빈칸 1 `meaning`, 2 `word`, 3 `random`, 4 `score`

## 진도 차이 대응

- 1~4주가 밀린 학생: 오늘은 밀린 주차의 2단계 바꾸기를 끝내고, 그 미니 프로젝트를 교과 주제로 살짝 바꾼 것(예: 밸런스 게임 → 역사 밸런스 게임)으로 발표해도 된다. 완충 주간의 목적을 우선한다.
- 빠른 학생: 미니 3단계 → 확장 퀘스트 도전. 확장을 마친 학생은 다른 확장 주제의 사건·단계를 하나 더 추가.
- 발표를 어려워하는 학생: 교사가 대신 플레이하고 학생은 "자랑할 코드 한 줄"만 설명하게 한다.
- 평가 체크리스트는 성적이 아니라 자기 점검용으로 사용하고, 미완성 항목은 9주(설계와 보충)에서 채울 수 있다고 안내한다.
