# 5주차 교사 가이드: 중간 프로젝트 (교과 퀴즈)

## 수업 목표

- 1~4주 개념만으로 교과 연계 퀴즈를 처음부터 끝까지 만들고 발표한다.
- 완충 주간으로서 1~4주 진도가 늦은 학생이 따라잡을 기회를 준다.

## 형식 (공통 퀴즈 뼈대)

교안: `lesson.html`. 수학·역사·영어 퀴즈는 뼈대가 같다: 시작 → 문제 내고 채점 → 보너스(무작위 점수) → 점수와 등급. 단계 1~4에서 **수학 퀴즈로 뼈대를 함께 만들고**, "내 것으로 바꾸기"에서 고른 교과의 문제로 바꾼다(저장소 주인 결정, 2026-11-06).

| 구분 | 주제 | 파일 | 교과 연계 |
| --- | --- | --- | --- |
| 미니 | 수학 연산 퀴즈 | `mini_starter.py` → 단계 1~4 (`mini_solution.py` 맨 아래에 무작위 숫자 문제 예시) | 수학: 사칙연산 |
| 미니 | 역사 인물 퀴즈 | 같은 뼈대에서 문제만 바꾼다. 예시 답안 `midterm_history_solution.py` | 사회(5~6학년 역사) |
| 미니 | 영어 단어 퀴즈 | 같은 뼈대에서 문제만 바꾼다. 예시 답안 `midterm_english_solution.py` | 영어: 교과서 기본 어휘 |
| 도전 | 화성 탐사 미션 센터 | `midterm_mars_starter.py` → `midterm_mars_solution.py` | 과학: 태양계, 속력 = 거리 ÷ 시간 |
| 도전 | 지진 조기 경보 시스템 | `midterm_earthquake_starter.py` → `midterm_earthquake_solution.py` | 과학(중1~2 지권): P파·S파, 규모 |

1~4주 미니 프로젝트를 교과 주제로 바꿔 키워도 된다(새로 만들기 아이디어). 교과 단원·학년은 학교 교과서 목차와 맞춰 본다.

## 핵심 설명 포인트

- 1~4주 개념만 쓴다. while, 리스트, and/or, 중첩 if는 쓰지 않는다. "다시 하기"나 "여러 번 기회"를 원하면 6~7주 예고로 돌린다.
- 채점은 글자로 비교한다(`answer == "56"`). 숫자 문제도 낱말 문제도 같은 모양이라 교과를 바꾸기 쉽다. 수학에서 무작위 숫자 문제를 낼 때만 `int(input())`으로 받아 계산 값과 비교한다(바꾸기 더 해 보기).
- 문제 하나 = "질문 → 비교 → 점수" 덩어리. 덩어리를 복사해 문제와 정답만 바꾸게 한다. 복사 후 들여쓰기가 흐트러지는 일이 잦다.
- 새로 만들기의 "힌트 기회"는 중첩 if 없이 `points` 변수로 만든다(예시 답안과 같은 방식).
- 예시 답안의 무작위 문제 고르기(`pick = random.randint(1, N)` → `if pick == 1:`)는 리스트(8주) 전의 방식이다. 8주에 random.choice()로 다시 만들어 보게 연결한다.
- 도전 지진: P파 약 6km/s, S파 약 3~3.5km/s를 3km/s로 단순화했다. 규모는 소수이므로 정수 두 개로 표현하고, 비교는 10배 값으로 한다(float 미학습).
- 도전 화성: 지구-화성 거리는 공전 위치에 따라 약 5,500만~4억 km로 변하고, 실행마다 새로 뽑는다. 실제 비행은 직선이 아니라는 점은 탐구 거리로 남긴다. 빛이 지구에서 화성까지 가는 시간은 약 3~22분이다.
- round()를 쓰는 학생에게는 짝수 반올림(round(2.5) → 2)을 다시 알려 준다.

## 자주 나오는 오류와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| 정답인데 오답 처리 | 정답에 따옴표 없음, 대답 끝 공백 | `"56"`처럼 따옴표, `.strip()` |
| 무작위 문제에서 정답인데 오답 | `int()` 누락 | `int(input(...))` |
| `ValueError` | 숫자 질문에 글자 입력 | 질문에 "(숫자만)" 명시 |
| 점수가 안 오름 | `score + 10`만 쓰고 다시 넣지 않음 | `score = score + 10` |
| `IndentationError` | 덩어리 복사·붙여넣기 들여쓰기 | if 안은 4칸으로 맞추기 |
| 영어 정답인데 오답 | 대소문자 다름 | 문제에 "소문자로" 안내 (lower()는 배우지 않음) |

## 워밍업 정답

순서: 11번(SyntaxError) → 15번(TypeError, 원인은 9번) → 17번(NameError).

1. 11번째 줄: `if answer == a * b` 끝에 `:` 추가 (SyntaxError, 실행 전에 나온다)
2. 9번째 줄: `answer = input(...)` → `answer = int(input(...))`. 고치기 전에는 대답이 글자라 늘 "아쉬워요"로 가고 15번째 줄 `abs(answer - a * b)`에서 TypeError가 난다. 힌트 블록의 `워밍업` 카드에 고치는 모양이 있다.
3. 17번째 줄: `점수` 상자가 없다(NameError). 줄을 지우거나, 위에 `score = 0`, 정답일 때 `score = score + 10`, 마지막 줄 `print(f"퀴즈 끝! {score}점")`.

## 단계별 확인

- 단계 1: 이름이 들어간 안내 문장 / 단계 2: 56 → 정답 +10점, 다른 수 → 정답 알려 줌 / 단계 3: 보너스 점수는 5·10·15 중 매번 새로 뽑음(같은 값이 다시 나와도 정상) / 단계 4: 점수와 등급. 자세한 답은 `answer_key.md`.

## 진도 차이 대응

- 1~4주가 밀린 학생: 오늘은 밀린 주차의 바꾸기를 끝내고, 그 미니 프로젝트를 교과 주제로 살짝 바꾼 것(예: 밸런스 게임 → 역사 밸런스 게임)으로 발표해도 된다. 완충 주간의 목적을 우선한다.
- 빠른 학생: 새로 만들기(힌트 기회) → 도전(화성 또는 지진). 도전을 마친 학생은 다른 주제의 사건을 하나 더 더한다.
- 발표를 어려워하는 학생: 교사가 대신 풀어 보고 학생은 "자랑할 코드 한 줄"만 설명하게 한다.
- 미완성 항목은 9주(설계와 보충)에서 채울 수 있다고 안내한다.
- 인쇄: 양면 인쇄를 권장한다.
