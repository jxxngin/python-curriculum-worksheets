# 5주차 교안 정답지: 교과 퀴즈

교사용. `lesson.html`의 블록 순서대로 정리했다. 실행 결과는 `mini_solution.py`를 Python 3.11로 실제로 실행해 확인했다 (보너스 점수는 randint가 2를 뽑아 10점으로 고정).

## 🎯 미션

"완성하면 이렇게 돼요"는 하린 / 56 / 25를 넣고 실행한 화면이다.

## 🔧 워밍업 (고장 난 구구단 퀴즈 고치기)

| 나타나는 순서 | 줄 | 오류 이름 (실제 메시지) | 고친 방법 |
| --- | --- | --- | --- |
| 1 | 11 | SyntaxError (`expected ':'`) | `if answer == a * b:` |
| 2 | 15 | TypeError (`unsupported operand type(s) for -: 'str' and 'int'`) | 9번 줄을 `answer = int(input(...))`로 (워밍업 힌트 카드) |
| 3 | 17 | NameError (`name '점수' is not defined`) | 줄을 지우거나, 점수 상자를 만들고 `print(f"퀴즈 끝! {score}점")` |

- SyntaxError(11번)는 실행 전에 나온다. 고치면 대답이 글자라 늘 "아쉬워요"로 가고 15번 `abs(answer - a * b)`에서 TypeError가 난다. 원인은 9번 줄이다. int()로 고치면 맞든 틀리든 17번 NameError가 난다.

## 🪜 단계 1 · 퀴즈 시작하기

- 실행하고 확인: `(이름)님, 문제마다 맞히면 점수를 받아요!`

## 🪜 단계 2 · 1번 문제 내고 채점하기

- 실행하고 확인: 56 → `정답! +10점` / 54 → `아쉬워요. 정답은 56`

## 🪜 단계 3 · 보너스 문제: 점수를 무작위로

- 실행하고 확인: 보너스 점수는 실행마다 5·10·15 중에서 새로 뽑는다. 같은 점수가 다시 나와도 정상이다(직전과 같을 확률 1/3).

## 🪜 단계 4 · 점수와 등급 보여 주기

- 실행하고 확인: `(이름)님의 점수: N점` / `등급: …` (20점 이상 퀴즈 박사, 10점 이상 퀴즈 탐험가, 그 밖에는 다시 도전!)

**따라가기** (보너스 15점이 뽑혔고 지우 / 54 / 25를 넣으면?, 실행해 확인함)

| 1번 뒤 score | 보너스 뒤 score | 등급 |
| --- | --- | --- |
| 0 (54 ≠ 56) | 15 (25 정답, +15) | 퀴즈 탐험가 (15 ≥ 10) |

## ⭐ 내 것으로 바꾸기

- 문제 하나 = "질문 → 비교 → 점수" 덩어리다. 덩어리를 복사해 문제와 정답만 바꾸면 문제가 늘어난다. 새 문제는 단계 4(점수와 등급) 코드 **위**에 넣어야 점수와 등급에 반영된다. 수학 무작위 문제 예시는 `mini_solution.py` 맨 아래 주석(단계 4 위로 옮겨 쓴다), 역사·영어 예시 답안 `midterm_history_solution.py`, `midterm_english_solution.py`는 같은 뼈대(1번 → 보너스 → 등급)를 교과로 바꾸고 문제 3개를 더해 ★ 3개를 모두 채운 완성 예시다(최고 55점, 등급 기준 40·20점).
- 완성 기준은 ★ 3개다. 더 해 보기는 평가에 넣지 않는다.

## 🚀 도전 프로젝트 (화성 탐사 미션 센터 · 지진 조기 경보 시스템 중 택1)

- 화성: 거리는 실행마다 5,500만~4억 km 중에서 새로 뽑아 결과가 달라진다. 지진: 거리 120km면 P파 20초, S파 40초, 대피 시간 약 20초(실행해 확인함, 예시 답안은 `0분 20초 (20초)`처럼 60초 미만도 분·초로 보여 준다), 규모는 3~7 중 무작위. 예시 답안은 `midterm_mars_solution.py`, `midterm_earthquake_solution.py`.
