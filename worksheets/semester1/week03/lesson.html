단계 1 나이 계산하기

📌 목표: 태어난 해와 올해를 숫자로 받아 나이를 계산한다.
🧰 글자를 숫자로: int()

input()으로 받은 대답은 늘 글자예요. 계산하려면 int()로 감싸서 숫자로 바꿔요.

height = int(input("키는? "))print(height + 10)

→ 140을 넣으면 150

🧰 문장 속에 상자 넣기: f-string

따옴표 앞에 f를 붙이면 { } 안에 상자나 계산을 넣을 수 있어요. 숫자도 바로 들어가요.

cats = 3print(f"고양이 {cats}마리, 다리 {cats * 4}개")

→ 고양이 3마리, 다리 12개

①기능 추가하기 mini_starter.py의 # 단계 1 아래에 입력
print("인생 숫자 계산기")name = input("이름: ")birth_year = int(input("태어난 해 (숫자만, 예: 2015): "))this_year = int(input("올해는 몇 년? (숫자만) "))age = this_year - birth_yearprint(f"{name}님은 올해 {age}번째 생일을 맞아요.")
②실행하고 확인 마지막 줄 적기
  • 몇 번째 생일인지 숫자로 나왔어요.

단계 2 살아온 날과 시간 계산하기

📌 목표: 나이로 살아온 날, 시간, 심장이 뛴 횟수를 계산한다.
🧰 계산 기호: * / //

*는 곱하기, /는 나누기(소수까지), //는 나누기의 몫만이에요.

print(7 * 24)print(17 / 5)print(17 // 5)

→ 168, 3.4, 3

②실행하고 확인 살아온 날(일) 숫자 하나만 적기

단계 3 인생 숫자 뽑기

📌 목표: 태어난 해·달·날로 1~9 중 하나인 인생 숫자를 만든다.
🧰 나머지: %

나누고 남은 수를 알려 줘요. 9로 나눈 나머지는 0~8 중 하나예요.

print(20 % 9)print(27 % 9)

→ 2, 0

①기능 추가하기 mini_starter.py의 # 단계 3 아래에 입력
birth_month = int(input("태어난 달 (1~12): "))birth_day = int(input("태어난 날 (1~31): "))life_number = (birth_year + birth_month + birth_day) % 9 + 1print(f"{name}님의 인생 숫자는 {life_number}!")
②실행하고 확인 내 인생 숫자 적기

단계 4 인생 숫자 뜻 알려 주기

📌 목표: 인생 숫자 크기에 따라 다른 타입을 보여 준다.
🧰 크기 비교: <=

<=는 "작거나 같다"예요. if와 함께 써요. (< 작다, >= 크거나 같다)

score = 85if score >= 80:    print("통과")

→ 통과

🚀 도전 프로젝트 내가 태어난 요일 계산기 · 일찍 끝낸 사람

왜 만들까? 달력 앱도 공식으로 요일을 계산해요. 나머지(%)가 "7일마다 돌아오는 요일"을 어떻게 만드는지 직접 확인하는 연습이에요.

📌 목표: h 값(0~6)을 요일 이름으로 바꿔 내가 태어난 요일을 보여 준다.
🧰 돌고 도는 수: % 7

요일은 7일마다 돌아와요. 7로 나눈 나머지(0~6)가 요일 번호가 돼요.

print(10 % 7)print(17 % 7)

→ 둘 다 3 (7일 지나면 같은 요일)
