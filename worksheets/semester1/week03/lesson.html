🧰 도구 카드 · 글자를 숫자로: int()

input()으로 받은 대답은 늘 글자예요. 계산하려면 int()로 감싸서 숫자로 바꿔요.

height = int(input("키는? "))print(height + 10)

→ 140을 넣으면 150

🧰 도구 카드 · 글자 속에 상자 넣기: f-string

따옴표 앞에 f를 붙이면 { } 안에 상자나 계산을 바로 넣을 수 있어요. 숫자도 OK!

cats = 3print(f"고양이가 {cats}마리, 다리는 {cats * 4}개")

→ 고양이가 3마리, 다리는 12개

⌨️ 따라 쓸 코드
print("🔢 인생 숫자 계산기 🔢")name = input("이름: ")birth_year = int(input("태어난 해 (예: 2015): "))this_year = int(input("올해는 몇 년? "))age = this_year - birth_yearprint(f"{name}님은 올해 {age}번째 생일을 맞아요.")
▶️ 실행하고 확인
  • 올해 몇 번째 생일인지 숫자로 계산되어 나왔어요.

🧰 도구 카드 · 계산 기호: + - * / //

*는 곱하기, /는 나누기(소수로), //는 나누기의 몫만이에요.

print(7 * 24)print(17 / 5)print(17 // 5)

→ 168, 3.4, 3

🧰 도구 카드 · 나머지: %

나누고 남은 수를 알려 줘요. 9로 나눈 나머지는 언제나 0~8 중 하나예요.

print(20 % 9)print(27 % 9)

→ 2, 0

⌨️ 따라 쓸 코드
birth_month = int(input("태어난 달 (1~12): "))birth_day = int(input("태어난 날 (1~31): "))life_number = (birth_year + birth_month + birth_day) % 9 + 1print(f"✨ {name}님의 인생 숫자는 {life_number}!")
▶️ 실행하고 확인

🧰 도구 카드 · 크기 비교: < > <= >= == !=

<=는 "작거나 같다", !=는 "같지 않다"예요. if와 함께 써요.

score = 85if score >= 80:    print("훌륭해요!")

→ 훌륭해요!

🧰 도구 카드 · 돌고 도는 수: % 7

요일은 7일마다 돌아와요. 7로 나눈 나머지(0~6)가 요일 번호가 돼요.

print(10 % 7)print(17 % 7)

→ 둘 다 3 (7일 지나면 같은 요일)

날짜h 값 (실행 결과)요일

  • 내 생일을 넣어 요일을 확인했어요.

몫은 age // 10, 나머지는 age % 10이에요. 11이면 1번의 10년과 1년.

left = (100 - age) * 365print(f"🎂 100살까지 약 {left}일 남았어요.")
