## 📇 개념 카드

### 카드 1. int()와 type(): 글자를 숫자로

`input()`은 항상 글자(str)를 줘요. 계산하려면 `int()`로 정수(int)로 바꿔야 해요.

```python
age = input("나이: ")
print(type(age))        # <class 'str'>
age = int(age)
print(type(age))        # <class 'int'>
print(age + 1)
```

✋ **직접 해 보기:** `int(input("나이: "))`처럼 한 줄로 줄여 보세요.

### 카드 2. 산술 연산자

| 기호 | 뜻 | 예 | 결과 |
| --- | --- | --- | --- |
| `+ - *` | 더하기, 빼기, 곱하기 | `7 * 3` | `21` |
| `/` | 나누기 (소수점까지) | `7 / 2` | `3.5` |
| `//` | 몫 | `7 // 2` | `3` |
| `%` | 나머지 | `7 % 2` | `1` |

```python
candy = 17
print(candy // 5)   # 5명에게 나누면 한 명당 3개
print(candy % 5)    # 남는 사탕 2개
```

✋ **직접 해 보기:** `%`로 어떤 수가 짝수인지 알아내는 방법을 찾아보세요. (힌트: `% 2`)

### 카드 3. 비교 연산자

비교 결과로 조건을 만들어요. `==`는 같다, `!=`는 다르다예요.

```python
score = int(input("점수: "))
if score >= 90:
    print("최고예요!")
elif score != 0:
    print("잘했어요!")
```

✋ **직접 해 보기:** `<`, `<=`, `>`를 써서 키가 140 미만인지 검사해 보세요.

### 카드 4. f-string: 문장 안에 변수 넣기

따옴표 앞에 `f`를 붙이고 `{}` 안에 변수나 계산식을 넣어요. 숫자도 그대로 넣을 수 있어 `+`보다 편해요.

```python
name = "민지"
age = 12
print(f"{name}는 {age}살, 내년엔 {age + 1}살!")
```

✋ **직접 해 보기:** `print(name + "는 " + age + "살")`을 실행해서 오류를 확인하고 f-string으로 고쳐 보세요.

## 📅 확장 프로젝트 퀘스트: 내가 태어난 요일 계산기

`extension_starter.py`는 **젤러의 공식**으로 날짜의 요일을 계산해요. 지금은 토요일, 일요일만 알려 주고 나머지는 "평일"이라고만 해요. 공식은 그대로 두고 바꿔 보세요.

### 바꾸기 (완성 기준)

- [ ] `h` 값 0~6에 맞춰 요일 7개를 모두 출력해요.
- [ ] 결과를 `"2014년 5월 3일 토요일에 태어났어요!"`처럼 f-string으로 출력해요.
- [ ] 비교 연산자로 주말/평일을 판정해요.
- [ ] 달이 12보다 크거나 날이 31보다 크면 경고를 보여 줘요.
