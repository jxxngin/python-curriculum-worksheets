## 🎯 오늘의 미션

나는 지금까지 며칠을 살았을까? 심장은 몇 번이나 뛰었을까? 💓 태어난 날을 넣으면 놀라운 숫자들을 계산해 주고, 나만의 인생 숫자까지 뽑아 주는 계산기를 만들어 봐요.

완성하면 이렇게 돼요:

```
🔢 인생 숫자 계산기 🔢
이름: 하린
태어난 해 (예: 2015): 2015
올해는 몇 년? 2026
하린님은 올해 11번째 생일을 맞아요.
지금까지 약 4015일, 96360시간을 살았어요.
심장은 약 462528000번 뛰었어요! 💓
태어난 달 (1~12): 5
태어난 날 (1~31): 3
✨ 하린님의 인생 숫자는 8!
🔍 끝까지 파고드는 탐구자 타입!
```

## 🔧 워밍업

`warmup.py`를 실행하고 오류 3개를 고쳐요. (고장 난 강아지 나이 변환기 고치기)

## 🪜 단계 1: 나이 계산하기

> 🧰 **글자를 숫자로: int()**: input()으로 받은 대답은 늘 글자예요. 계산하려면 int()로 감싸서 숫자로 바꿔요.

> 🧰 **글자 속에 상자 넣기: f-string**: 따옴표 앞에 f를 붙이면 { } 안에 상자나 계산을 바로 넣을 수 있어요. 숫자도 OK!

`mini_starter.py`의 `# 단계 1` 아래에 이어 써요.

```python
print("🔢 인생 숫자 계산기 🔢")
name = input("이름: ")
birth_year = int(input("태어난 해 (예: 2015): "))
this_year = int(input("올해는 몇 년? "))
age = this_year - birth_year
print(f"{name}님은 올해 {age}번째 생일을 맞아요.")
```

✅ 올해 몇 번째 생일인지 숫자로 계산되어 나왔어요.

## 🪜 단계 2: 살아온 날과 시간 계산하기

> 🧰 **계산 기호: + - * / //**: *는 곱하기, /는 나누기(소수로), //는 나누기의 몫만이에요.

`mini_starter.py`의 `# 단계 2` 아래에 이어 써요.

```python
days = age * 365
hours = days * 24
heartbeats = hours * 60 * 80
print(f"지금까지 약 {days}일, {hours}시간을 살았어요.")
print(f"심장은 약 {heartbeats}번 뛰었어요! 💓")
```

✅ 살아온 날, 시간, 심장이 뛴 횟수가 나왔어요.

## 🪜 단계 3: 인생 숫자 뽑기

> 🧰 **나머지: %**: 나누고 남은 수를 알려 줘요. 9로 나눈 나머지는 언제나 0~8 중 하나예요.

`mini_starter.py`의 `# 단계 3` 아래에 이어 써요.

```python
birth_month = int(input("태어난 달 (1~12): "))
birth_day = int(input("태어난 날 (1~31): "))
life_number = (birth_year + birth_month + birth_day) % 9 + 1
print(f"✨ {name}님의 인생 숫자는 {life_number}!")
```

✅ 1~9 중 하나인 인생 숫자가 나왔어요.

## 🪜 단계 4: 인생 숫자 뜻 알려 주기

> 🧰 **크기 비교: &lt; &gt; &lt;= &gt;= == !=**: &lt;=는 "작거나 같다", !=는 "같지 않다"예요. if와 함께 써요.

`mini_starter.py`의 `# 단계 4` 아래에 이어 써요.

```python
if life_number <= 3:
    print("🔥 앞장서는 리더 타입!")
elif life_number <= 6:
    print("🤝 친구를 잘 챙기는 타입!")
else:
    print("🔍 끝까지 파고드는 탐구자 타입!")
```

✅ 인생 숫자에 따라 다른 타입이 나왔어요.

## ⭐ 내 것으로 바꾸기 (오늘의 완성 기준)

**★ 꼭 하기**

- [ ] 계산을 1개 더 만들어 f-string으로 보여 줬어요. (잠잔 시간, 먹은 끼니 등)
- [ ] 인생 숫자 타입 3가지를 내 말로 바꿨어요.
- [ ] //와 %로 "○번의 10년과 ○년"을 보여 줬어요.

**➕ 더 해 보기**

- [ ] 인생 숫자 뜻을 9개 모두 지었어요. (==와 elif)
- [ ] 100살이 되려면 며칠 남았는지 계산했어요.

## 💡 새로 만들기 (하고 싶은 사람)

- 100살까지 남은 날 계산기
- 친구와 나의 나이 차이 계산기 (누가 몇 살 많은지 비교)

## 🚀 도전 프로젝트: 내가 태어난 요일 계산기

나는 무슨 요일에 태어났을까? 📅 수학 공식(젤러의 공식)으로 요일을 계산해요. 공식은 이미 들어 있으니 바꾸지 말고, h 값을 요일 이름으로 바꾸는 부분부터 만들어요.

`extension_starter.py`를 실행해 보고 바꿔요.

- [ ] h가 0~6일 때 요일 7개를 모두 elif로 보여 줘요. (0은 토요일)
- [ ] 내 생일을 넣어 요일을 확인했어요.
- [ ] 결과를 f-string으로 꾸몄어요. (예: "2015년 5월 3일은 일요일")
