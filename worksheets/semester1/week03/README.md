## 🎯 오늘의 미션

태어난 해를 넣으면 살아온 날과 시간을 계산하고, 나만의 인생 숫자를 뽑아 주는 계산기를 만들어요.

**오늘의 목표**

- 대답을 숫자로 바꿔(`int()`) 계산할 수 있다.
- 계산 결과를 문장 속에 넣어(f-string) 보여 줄 수 있다.
- 나머지(`%`)와 크기 비교로 결과를 나눌 수 있다.

완성하면 이렇게 돼요:

```

이름: 하린
태어난 해 (숫자만, 예: 2015): 2015

태어난 달 (1~12): 5
태어난 날 (1~31): 3
하린님의 인생 숫자는 8!
끝까지 파고드는 탐구자 타입
```

📌 목표: 오류 메시지를 읽고 오류 3개를 고친다. (고장 난 강아지 나이 변환기 고치기)

## 🪜 단계 1: 나이 계산하기

📌 목표: 태어난 해와 올해를 숫자로 받아 나이를 계산한다.

> 🧰 **글자를 숫자로: int()**: `input()`으로 받은 대답은 늘 글자예요. 계산하려면 `int()`로 감싸서 숫자로 바꿔요.
>
> ```python
> height = int(input("키는? "))
> print(height + 10)
> ```
> → 140을 넣으면 150

> 🧰 **문장 속에 상자 넣기: f-string**: 따옴표 앞에 `f`를 붙이면 `{ }` 안에 상자나 계산을 넣을 수 있어요. 숫자도 바로 들어가요.
>
> ```python
> cats = 3
> print(f"고양이 {cats}마리, 다리 {cats * 4}개")
> ```
> → 고양이 3마리, 다리 12개

① 기능 추가하기: `mini_starter.py`의 `# 단계 1` 아래에 입력

```python
print("인생 숫자 계산기")
name = input("이름: ")
birth_year = int(input("태어난 해 (숫자만, 예: 2015): "))
this_year = int(input("올해는 몇 년? (숫자만) "))
age = this_year - birth_year
print(f"{name}님은 올해 {age}번째 생일을 맞아요.")
```

② 실행하고 확인: 마지막 줄 적기

✅ 몇 번째 생일인지 숫자로 나왔어요.

## 🪜 단계 2: 살아온 날과 시간 계산하기

📌 목표: 나이로 살아온 날, 시간, 심장이 뛴 횟수를 계산한다.

> 🧰 **계산 기호: * / //**: `*`는 곱하기, `/`는 나누기(소수까지), `//`는 나누기의 몫만이에요.
>
> ```python
> print(7 * 24)
> print(17 / 5)
> print(17 // 5)
> ```
> → 168, 3.4, 3

① 기능 추가하기: `mini_starter.py`의 `# 단계 2` 아래에 입력

```python
days = age * 365
hours = days * 24
heartbeats = hours * 60 * 80
print(f"지금까지 약 {days}일, {hours}시간을 살았어요.")
print(f"심장은 약 {heartbeats}번 뛰었어요!")
```

② 실행하고 확인: 살아온 날(일) 숫자 하나만 적기

✅ 살아온 날, 시간, 심장이 뛴 횟수가 나왔어요.

## 🪜 단계 3: 인생 숫자 뽑기

📌 목표: 태어난 해·달·날로 1~9 중 하나인 인생 숫자를 만든다.

> 🧰 **나머지: %**: 나누고 남은 수를 알려 줘요. 9로 나눈 나머지는 0~8 중 하나예요.
>
> ```python
> print(20 % 9)
> print(27 % 9)
> ```
> → 2, 0

① 기능 추가하기: `mini_starter.py`의 `# 단계 3` 아래에 입력

```python
birth_month = int(input("태어난 달 (1~12): "))
birth_day = int(input("태어난 날 (1~31): "))
life_number = (birth_year + birth_month + birth_day) % 9 + 1
print(f"{name}님의 인생 숫자는 {life_number}!")
```

② 실행하고 확인: 내 인생 숫자 적기

✅ 1~9 중 하나인 인생 숫자가 나왔어요.

## 🪜 단계 4: 인생 숫자 뜻 알려 주기

📌 목표: 인생 숫자 크기에 따라 다른 타입을 보여 준다.

> 🧰 **크기 비교: <=**: `<=`는 "작거나 같다"예요. `if`와 함께 써요. (`<` 작다, `>=` 크거나 같다)
>
> ```python
> score = 85
> if score >= 80:
>     print("통과")
> ```
> → 통과

① 기능 추가하기: `mini_starter.py`의 `# 단계 4` 아래에 입력

```python
if life_number <= 3:
    print("앞장서는 리더 타입")
elif life_number <= 6:
    print("친구를 잘 챙기는 타입")
else:
    print("끝까지 파고드는 탐구자 타입")
```

② 실행하고 확인: 나온 타입 적기

✅ 인생 숫자에 따라 다른 타입이 나왔어요.

③ 따라가기: 지우 / 2014 / 2026 / 12 / 25를 넣으면 상자 속에는? (`print(type(age))`를 넣어 확인해도 돼요)

## 🚀 도전 프로젝트: 내가 태어난 요일 계산기

**왜 만들까?** 달력 앱도 공식으로 요일을 계산해요. 나머지(%)가 "7일마다 돌아오는 요일"을 어떻게 만드는지 직접 확인하는 연습이에요.

📌 목표: h 값(0~6)을 요일 이름으로 바꿔 내가 태어난 요일을 보여 준다.

> 🧰 **돌고 도는 수: % 7**: 요일은 7일마다 돌아와요. 7로 나눈 나머지(0~6)가 요일 번호가 돼요.

① 실행해 보기: `extension_starter.py`를 그대로 실행

② 기록하기: 표의 날짜를 넣어 실행하고 h 값과 요일 적기

공식(젤러의 공식)은 이미 들어 있어요. 공식은 바꾸지 않아요.

| 날짜 | h 값 (실행 결과) | 요일 |
| --- | --- | --- |
| 2015년 5월 3일 |   |   |
| 내 생일: |   |   |
| 가족이나 친구 생일: |   |   |

③ 바꾸고 체크하기

- [ ] h가 0~6일 때 요일 7개를 모두 `elif`로 보여 줘요. (0은 토요일)
- [ ] 내 생일을 넣어 요일을 확인했어요.
- [ ] 결과를 f-string으로 보여 줘요. (예: "2015년 5월 3일: 일요일")

**➕ 더 해 보기**

- 주말에 태어났으면 특별한 메시지 (비교 기호 `h < 2`)
- 달이 12보다 크면 안내하기
- 올해 내 생일 요일도 알려 주기
