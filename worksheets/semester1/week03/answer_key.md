# 3주차 교안 정답지: 인생 숫자 계산기

교사용. `lesson.html`의 블록 순서대로 정리했다. 실행 결과는 `mini_solution.py`를 실제로 실행해 확인했다.

## 🎯 미션

"완성하면 이렇게 돼요"는 하린 / 2015 / 2026 / 5 / 3를 넣고 실행한 화면이다.

## 🔧 워밍업 (고장 난 강아지 나이 변환기 고치기)

| 줄 | 오류 이름 | 고친 방법 |
| --- | --- | --- |
| 15 | SyntaxError (`unterminated string literal (detected at line 15)`) | 줄 끝에 닫는 따옴표: `...살이 돼요.")` |
| 7 | 메시지 없음 (3을 넣으면 사람 나이가 `3333333`, 12번 줄 type이 `<class 'str'>`) | `dog_age = int(input("강아지 나이(살): "))` |
| 14 | TypeError (`can only concatenate str (not "int") to str`) | f-string으로: `print(f"{dog_name}는 사람 나이로 {human_age}살이에요!")` |

- 15번 SyntaxError를 먼저 고쳐야 실행된다. 실행하면 9번 줄이 `<class 'str'>`를 보여 주고, 14번 줄이 `3333333살`을 출력한 뒤 15번 줄에서 TypeError가 난다(7번이 원인). 7번을 int()로 고치면 이번에는 14번 줄에서 TypeError가 난다. 오류 순서: 15 → 7 → 14. (실행해 확인함, 입력 초코 / 3)

## 🪜 단계 1 · 나이 계산하기

- 실행하고 확인: 예시 입력(하린 / 2015 / 2026)이면 `하린님은 올해 11번째 생일을 맞아요.` (실행해 확인함)

## 🪜 단계 2 · 살아온 날과 시간 계산하기

- 실행하고 확인: 나이 11이면 `지금까지 약 4015일, 96360시간을 살았어요.` / `심장은 약 462528000번 뛰었어요! 💓` (실행해 확인함)

## 🪜 단계 3 · 인생 숫자 뽑기

- 실행하고 확인: 5 / 3을 넣으면 `✨ 하린님의 인생 숫자는 8!` (2015 + 5 + 3 = 2023, 2023 % 9 = 7, 7 + 1 = 8)

## 🪜 단계 4 · 인생 숫자 뜻 알려 주기

- 실행하고 확인: 인생 숫자 8이면 `🔍 끝까지 파고드는 탐구자 타입!` (1~3 리더, 4~6 친구, 7~9 탐구자)

**따라가기** (하린 / 2015 / 2026 / 5 / 3을 넣었다면 상자 속에는? (print(type(age))를 넣어 확인해도 돼요), 실행해 확인함)

| age | days | type(age) | life_number |

## ⭐ 내 것으로 바꾸기

- "○번의 10년과 ○년"은 `age // 10`, `age % 10`. 11이면 1번의 10년과 1년. 예시는 `mini_solution.py` 맨 아래 주석. 계산 결과는 윤년·생일이 지났는지를 무시한 어림값이라 "약"을 붙인다. 심박수 80은 어린이 안정 시 심박수(대략 1분에 70~110번) 안의 어림값이다.
- 완성 기준은 ★ 꼭 하기 3개다. 더 해 보기는 평가에 넣지 않는다.

## 🚀 도전 프로젝트 (내가 태어난 요일 계산기)

- 예시 답안은 `extension_solution.py`. 표 첫 줄: 2015년 5월 3일 → h = 1, 일요일 (`extension_starter.py`에 2015 / 5 / 3을 넣어 실행해 확인함, 실제 달력도 일요일). h는 0=토, 1=일, 2=월, 3=화, 4=수, 5=목, 6=금. 2026년 11월 4일을 넣으면 h = 4(수요일)로 확인할 수 있다.
