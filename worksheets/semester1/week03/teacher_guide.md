# 3주차 교사 가이드: 인생 숫자 계산기

## 수업 목표

- int()로 형 변환하고, type()으로 str/int를 구별한다.
- 산술 연산자(+ - * / // %)와 비교 연산자(< > <= >= == !=)를 사용한다.
- f-string으로 출력한다.

## 110분 시간 배분

교안: `lesson.html`. 시간은 기준 기본값(15/40/10/30/15분, ±5분)을 따른다.

| 시간 | 활동 | 비고 |
| --- | --- | --- |

| 15~55분 | 단계 1~4 따라 쓰기 (도구 카드는 필요한 순간에 짧게) | // 와 % 는 사탕 나누기로 구체물 비유. 단계 4 뒤 따라가기 표 |

## 핵심 설명 포인트

- 워밍업 `"3" * 7`이 `"3333333"`이 되는 현상이 str/int 차이를 보여 주는 가장 좋은 장면이다. 웃음이 나오는 지점에서 type()을 보여 준다.
- `/`는 항상 소수(float)를 돌려준다(`6 / 2` → `3.0`). 몫이 필요하면 `//`. float는 이름만 소개하고 깊이 다루지 않는다.
- `%`는 짝수·홀수, 요일 계산(7로 나눈 나머지), 인생 숫자(9로 나눈 나머지)처럼 "돌고 도는 수"에 쓴다고 연결한다.
- str()은 3학기 개념이므로 글자+숫자 출력은 f-string으로 해결한다.
- 이번 주는 while, 리스트, import를 쓰지 않는다. 범위 검사도 and/or 없이 if를 여러 번 써서 처리한다(and/or는 6주).
- 도전: 젤러의 공식은 원리를 증명하지 않는다. "1·2월을 지난해 13·14월로 본다", "k는 뒤 두 자리, j는 앞 두 자리"를 `%`·`//`로 확인시키는 정도면 충분하다. 공식 h값은 0=토요일부터 시작한다는 점을 주의시킨다.
- 인생 숫자 계산식은 재미용이며 근거가 없다는 점을 가볍게 짚는다.
- 단계 1의 나이는 `올해 - 태어난 해`라서 "올해 몇 번째 생일"로 표현했다(생일이 지났는지는 따지지 않는다). 살아온 날·시간도 윤년을 무시한 어림값이라 "약"을 붙인다.
- 따라가기 표의 `type(age)`는 `print(type(age))` 한 줄로 확인할 수 있다. 워밍업에서 본 `<class 'str'>`과 비교해 int()가 한 일을 다시 짚는다.

## 자주 나오는 오류와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| `TypeError: can only concatenate str (not "int") to str` | 글자 + 숫자 | f-string 사용 |
| `TypeError: unsupported operand type(s) for -: 'int' and 'str'` | int() 누락 | input()을 int()로 감싸기 |
| `ValueError: invalid literal for int() with base 10: '12살'` | 숫자 외 글자 입력 | 숫자만 입력하도록 안내 (오류 처리는 3학기) |
| `int(input("나이: ")` 괄호 짝 오류 | 중첩 괄호 | 괄호 개수 세기 |
| f-string에서 `{}`가 그대로 출력 | `f` 누락 | 따옴표 앞 `f` 확인 |
| 결과가 `3.0`처럼 소수 | `/` 사용 | `//`로 바꿀지 판단 |

## 워밍업 정답

1. 7번째 줄: `dog_age = input(...)` → `dog_age = int(input(...))` (메시지 없음, `"3" * 7` → `"3333333"` 논리 오류)
2. 14번째 줄: 1번을 고치면 `TypeError`(글자 + 숫자) 발생 → `print(f"{dog_name}는 사람 나이로 {human_age}살이에요!")`
3. 15번째 줄: f-string 닫는 따옴표 누락(SyntaxError) → `...{human_age + 7}살이 돼요.")`

SyntaxError인 3번이 가장 먼저 보이고, 그다음 실행하며 1번(이상한 값), 2번(TypeError) 순서로 발견된다.

## 단계별 확인

단계마다 실행 결과와 따라가기 답은 `answer_key.md`에 있다. 단계 1의 `int(input(...))`은 괄호가 두 번 닫혀서 괄호 짝 오류가 가장 많다. 단계 3의 덧셈 괄호를 빼면 `% 9`가 `birth_day`에만 걸려 숫자가 달라진다(오류 메시지 없음).

## 진도 차이 대응

- 빠른 학생: 새로 만들기(100살까지 남은 날, 나이 차이) → 🚀 도전(태어난 요일). 도전에서 올해 생일 요일까지 계산하려면 공식 부분을 복사·수정하다가 변수 이름이 겹치기 쉬우므로 `print(h, h2)`로 값을 확인하게 한다.
- 느린 학생: int() 변환과 f-string 출력까지 성공하면, ★ 꼭 하기 중 새 계산 1개 + 인생 숫자 타입 바꾸기를 최소 목표로.
- 숫자 입력에 글자를 넣어 ValueError가 나는 학생이 많다. "숫자만 입력"을 질문 문구에 써 두게 한다.
