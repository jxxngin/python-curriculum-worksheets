## 핵심 설명 포인트

- 모듈 = 블록 코딩의 "확장 기능 추가"와 같다. import는 파일 맨 위에 쓰는 것이 약속.
- `random.randint(1, 3)`은 1, 2, 3 모두 나온다(range와 달리 끝 포함). 2학기 range()와 헷갈리기 쉬우므로 지금 분명히 해 둔다.
- abs()는 "차이가 얼마인지"만 알고 싶을 때 쓴다. 비밀번호 게임에서 `guess - secret`이 음수가 되는 경우를 먼저 보여 주고 abs()로 해결.
- 아직 while을 배우지 않았으므로 기회는 한 번씩, 관문을 순서대로 이어 붙이는 구조로 만든다. "여러 번 기회를 주고 싶다"는 요구가 나오면 7주 while 예고로 활용.
- 도전: 원의 넓이 = π × r². 지름을 반지름으로 바꾸는 것(`/ 2`)을 빼먹는 실수가 잦다. 지름이 2배면 넓이는 4배라는 점이 가성비 차이의 핵심.
- **round() 주의점**: 파이썬 round()는 끝자리가 5일 때 짝수 쪽으로 맞춘다(round(2.5) → 2, round(3.5) → 4). 학교에서 배우는 사사오입과 다르다. 피자 넓이·가격 계산에서 결과가 1 차이 나는 이유를 묻는 학생이 있으면 탐구 거리로 쓴다. (소수 자리 반올림은 컴퓨터 내부 소수 표현 때문에 더 예측하기 어려울 수 있다는 정도만 언급)
- 보완 메모 반영: 도전 더 해 보기에 오늘의 할인 쿠폰(random)과 두 피자의 가격 차이(abs()) 포함.

## 자주 나오는 오류와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| `NameError: name 'random' is not defined` | import 누락 | 맨 위에 `import random` |
| `AttributeError: module 'random' has no attribute 'randInt'` | 대소문자·철자 | `randint` 소문자 |
| 파일 이름을 `random.py`로 저장 | 내 파일이 모듈을 가린다 | 파일 이름을 바꾸고 같은 폴더의 `random.py`도 삭제 |
| `TypeError: randint() missing 1 required positional argument` | 인자 하나만 씀 | `randint(1, 3)`처럼 두 개 |
| 정답인데 꽝 | `int()` 없이 문자열과 숫자 비교 | input을 int()로 감싸기 |
| 넓이가 4배 크게 나옴 | 지름을 반지름처럼 사용 | `size / 2` |

## 워밍업 정답

1. 맨 위에 `import random` 추가 (NameError)
2. 8번째 줄: `random.randInt` → `random.randint` (AttributeError)
3. 13번째 줄: `{abs(dice1 - dice2}` → `{abs(dice1 - dice2)}` (SyntaxError, 가장 먼저 보고됨)
