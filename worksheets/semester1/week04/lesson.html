🧰 도구 카드 · 도구 상자 꺼내기: import

파이썬에 들어 있는 도구 상자를 꺼내 써요. 맨 위에 한 번만!

import random

→ random 도구 상자를 쓸 수 있어요

🧰 도구 카드 · 무작위 뽑기: random.randint(a, b)

a부터 b까지 중 하나를 뽑아요. b도 나와요!

dice = random.randint(1, 6)print(dice)

→ 1~6 중 하나 (실행할 때마다 달라요)

⌨️ 따라 쓸 코드
import randomname = input("탐험가 이름: ")score = 0treasure_door = random.randint(1, 3)print(f"(쉿! 테스트용) 보물은 {treasure_door}번 문")

🧰 도구 카드 · 거리 재기: abs()

두 수가 얼마나 떨어져 있는지 알려 줘요. 누가 더 커도 0 이상이 나와요.

print(abs(9 - 12))print(abs(12 - 9))

→ 둘 다 3

⌨️ 따라 쓸 코드
secret = random.randint(1, 20)guess = int(input("[2관문] 1~20 중 비밀번호는? "))gap = abs(guess - secret)print(f"비밀번호와 {gap}만큼 차이 나요!")
▶️ 실행하고 확인
  • 비밀번호와의 차이가 화면에 나왔어요. (음수가 아니에요!)

예) 용의 동굴 열쇠 고르기randint(1, 4)+15
★ 꼭 하기 (이 3개를 하면 완성!)

  • random.randint()를 쓰는 새 관문을 1개 더 만들었어요.
  • 마지막에 점수에 따라 칭호가 나와요. (예: 30점 이상 "전설의 탐험가")
➕ 더 해 보기
  • 문 개수나 비밀번호 범위를 바꿔 난이도를 조절했어요.
  • abs()로 차이에 따라 "뜨거워요 / 따뜻해요 / 차가워요"를 알려 줘요.

📋 할 일

크기도 가격도 다른 두 피자, 어느 쪽이 더 이득일까요? 🍕 넓이 1cm²당 가격으로 비교해요. 실행하기 전에 어느 쪽이 이득일지 먼저 예상해 봐요.

🧰 도구 카드 · 새 도구 4가지

math.pi 원주율 · pow(5, 2) 제곱 · round(3.146, 2) 반올림 · max(3, 8) 더 큰 값

import mathprint(round(math.pi * pow(10, 2), 1))

→ 314.2 (반지름 10cm 원의 넓이)

내 예상: 피자가 이득 → 실행 결과: 피자가 이득

  • 피자 이름도 물어봐서 결과에 이름이 나와요.
  • max()로 더 큰 피자를 알려 줘요.
  • 실제 메뉴(지름, 가격)를 넣어 확인했어요.
➕ 더 해 보기
  • 오늘의 할인 쿠폰: random으로 10%·20%·30% 중 하나를 뽑아 한 피자에 적용
  • 두 피자의 가격 차이를 abs()로 보여 주기
  • 지름이 2배면 넓이는 몇 배인지 pow()로 확인

🃏 힌트 카드 막히면 1번부터 차례로
