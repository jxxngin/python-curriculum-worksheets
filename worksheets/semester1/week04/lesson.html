🚀 도전 프로젝트 피자 가성비 계산기 · 일찍 끝낸 사람

왜 만들까? 크기와 가격이 다른 물건 중 무엇이 이득인지 따질 때 쓰는 계산이에요. 넓이 1cm²당 가격으로 비교하는 방법을 연습해요.

📌 목표: 두 피자의 1cm²당 가격을 계산해 어느 쪽이 이득인지 보여 준다.
🧰 원의 넓이: math.pi, pow()

math.pi는 원주율(3.14…), pow(5, 2)는 5의 제곱(25)이에요. 넓이 = 원주율 × 반지름의 제곱.

import mathprint(math.pi * pow(10, 2))

→ 314.159… (반지름 10cm 원의 넓이)

🧰 결과 다듬기: round(), max()

round(3.146, 2)는 소수 둘째 자리까지 반올림(3.15), max(3, 8)은 더 큰 값(8)이에요.

print(round(314.159, 1))print(max(30, 25))

→ 314.2, 30

새로 만들기함정 문 만들기 · 무엇부터 할지 모를 때●○○

함정 문 번호를 무작위로 뽑고, 고른 문이 함정이면 점수를 빼요. 1관문과 모양이 같아요.

새로 만들기함정 문 만들기 · 쓸 도구가 떠오르지 않을 때●●○

새 상자 두 개: trap(함정 문 번호, random.randint()), pick3(고른 문, int(input())). 걸리면 score = score - 5.

새로 만들기함정 문 만들기 · 거의 다 됐는데 안 될 때●●●

점수를 보여 주는 마지막 두 줄(비밀번호:, 점수:) 위에 넣어요. 아래에 넣으면 점수에 반영되지 않아요.

trap = random.randint(1, 3)pick3 = int(input("[함정] 문 번호: "))if pick3 == trap:    print("함정! -5점")    score = score - 5
도전할인 쿠폰 · 무엇부터 할지 모를 때●○○

할인율을 무작위로 뽑고, 가격에서 할인액을 빼요. 넓이를 계산하기 전에 가격을 바꿔야 결과에 반영돼요.

도전할인 쿠폰 · 쓸 도구가 떠오르지 않을 때●●○

import random을 파일 맨 위에 더해요. 새 상자: coupon(할인율, random.randint(1, 3) * 10), cut(할인액, price_a * coupon // 100).

도전할인 쿠폰 · 거의 다 됐는데 안 될 때●●●

맨 위에 import random을 쓰고, 가격을 물어본 줄(price_b = …) 아래에 넣어요.

coupon = random.randint(1, 3) * 10cut = price_a * coupon // 100price_a = price_a - cutprint(f"A 피자 {coupon}% 할인: {price_a}원")
