## 1쪽 · 워밍업 (주사위 굴리기)

| 줄 | 오류 이름 | 고친 방법 |
| --- | --- | --- |
| 7 | NameError (`name 'random' is not defined`) | 맨 위에 `import random` 추가 |
| 8 | AttributeError (`module 'random' has no attribute 'randInt'`) | `randInt` → `randint` (대소문자) |
| 13 | SyntaxError (괄호 짝) | `{abs(dice1 - dice2)}`처럼 `)` 추가 |

**디버거 미션:** 값은 실행할 때마다 다르다(1~6).
- 확인할 점: "차이"는 abs() 때문에 dice1이 더 작아도 음수가 나오지 않는다. 마지막 빈칸의 답은 "아니요"다.

## 2쪽 · 개념 카드

| 카드 | 예상 실행 화면 |
| --- | --- |
| 1 | `3.141592653589793` / `원주율이에요!` |
| 2 | dice: 1, 2, 3, 4, 5, 6 중 하나 / coin: 1 또는 2 (coin은 출력하지 않는다) |
| 3 | `7` / `7` / `7` |
| 4 | `차이 3` |

**직접 해 보기 (예시)**

```python
my = int(input("내 키: "))
friend = int(input("친구 키: "))
print(f"우리 키 차이는 {abs(my - friend)}cm예요")
```

**생각해 보기:** 3도 나올 수 있다. randint(a, b)는 b도 포함한다.

## 3쪽 · 미니 프로젝트

**따라 하기 빈칸:** ① `import` ② `randint` ③ `abs` ④ `<=`

**실행 기록:** 실행마다 보물 문(1~3)과 비밀번호(1~20)가 바뀌면 된다.

## 4쪽 · 2단계 바꾸기

학생마다 다르다. 확인할 점은 다음과 같다.
- 새 관문에 `random.randint()`를 썼는가
- 칭호 기준이 큰 점수부터 `if/elif` 순서로 되어 있는가 (예: `if score >= 30` → `elif score >= 15` → `else`)

## 5쪽 · 확장 프로젝트 (피자 가성비)

- 1cm²당 가격 = 가격 ÷ (math.pi × 반지름²). 지름 30cm, 20,000원이면 넓이 ≈ 706.86cm², 1cm²당 ≈ 28.29원이다.
- 지름이 2배가 되면 넓이는 **4배**다. 확인: `pow(2, 2)` → 4
- 쿠폰 문장 예: `오늘의 쿠폰: 20% 할인! 18000원`
- round()는 끝자리가 5일 때 짝수 쪽으로 맞춘다(`round(2.5)` → 2). 학생이 물으면 탐구 거리로 쓴다.
