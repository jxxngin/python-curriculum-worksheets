## 📇 개념 카드

### 카드 1. import: 도구 상자 가져오기

파이썬에는 미리 만들어 둔 기능 묶음(모듈)이 있어요. 맨 위에 `import 모듈이름`을 쓰면 `모듈이름.기능()`으로 쓸 수 있어요.

```python
import random
import math
print(math.pi)    # 원주율 3.14159...
```

✋ **직접 해 보기:** `import math` 줄을 지우고 실행하면 어떤 오류가 나는지 확인해 보세요.

### 카드 2. random.randint(): 무작위 정수

`random.randint(a, b)`는 a부터 b까지(b도 포함!) 정수 하나를 무작위로 뽑아요.

```python
import random
dice = random.randint(1, 6)
print(f"주사위: {dice}")
coin = random.randint(1, 2)
print(f"동전(1=앞, 2=뒤): {coin}")
```

✋ **직접 해 보기:** 실행을 5번 해서 결과가 매번 바뀌는지 보세요. 1부터 100 사이 행운의 숫자도 뽑아 보세요.

### 카드 3. abs(): 거리 구하기

`abs()`는 절댓값, 즉 0에서 얼마나 떨어졌는지를 알려 줘요. 두 수의 **차이**를 구할 때 누가 큰지 몰라도 항상 양수가 나와요.

```python
print(abs(-7))       # 7
print(abs(3 - 10))   # 7
print(abs(10 - 3))   # 7
```

✋ **직접 해 보기:** 내 키와 친구 키를 입력받아 키 차이를 출력해 보세요.

## 🍕 확장 프로젝트 퀘스트: 피자 가성비 계산기

> 중고등학생은 미니 1단계 후 이 퀘스트가 **오늘의 완성 기준**이에요. 초등학생은 미니를 마친 뒤 선택해요.

`extension_starter.py`는 피자 두 판의 지름과 가격으로 **1cm²당 가격**을 계산해서 어느 쪽이 이득인지 알려 줘요. 오늘은 새로운 도구도 써요.

| 도구 | 뜻 | 예 |
| --- | --- | --- |
| `math.pi` | 원주율 | `3.141592...` |
| `pow(a, b)` | a의 b제곱 | `pow(5, 2)` → `25` |
| `round(x, n)` | 소수 n째 자리까지 반올림 | `round(3.146, 2)` → `3.15` |
| `max(a, b)` | 더 큰 값 | `max(3, 8)` → `8` |

### 바꾸기 (완성 기준)

- [ ] 피자 이름도 입력받아 결과에 이름이 나와요.
- [ ] `max()`로 더 큰 피자를 찾아 알려 줘요.
- [ ] 먹을 사람 수를 받아 한 사람당 넓이를 계산했어요.
- [ ] 실제 피자 가게 메뉴(지름, 가격)를 넣어 확인해 봤어요.

### 새로 만들기 (선택)

- 💡 **오늘의 할인 쿠폰**: `random`으로 10%·20%·30% 중 하나를 뽑아 한 피자에 적용
- 💡 **두 피자의 가격 차이**를 `abs()`로 구해 출력
- 💡 지름이 2배가 되면 넓이는 몇 배인지 `pow()`로 확인해 보기

<details>
<summary>힌트 1 (방향)</summary>

쿠폰은 "무작위로 할인율 뽑기 → 가격에서 할인액 빼기"예요. 가성비를 계산하기 **전에** 가격을 바꿔야 결과에 반영돼요.

</details>

<details>
<summary>힌트 2 (사용할 함수)</summary>

`random.randint(1, 3) * 10`이면 10, 20, 30 중 하나가 나와요. 할인액은 `가격 * 할인율 // 100`, 차이는 `abs(price_a - price_b)`.

</details>

<details>
<summary>힌트 3 (거의 코드)</summary>

```python
import random
coupon = random.randint(1, 3) * 10
price_a = price_a - price_a * coupon // 100
print(f"🎟️ {coupon}% 할인! A 피자 {price_a}원")
diff = abs(price_a - price_b)
print(f"가격 차이: {diff}원")
```

</details>
