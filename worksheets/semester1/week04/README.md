## 🪜 단계 1: 보물 문을 무작위로 정하기

📌 목표: 실행할 때마다 보물 문 번호(1~3)를 새로 뽑는다.

> 🧰 **도구 상자 꺼내기: import**: 파이썬에 들어 있는 도구 상자를 꺼내 써요. 맨 위에 한 번만 써요.
>
> ```python
> import random
> ```
> → random 도구 상자를 쓸 수 있어요

> 🧰 **무작위 뽑기: random.randint(a, b)**: a부터 b까지 중 하나를 뽑아요. b도 나와요.
>
> ```python
> dice = random.randint(1, 6)
> print(dice)
> ```
> → 1~6 중 하나 (실행할 때마다 달라요)

① 기능 추가하기: `mini_starter.py`의 `# 단계 1` 아래에 입력

```python
import random
name = input("탐험가 이름: ")
score = 0
treasure_door = random.randint(1, 3)
print(f"(테스트용) 보물은 {treasure_door}번 문")
```

② 실행하고 확인: 3번 실행하고 보물 문 번호 적기

✅ 3번 모두 1~3 중 하나가 나왔어요. 같은 번호가 또 나와도 정상이에요. (매번 새로 뽑아요)

## 🪜 단계 2: 1관문: 문을 골라 보물 찾기

📌 목표: 고른 문이 보물 문이면 10점을 얻는다.

> 🧰 **점수 올리기: score = score + 10**: 오른쪽에서 지금 점수에 10을 더하고, 그 값을 다시 `score` 상자에 넣어요.
>
> ```python
> coins = 3
> coins = coins + 2
> print(coins)
> ```
> → 5

① 기능 추가하기: `mini_starter.py`의 `# 단계 2` 아래에 입력

```python
pick = int(input("[1관문] 몇 번 문을 열까요? (숫자만, 1~3): "))
if pick == treasure_door:
    print("보물을 찾았어요! +10점")
    score = score + 10
else:
    print(f"꽝! 보물은 {treasure_door}번 문")
```

② 실행하고 확인: 테스트용 줄을 보고 맞는 문과 틀린 문을 한 번씩 넣어 보고 나온 말 적기

✅ 맞히면 "보물을 찾았어요", 틀리면 "꽝!"이 나왔어요.

## 🪜 단계 3: 2관문: 비밀번호가 얼마나 가까운지 알려 주기

📌 목표: 비밀번호와 내가 넣은 수의 차이가 화면에 나온다.

> 🧰 **거리 재기: abs()**: 두 수가 얼마나 떨어져 있는지 알려 줘요. 누가 더 커도 0 이상이 나와요.
>
> ```python
> print(abs(9 - 12))
> print(abs(12 - 9))
> ```
> → 둘 다 3

① 기능 추가하기: `mini_starter.py`의 `# 단계 3` 아래에 입력

```python
secret = random.randint(1, 20)
guess = int(input("[2관문] 1~20 중 비밀번호는? (숫자만) "))
gap = abs(guess - secret)
print(f"비밀번호와 {gap}만큼 차이 나요.")
```

② 실행하고 확인: 나온 차이 숫자 적기

✅ 차이가 화면에 나왔어요. (음수가 아니에요)

## 🪜 단계 4: 점수를 주고 게임 끝내기

📌 목표: 차이에 따라 점수를 더하고 마지막 점수를 보여 준다.

① 기능 추가하기: `mini_starter.py`의 `# 단계 4` 아래에 입력

```python
if gap == 0:
    score = score + 20
elif gap <= 3:
    score = score + 5

```

② 실행하고 확인: 마지막 줄 적기. 다 되면 단계 1의 테스트용 `print` 줄 맨 앞에 `#`을 붙여 숨기기

✅ 마지막에 내 점수가 나왔어요. / 테스트용 줄을 #으로 숨겼어요.

## 🚀 도전 프로젝트: 피자 가성비 계산기

**왜 만들까?** 크기와 가격이 다른 물건 중 무엇이 이득인지 따질 때 쓰는 계산이에요. 넓이 1cm²당 가격으로 비교하는 방법을 연습해요.

📌 목표: 두 피자의 1cm²당 가격을 계산해 어느 쪽이 이득인지 보여 준다.

> 🧰 **원의 넓이: math.pi, pow()**: `math.pi`는 원주율(3.14…), `pow(5, 2)`는 5의 제곱(25)이에요. 넓이 = 원주율 × 반지름의 제곱.

> 🧰 **결과 다듬기: round(), max()**: `round(3.146, 2)`는 소수 둘째 자리까지 반올림(3.15), `max(3, 8)`은 더 큰 값(8)이에요.

① 실행해 보기: `extension_starter.py`를 그대로 실행

② 기록하기: 진짜 메뉴(전단지·배달 앱)를 보고 두 피자를 적고, 실행 전에 이득일 쪽 예상하기

|   | 피자 이름 | 지름(cm) | 가격(원) | 1cm²당 가격 (실행 결과) |
| --- | --- | --- | --- | --- |
| A |   |   |   |   |
| B |   |   |   |   |

내 예상: ____ 피자 → 실행 결과: ____ 피자

③ 바꾸고 체크하기

- [ ] 피자 이름도 물어봐서 결과에 이름이 나와요.
- [ ] `max()`로 더 큰 피자를 알려 줘요.
- [ ] 실제 메뉴(지름, 가격)를 넣어 확인했어요.

**➕ 더 해 보기**

- 오늘의 할인 쿠폰: random으로 10%·20%·30% 중 하나를 뽑아 한 피자에 적용
- 두 피자의 가격 차이를 `abs()`로 보여 주기
- 지름이 2배면 넓이는 몇 배인지 `pow()`로 확인

<summary>[단계 4] 점수가 늘 그대로일 때 ●○○</summary>

`if` → `elif` 순서인지, "3 이하"를 `<= 3`으로 썼는지, 점수를 `score = score + 5`처럼 다시 넣었는지 봐요.

</details>

<details>
<summary>[새로 만들기] 함정 문 만들기 · 무엇부터 할지 모를 때 ●○○</summary>

함정 문 번호를 무작위로 뽑고, 고른 문이 함정이면 점수를 빼요. 1관문과 모양이 같아요.

</details>

<details>
<summary>[새로 만들기] 함정 문 만들기 · 쓸 도구가 떠오르지 않을 때 ●●○</summary>

새 상자 두 개: `trap`(함정 문 번호, `random.randint()`), `pick3`(고른 문, `int(input())`). 걸리면 `score = score - 5`.

</details>

<details>
<summary>[새로 만들기] 함정 문 만들기 · 거의 다 됐는데 안 될 때 ●●●</summary>

점수를 보여 주는 마지막 두 줄(`비밀번호:`, `점수:`) 위에 넣어요. 아래에 넣으면 점수에 반영되지 않아요.

```python
trap = random.randint(1, 3)
pick3 = int(input("[함정] 문 번호: "))
if pick3 == trap:
    print("함정! -5점")
    score = score - 5
```

</details>

<details>
<summary>[도전] 할인 쿠폰 · 무엇부터 할지 모를 때 ●○○</summary>

할인율을 무작위로 뽑고, 가격에서 할인액을 빼요. 넓이를 계산하기 전에 가격을 바꿔야 결과에 반영돼요.

</details>

<details>
<summary>[도전] 할인 쿠폰 · 쓸 도구가 떠오르지 않을 때 ●●○</summary>

`import random`을 파일 맨 위에 더해요. 새 상자: `coupon`(할인율, `random.randint(1, 3) * 10`), `cut`(할인액, `price_a * coupon // 100`).

</details>

<details>
<summary>[도전] 할인 쿠폰 · 거의 다 됐는데 안 될 때 ●●●</summary>

맨 위에 `import random`을 쓰고, 가격을 물어본 줄(`price_b = …`) 아래에 넣어요.

```python
coupon = random.randint(1, 3) * 10
cut = price_a * coupon // 100
price_a = price_a - cut
print(f"A 피자 {coupon}% 할인: {price_a}원")
```

</details>
