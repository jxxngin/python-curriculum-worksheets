## 🪜 단계 2: 0을 넣을 때까지 계속 묻기

📌 목표: 메뉴 번호를 계속 묻다가 0을 넣으면 반복을 멈춘다.

> 🧰 **끝없이 되풀이하고 멈추기: while True, break**: `while True:` 아래 4칸 들여 쓴 줄을 끝없이 되풀이해요. `break`를 만나면 반복을 바로 빠져나가요.
>
> ```python
> while True:
>     word = input("암호: ")
>     if word == "참깨":
>         break
> ```
> → "참깨"를 넣을 때까지 계속 물어요

① 기능 추가하기: `mini_starter.py`의 `# 단계 2` 아래에 입력

```python
total = 0
while True:
    menu = input("메뉴 번호 (끝내려면 0): ").strip()
    if menu == "0":
        break
```

② 실행하고 확인: 표의 값을 차례로 넣고 어떻게 됐는지 적기

✅ 0을 넣기 전까지 계속 묻고, 0을 넣으니 끝났어요.

## 🪜 단계 3: 없는 번호 건너뛰기

📌 목표: 1, 2, 3이 아닌 번호를 넣으면 알려 주고 다시 묻는다.

> 🧰 **이번 차례 건너뛰기: continue**: `continue`를 만나면 아래 줄을 건너뛰고 반복의 처음으로 돌아가요.
>
> ```python
> n = 0
> while n < 4:
>     n = n + 1
>     if n == 2:
>         continue
>     print(n)
> ```
> → 1, 3, 4 (2는 건너뛰어요)

① 기능 추가하기: `mini_starter.py`의 `# 단계 3` 아래에 입력

```python
    if menu != "1" and menu != "2" and menu != "3":
        print("없는 번호예요. 다시 골라 주세요.")
        continue
```

② 실행하고 확인: 표의 값을 차례로 넣고 나온 말 적기 (나온 말이 없으면 "없음")

✅ 없는 번호를 넣으면 알려 주고 다시 물었어요.

## 🪜 단계 5: 합계 쌓고 결제 금액 보여 주기

📌 목표: 담을 때마다 합계에 가격을 더하고, 0을 넣으면 결제할 금액을 보여 준다.

> 🧰 **계속 쌓기: 누적 변수**: 반복 전에 0으로 만든 상자(단계 2의 `total = 0`)에, 반복 안에서 자기 자신을 더해 쌓아요.
>
> ```python
> coins = 500
> coins = coins + 100
> print(coins)
> ```
> → 600

① 기능 추가하기: `mini_starter.py`의 `# 단계 5` 아래에 입력

```python

    print(f"합계: {total}원")

```

② 실행하고 확인: 마지막 두 줄 적기

✅ 담을 때마다 합계가 늘고, 0을 넣으니 결제할 금액이 나왔어요.
