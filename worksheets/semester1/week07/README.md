## 📇 개념 카드

### 카드 1. while: 조건이 참인 동안 반복

조건을 검사해서 참이면 블록을 실행하고, 다시 위로 올라가 조건을 검사해요. 조건이 거짓이 되면 멈춰요.

```python
count = 1
while count <= 5:
    print(f"{count}번째 박수 👏")
    count = count + 1
print("끝!")
```

✋ **직접 해 보기:** 2, 4, 6, 8, 10만 출력되게 바꿔 보세요.

### 카드 2. break: 반복 탈출

`while True:`는 영원히 반복해요. 원하는 순간에 `break`로 빠져나와요.

```python
while True:
    word = input("암호를 말하세요: ").strip()
    if word == "열려라참깨":
        break
print("문이 열렸어요! 🚪")
```

✋ **직접 해 보기:** 틀릴 때마다 "땡!"이 나오게 해 보세요.

### 카드 3. continue: 이번 차례 건너뛰기

`continue`를 만나면 아래 줄을 실행하지 않고 바로 반복의 처음(조건 검사)으로 돌아가요.

```python
n = 0
while n < 10:
    n = n + 1
    if n % 3 == 0:
        continue
    print(n)      # 3, 6, 9는 출력되지 않아요
```

✋ **직접 해 보기:** 짝수만 건너뛰도록 바꿔 보세요.

### 카드 4. 누적 변수: 계속 쌓기

반복하기 **전에** 0으로 만들고, 반복 **안에서** 자기 자신에 더해요.

```python
total = 0
count = 0
while count < 3:
    total = total + int(input("점수: "))
    count = count + 1
print(f"합계 {total}점")
```

✋ **직접 해 보기:** 평균도 출력해 보세요. (`total // count`)
