# 7주차 교사 가이드: 편의점 키오스크

## 수업 목표

- while 반복문을 쓰고, 종료 조건을 설계한다.
- break/continue로 반복 흐름을 제어한다.
- 누적 변수(합계, 개수)를 초기화하고 갱신한다.

## 110분 시간 배분

| 시간 | 활동 | 비고 |
| --- | --- | --- |
| 0~12분 | 워밍업 + 무한 반복 멈추기(편집기 정지 버튼) 실습 | 멈추는 법을 먼저 알려 준다 |
| 12~40분 | 개념 카드 1~4 | 따라가기로 반복 흐름 시연 |
| 40~50분 | 쉬는 시간 | |
| 50~65분 | 미니 1단계 따라 하기 | |

| 98~106분 | 서로의 키오스크로 주문해 보기, 숫자 야구 대결 | |

## 핵심 설명 포인트

- 블록 코딩의 "~까지 반복하기"는 조건이 참이 될 때 멈추지만, 파이썬 while은 조건이 **참인 동안** 반복한다. 방향이 반대라서 자주 헷갈린다.
- 무한 반복은 오류가 아니라 "멈출 조건이 없음"이다. 반복 안에서 조건에 쓰이는 변수가 바뀌는지 확인하는 습관.
- `while True:` + `break` 패턴은 "언제 끝날지 모르는 입력 반복"에 쓴다. 횟수가 정해져 있으면 `while count < N:`.
- continue는 "아래를 건너뛰고 위로". 키오스크에서 잘못된 번호일 때 가격 누적을 건너뛰는 데 쓰는 것이 자연스러운 예다.
- 누적 변수는 반복 **밖에서** 0으로 초기화. 반복 안에서 초기화하면 매번 0으로 돌아간다.
- `+=` 같은 줄임 문법은 다루지 않는다(커리큘럼 기준상 제외 대상). `total = total + price`로 통일. 학생이 알고 있으면 같은 뜻이라고만 말해 준다.
- 숫자 야구(보완 메모): 서로 다른 세 자리 숫자 뽑기는 따라 하기 코드로 제공했다. 리스트 없이 변수 3개와 "겹치면 다시 뽑는 while"로 구현한다. 자리 나누기 `//`, `%`는 3주 복습.
- 독감 시뮬레이터: 접종자 면역, 1/3 회복, 마스크로 전파 감소 등은 모두 단순화한 모델이다. 실제 감염병 모델(SIR)의 맛보기라는 점, 숫자를 바꾸면 결과가 크게 달라진다는 점(예방의 효과)을 토론 거리로 쓴다.

## 자주 나오는 오류와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| 프로그램이 안 끝남 | 조건 변수 갱신 누락 | 정지 버튼으로 멈춘 뒤 반복 안의 갱신 줄 확인 |
| 한 번만 실행되고 끝남 | 갱신·break가 반복 밖/안 들여쓰기 잘못 | 들여쓰기 확인, 반복 안에 `print()` 넣어 추적 |
| 합계가 마지막 가격만 | 누적 변수를 반복 안에서 0으로 초기화 | 초기화는 반복 위로 |
| `NameError: name 'price'` | continue 없이 else 다음 줄로 진행 | else에서 continue |
| `SyntaxError: 'break' outside loop` | break 들여쓰기가 반복 밖 | 반복 블록 안으로 |
| `ValueError` (수량에 글자) | int() 변환 실패 | 숫자 입력 안내 (오류 처리는 3학기) |
| 숫자 야구 첫 자리 0 입력 | `012` → 12가 되어 세 자리 아님 | 범위 검사(100~999)로 안내 |

## 워밍업 정답

1. 8번째 줄: `while count > 0` → 끝에 `:` (SyntaxError)
2. 9번째 줄 아래에 `count = count - 1` 추가 (무한 반복, 메시지 없음)
3. 반복 전에 `total = 0` 추가 (12번째 줄 NameError). 예: 6번째 줄 아래에 `total = 0`

## 미니 따라 하기 정답

빈칸 1 `while`, 빈칸 2 `break`, 빈칸 3 `continue`, 빈칸 4 `total`
(빈칸 1~3은 키워드 자리라 빈칸 상태로는 SyntaxError가 나는 것이 정상이다.)

## 진도 차이 대응

- 빠른 학생: 미니 3단계(예산 모드) → 확장 둘 다 도전, 또는 네 자리 숫자 야구.
- 느린 학생: 따라 하기 + 메뉴 추가 + 수량 누적까지를 최소 목표로. 거스름돈 while은 힌트 3을 보고 따라 써도 된다.
- 중고등: 숫자 야구는 볼 판정 로직, 독감은 회복·접종 모델 설계가 핵심. 독감 선택 학생은 숫자를 바꿔 가며 결과를 비교하는 표를 만들게 하면 데이터 해석 활동이 된다.
- 8주 리스트를 배우면 키오스크의 "산 물건 목록"을 저장할 수 있다고 예고한다.
