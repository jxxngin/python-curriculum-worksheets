# 7주차 교사 가이드: 편의점 키오스크

## 수업 목표

- while로 같은 질문을 되풀이한다(`while True` + `break`).
- continue로 이번 차례를 건너뛴다.
- 누적 변수(반복 전에 0, 반복 안에서 더하기)로 합계를 낸다.
- (도전) 정해진 횟수 반복과 반복 안의 여러 조건으로 게임·시뮬레이션을 만든다.

## 핵심 설명 포인트

- 반복은 "조건 확인 → 실행 → 다시 위로"다. 블록 코딩의 "계속 반복하기"가 `while True:`, "~까지 반복하기"가 `while 조건:`과 비슷하다고 연결한다.
- `while True:`는 스스로 멈추지 않는다. `break`가 유일한 출구라는 점을 단계 2에서 확인한다.
- `continue`는 "아래를 건너뛰고 처음으로". 단계 3이 단계 4·5보다 위에 있어서, 없는 번호는 가격도 합계도 건드리지 않는다. 따라가기의 7번 바퀴가 이것을 보여 준다.
- 단계 3의 조건은 6주의 `and`를 다시 쓴다. `or`로 쓰면 늘 참이 되어 모든 번호가 "없는 번호"가 된다.
- 단계 4는 "기본값을 먼저 넣고, 아니면 바꾸기" 모양이다. 1번이면 `price = 1200` 그대로 간다.
- 누적 변수는 5주의 `score = score + 10`과 같은 모양이다. 새로운 점은 "반복 안에서 여러 번 쌓인다"는 것. `total = 0`을 반복 안으로 옮기면 어떻게 되는지 물어볼 수 있다(매번 0으로 돌아간다).
- 무한 반복은 오류 메시지가 없다. 화면이 멈추지 않는 것이 증상이다. 워밍업에서 "조건의 상자가 반복 안에서 바뀌는가?"를 습관으로 만든다.
- 도전 숫자 야구의 "서로 다른 세 자리 숫자 뽑기"는 커리큘럼 보완 메모대로 시작 파일에 따라 하기 코드로 주어져 있다. `while s2 == s1:`이 "겹치면 다시 뽑기"라는 것만 짚는다.
- 도전 독감 시뮬레이터는 단순화한 모형이다(접종하면 걸리지 않음, 하루 회복 1/3). 실제 감염병 모형은 더 복잡하다는 점과 예방 접종·마스크의 효과를 짧게 이야기한다.

## 자주 나오는 오류와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| 화면이 멈추지 않음 | 무한 반복 | 편집기의 정지 버튼으로 멈추고, 조건의 상자가 반복 안에서 바뀌는지 본다 |
| `SyntaxError: expected ':'` | `while`, `if` 줄 끝 `:` 빠짐 | 줄 끝에 `:` |
| `IndentationError` | 단계 3~5 줄을 4칸 들여 쓰지 않음 | `while` 안의 줄은 모두 4칸, `if` 안은 8칸 |
| 0을 넣어도 안 끝남 | `if menu == 0:`(따옴표 없음) | `input()`은 글자라서 `"0"`과 비교 |
| 모든 번호가 "없는 번호" | 단계 3 조건을 `or`로 씀 | `and`로 |
| 합계가 늘지 않음 | `total = 0`이 반복 안에도 있음 | 반복 전에 한 번만 |
| 결제 금액이 반복마다 나옴 | 마지막 두 줄을 4칸 들여 씀 | 반복이 끝난 뒤의 줄은 0칸 |

## 워밍업 정답

순서: 8번(SyntaxError) → 10번(NameError) → 무한 반복.

1. 8번째 줄: `while count > 0` → `while count > 0:` (SyntaxError, 실행 전에 나온다)
2. 10번째 줄: `seconds`가 없다 → 반복 전 7번 빈 줄에 `seconds = 0` (NameError, `10...`을 한 번 보여 준 뒤 나온다). 빈 줄에 넣으면 줄 번호가 밀리지 않는다.
3. 무한 반복: `10...`이 끝없이 나온다 → 11번 빈 줄에 `    count = count - 1` (힌트 블록의 `워밍업` 카드에 고치는 모양이 있다)

다 고치면 `10...`부터 `1...`까지, `🚀 발사!`, `걸린 시간: 10초`가 나온다.

## 단계별 확인

- 단계 1: 메뉴판 / 단계 2: 0을 넣을 때까지 계속 묻는다 / 단계 3: 없는 번호는 알려 주고 다시 묻는다 / 단계 4: 고른 메뉴의 가격 / 단계 5: 합계가 쌓이고 0을 넣으면 결제 금액. 자세한 답은 `answer_key.md`.

## 진도 차이 대응

- 빠른 학생: 새로 만들기(예산 모드, 1+1 행사) → 도전 프로젝트. 도전은 한 주제만 고르게 한다.
- 느린 학생: 단계 5까지 실행 + ★ 1~2개(메뉴 바꾸기·더하기, 개수 묻기)를 최소 목표로.
- 숫자 대신 글자를 넣으면 ValueError로 멈춘다(바꾸기의 개수, 거스름돈, 도전의 입력). 질문 문구의 "(숫자만)"을 가리키고 다시 실행하게 한다.
- 메뉴 번호는 `int()`로 바꾸지 않고 글자로 비교하므로 글자를 넣어도 오류가 나지 않는다. "없는 번호"로 처리된다.
- 독감 시작 파일에 옮기는 수로 0을 넣으면 끝나지 않는다. 질문의 "(1 이상)"을 가리키고, 무한 반복이 왜 생겼는지 워밍업과 연결한다.
- 인쇄: 양면 인쇄를 권장한다.
- 다음 주는 리스트. "메뉴를 한곳에 모아 두고 싶다"는 요구가 나오면 예고로 쓴다.
