# 7주차 워크시트 정답지: 편의점 키오스크

교사용. `worksheet.html`의 쪽 순서대로 정리했다.

## 1쪽 · 워밍업 (카운트다운 로켓)

| 줄 | 오류 이름 | 고친 방법 |
| --- | --- | --- |
| 8 | SyntaxError (`expected ':'`) | `while count > 0:` |
| 9 아래 | 메시지 없음 (10...이 끝없이 나온다) | 반복 안에 `count = count - 1` 추가 (들여쓰기) |
| 12 | NameError (`name 'total' is not defined`) | 반복 전에 `total = 0` |

- 무한 반복은 빨간 정지 버튼이나 Ctrl+F2로 멈춘다.

**디버거 미션** (누적 변수)

| 바퀴 | total | n | n <= 4 ? |
| --- | --- | --- | --- |
| 시작 전 | 0 | 1 | True |
| 1바퀴 뒤 | 1 | 2 | True |
| 2바퀴 뒤 | 3 | 3 | True |
| 3바퀴 뒤 | 6 | 4 | True |
| 4바퀴 뒤 | 10 | 5 | False |

- 마지막에 `10`이 출력된다.

## 2쪽 · 개념 카드

| 카드 | 예상 실행 화면 |
| --- | --- |
| 1 | `1번째 박수 👏` / `2번째 박수 👏` / `3번째 박수 👏` / `끝!` |
| 2 ("참깨" → "열려라참깨") | `암호: 참깨` / `암호: 열려라참깨` / `문이 열렸어요! 🚪` |
| 3 | `1` / `2` / `4` / `5` (3과 6은 건너뜀) |
| 4 (80, 90, 70) | `합계 240점` |

**직접 해 보기 (예시)**

```python
n = 2
while n <= 10:
    print(n)
    n = n + 2
```

**생각해 보기:** `total = 0`이 while 안에 있으면 바퀴마다 0으로 돌아가서 마지막 점수만 남는다(70). 누적 변수는 반복 전에 한 번만 0으로 만든다.

## 3쪽 · 미니 프로젝트

**따라 하기 빈칸:** ① `while` ② `break` ③ `continue` ④ `total`

**예상 실행 화면** (1 → 9 → 3 → 0, 빈칸을 채운 starter를 실행해 확인함)

```
메뉴 번호: 1
🛒 삼각김밥 담았어요! (현재 1개, 1200원)
메뉴 번호: 9
없는 번호예요. 다시 골라 주세요.
메뉴 번호: 3
🛒 컵라면 담았어요! (현재 2개, 3000원)
메뉴 번호: 0

🧾 총 2개, 결제 금액은 3000원입니다. 감사합니다!
```

- 9는 continue로 건너뛰므로 개수와 금액이 늘지 않는다.

**2단계 할인 예:** 10000원 이상이면 10% 할인 → `total = total - total // 10`
