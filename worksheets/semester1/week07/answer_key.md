# 7주차 교안 정답지: 편의점 키오스크

교사용. `lesson.html`의 블록 순서대로 정리했다. 실행 결과는 `mini_solution.py`를 제작 환경(Python 3.8)에서 실제로 실행해 확인했고, 이 코드들은 3.11에서도 결과가 같다. 오류 메시지는 수업 기준인 Python 3.11 문구로 적었다.

## 🎯 미션

"완성하면 이렇게 돼요"는 1 / 9 / 3 / 2 / 0를 넣고 실행한 화면이다.

## 🔧 워밍업 (고장 난 카운트다운 로켓 고치기)

| 나타나는 순서 | 줄 | 오류 이름 (실제 메시지) | 고친 방법 |
| --- | --- | --- | --- |
| 1 | 8 | SyntaxError (`expected ':'`) | `while count > 0:` |
| 2 | 10 | NameError (`name 'seconds' is not defined`) | 반복 전 7번 빈 줄에 `seconds = 0` |
| 3 | 8~10 | 메시지 없음 (무한 반복: `10...`이 끝없이 나온다) | 11번 빈 줄에 `    count = count - 1` (워밍업 힌트 카드) |

- SyntaxError(8번)는 실행 전에 나온다. 고치면 `10...`을 한 번 보여 준 뒤 10번에서 NameError가 난다. `seconds = 0`을 7번 빈 줄에 넣으면 줄 번호가 밀리지 않는다. 그다음 실행하면 `10...`이 끝없이 나온다(편집기의 정지 버튼으로 멈춘다). 11번 빈 줄에 `count = count - 1`을 넣으면 10...부터 1...까지, `🚀 발사!`, `걸린 시간: 10초`가 나온다(실행해 확인함).

## 🪜 단계 1 · 메뉴판 보여 주기

- 실행하고 확인: `3. 컵라면 1800원`

## 🪜 단계 2 · 0을 넣을 때까지 계속 묻기

- 실행하고 확인: 1 → 다시 묻는다 / 5 → 다시 묻는다 / 0 → 프로그램이 끝난다(아무 말 없이)

## 🪜 단계 3 · 없는 번호 건너뛰기

- 실행하고 확인: 7 → `없는 번호예요. 다시 골라 주세요.` / 2 → 없음(다시 묻는다) / 0 → 끝

## 🪜 단계 4 · 메뉴마다 가격 정하기

- 실행하고 확인: 1 → `1200원을 담았어요.` / 3 → `1800원을 담았어요.`

## 🪜 단계 5 · 합계 쌓고 결제 금액 보여 주기

- 실행하고 확인: 마지막 두 줄: `결제할 금액: N원` / `감사합니다!` (학생이 넣은 메뉴에 따라 N이 다르다)

**따라가기** (3 / 7 / 3 / 0을 차례로 넣으면? 바퀴마다 상자 값 적기, 실행해 확인함)

| 넣은 값 | price | total | 실행된 일 |
| --- | --- | --- | --- |
| 3 | 1800 | 1800 | 담기, `합계: 1800원` |
| 7 | 1800 (그대로) | 1800 (그대로) | `없는 번호예요…` 후 `continue`로 처음으로 |
| 3 | 1800 | 3600 | 담기, `합계: 3600원` |
| 0 | 1800 (그대로) | 3600 (그대로) | `break` → `결제할 금액: 3600원`, `감사합니다!` |

## ⭐ 내 것으로 바꾸기

- 예시는 `mini_solution.py` 맨 아래 주석(메뉴 더하기, 개수, 거스름돈 세 자리). 개수를 더하면 합계는 `price * count`만큼 는다. 거스름돈은 `paid`가 `total` 이상이 될 때까지 되풀이한다. 1, 2개, 0, 2000, 2000을 넣으면 합계 2400원, 거스름돈 1600원(실행해 확인함).
- 완성 기준은 ★ 3개다. 더 해 보기는 평가에 넣지 않는다.
