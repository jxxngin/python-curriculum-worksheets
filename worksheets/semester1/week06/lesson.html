단계 4 롤러코스터: 깃발로 판정하기

📌 목표: 조건 두 개를 차례로 확인해 탈 수 있는지를 True/False로 보여 준다.
🧰 참과 거짓: True, False

조건은 맞으면 True(참), 틀리면 False(거짓)가 돼요. 첫 글자는 대문자이고 따옴표는 없어요.

print(10 > 3)print(2 > 5)

→ True, False

🧰 깃발 변수

처음에 깃발을 세워 두고(True), 안 되는 조건을 하나라도 만나면 깃발을 내려요(False).

ok = Trueif 3 > 5:    ok = Falseprint(ok)

→ True

워밍업"아니요"를 넣어도 우산을 챙기라고 할 때●○○

or 오른쪽의 "흐림"은 비교가 아니라 글자뿐이라 늘 참으로 봐요. 흐림은 아래 if cloud == "네":가 이미 확인하니, 위 줄은 if rain == "네":만 남겨요.

단계 1나이를 넣으면 ValueError가 날 때●○○

숫자만 넣어요. "11살"처럼 글자가 섞이면 int()가 숫자로 바꿀 수 없어요.

단계 2조건이 맞는데도 탈 수 없다고 나올 때●○○

and는 두 조건이 모두 맞아야 해요. >=(이상)의 방향과 숫자를 봐요.

단계 3보호자와 왔는데도 못 탄다고 나올 때●○○

or 오른쪽도 완전한 비교로 써요: with_parent == "네". 대답 앞뒤 공백은 .strip()이 지워 줘요.

단계 4true나 false에서 NameError가 날 때●○○

참·거짓은 첫 글자를 대문자로 True, False라고 써요. 따옴표는 붙이지 않아요.

단계 5else에서 오류가 나거나 엉뚱한 말이 나올 때●○○

안쪽 if와 그 else는 4칸, 그 아래 print는 8칸이에요. 바깥 else는 맨 앞(0칸)에 써요.

새 상자 speed(속도, int(input()))와 safe(안전거리, speed // 2). distance < safe이면 danger = True.

도전속도 센서 · 거의 다 됐는데 안 될 때●●●

시작 파일의 if distance < 10: 두 줄을 지우고, 그 자리에 넣어요. danger = False보다 아래여야 해요.

speed = int(input("현재 속도 km/h (숫자만): "))safe = speed // 2if distance < safe:    danger = True
