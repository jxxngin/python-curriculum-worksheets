# 6주차 교안 정답지: 놀이공원 입장 판정기

교사용. `lesson.html`의 블록 순서대로 정리했다. 실행 결과는 `mini_solution.py`를 Python 3.11로 실제로 실행해 확인했다.

## 🎯 미션

"완성하면 이렇게 돼요"는 하린 / 11 / 135 / 네 / 아니요를 넣고 실행한 화면이다.

## 🔧 워밍업 (고장 난 우산 알림 고치기)

| 나타나는 순서 | 줄 | 오류 이름 (실제 메시지) | 고친 방법 |
| --- | --- | --- | --- |
| 1 | 19 | IndentationError (`expected an indented block after 'else' statement on line 18`) | `print(...)` 앞에 4칸 들여쓰기 |
| 2 | 8 | NameError (`name 'false' is not defined. Did you mean: 'False'?`) | `False` (첫 글자 대문자) |
| 3 | 10 | 메시지 없음 (비도 안 오고 맑아도 우산을 챙기라고 한다) | `if rain == "네":` (워밍업 힌트 카드) |

- IndentationError(19번)는 실행 전에 나온다. 고치면 실행되고, 5·6번 줄의 질문 두 개에 대답한 뒤 8번 NameError가 난다. 10번은 `or` 오른쪽의 `"흐림"`이 비교가 아니라 글자라서 늘 참이다.

## 🪜 단계 1 · 손님 정보 물어보기

- 실행하고 확인: 질문 4개가 차례로 나온다. 표에는 학생이 넣은 나이와 키를 적는다.

## 🪜 단계 2 · 바이킹: 두 조건이 모두 맞아야 탄다

- 실행하고 확인: 130·11 → `[바이킹] 탑승 가능!` / 130·8, 110·11 → `[바이킹] 키 120cm 이상, 10살 이상이어야 해요.`

## 🪜 단계 3 · 범퍼카: 하나만 맞아도 탄다

- 실행하고 확인: 8·네, 11·아니요 → `[범퍼카] 탑승 가능!` / 8·아니요 → `[범퍼카] 10살 미만은 보호자와 함께 타요.`

## 🪜 단계 4 · 롤러코스터: 깃발로 판정하기

- 실행하고 확인: 135·12 → `True` / 135·11 → `False` (`[롤러코스터] 탈 수 있나요? True/False`)

## 🪜 단계 5 · 유령의 집: if 안에 if

- 실행하고 확인: 자유이용권 네·9살 이상 → `[유령의 집] 입장 가능! 무서워도 울지 않기!` / 네·8살 이하 → `9살 이상만…` / 아니요 → `자유이용권이 필요해요.`

**따라가기** (지우 / 9 / 125 / 아니요 / 네를 넣으면?, 실행해 확인함)

| 바이킹 | 범퍼카 | can_ride | 유령의 집 |
| --- | --- | --- | --- |
| 탈 수 없음 (125 ≥ 120이지만 9 < 10) | 탑승 가능 (보호자 "네") | `False` (125 < 130) | 자유이용권이 필요해요 |

## ⭐ 내 것으로 바꾸기

- `not can_ride`는 `can_ride == False`와 같다. 예시는 `mini_solution.py` 맨 아래 주석.
- 완성 기준은 ★ 3개다. 더 해 보기는 평가에 넣지 않는다.

## 🚀 도전 프로젝트 (자율주행차 판단 AI)

- 시작 파일 판단(실행해 확인함): 노랑/아니요/40 → 속도를 줄이며 정지 준비, 초록/아니요/50 → 출발, 초록/아니요/5 → 정지(앞차 10m 미만이라 danger). 예시 답안은 `extension_solution.py`(속도·비·옆 차선 센서, 판단 5가지, 안전 점수, 무작위 테스트 모드).
