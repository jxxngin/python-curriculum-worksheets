# 6주차 워크시트 정답지: 놀이공원 입장 판정기

교사용. `worksheet.html`의 쪽 순서대로 정리했다.

## 1쪽 · 워밍업 (우산 챙길까?)

| 줄 | 오류 이름 | 고친 방법 |
| --- | --- | --- |
| 8 | NameError (`name 'false' is not defined`) | `False` (첫 글자 대문자) |
| 10 | 메시지 없음 (맑아도 우산을 챙기라고 한다) | `if rain == "네":` (`or "흐림"`은 항상 참이다) |
| 19 | IndentationError (`expected an indented block`) | `print(...)` 앞에 4칸 들여쓰기 |

- 10번 줄 설명: `or` 오른쪽의 `"흐림"`은 비교식이 아니라 글자 하나뿐이라 항상 참으로 본다. 카드 2의 "or 양쪽에는 완전한 비교"와 연결된다.

**디버거 미션** (비: 아니요, 흐림: 네)

| 줄 | 조건식 | True/False | 지난 뒤 need_umbrella |
| --- | --- | --- | --- |
| 8 | (깃발 세우기) | — | False |
| 10 | `rain == "네"` | False | False |
| 13 | `cloud == "네"` | True | True |
| 16 | `need_umbrella == True` | True | True |

- 깃발이 False → True로 바뀐 줄: **14**번 줄 (`need_umbrella = True`)

## 2쪽 · 개념 카드

| 카드 | 예상 실행 화면 |
| --- | --- |
| 1 | `True` / `False` / `True` |
| 2 ("토") | `요일: 토` / `주말이에요! 🎉` / `False` |
| 3 ("네", 8) | `9살부터 입장해요.` |
| 4 | `키가 작아요.` (탑승 가능은 나오지 않는다) |

**직접 해 보기**

```python
age = int(input("나이: "))
if age >= 13 and age <= 19:
    print("청소년이에요")
```

**생각해 보기:** `and` 한 줄은 짧지만, 안 될 때 이유를 하나로만 말할 수 있다. 깃발 변수는 조건마다 따로 검사하므로 "키가 작아요", "나이가 어려요"처럼 이유를 모두 알려 줄 수 있다.

## 3쪽 · 미니 프로젝트

**따라 하기 빈칸:** ① `and` ② `True` ③ `False` ④ `if`

**예상 실행 화면** (이름 지우, 나이 11, 키 135, 자유이용권 네 — 빈칸을 채운 starter를 실행해 확인함)

```
[회전목마]
혼자 탈 수 있어요! 🐴
[바이킹]
탑승 가능! ⛵
[롤러코스터]
12살 이상이어야 해요.
[유령의 집]
입장 가능! 👻 무서워도 울지 않기!
```

- 롤러코스터는 키는 통과(135 ≥ 130)했지만 나이 11 < 12라 깃발이 내려가고, "탑승 가능"이 출력되지 않는다.

## 4쪽 · 확장 프로젝트 (자율주행차)

- 판단 규칙표는 위험한 것부터 쓴다. 예: 1 긴급 정지(보행자 and 거리 < 10) → 2 정지(빨강 or 보행자) → 3 차선 변경/감속(너무 가까움) → 그 외 주행
- AI 시험표 예: 초록, 보행자 아니요, 5m → 너무 가까우므로 차선 변경 또는 감속 (안전거리 규칙에 따라)
- 확인할 점: if/elif 순서를 바꾸면 위험한 상황인데 "주행"이 먼저 나올 수 있다.
