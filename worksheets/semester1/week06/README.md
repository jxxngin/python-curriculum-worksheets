## 🎯 오늘의 미션

나이와 키를 넣으면 놀이기구마다 탈 수 있는지 알려 주는 판정기를 만들어요.

**오늘의 목표**

- 조건 두 개를 `and`, `or`로 묶어 판정할 수 있다.
- `True`/`False` 깃발 변수로 여러 조건을 한 번에 확인할 수 있다.
- `if` 안에 `if`를 넣어 두 번 나눠 판정할 수 있다.

완성하면 이렇게 돼요:

```
꿈나라 놀이공원 탑승 판정기
이름: 하린
나이 (숫자만): 11
키 cm (숫자만): 135
자유이용권이 있나요? (네/아니요): 네
[바이킹] 탑승 가능!
보호자와 함께 왔나요? (네/아니요): 아니요
[범퍼카] 탑승 가능!
[롤러코스터] 탈 수 있나요? False
[유령의 집] 입장 가능! 무서워도 울지 않기!
```

## 🪜 단계 2: 바이킹: 두 조건이 모두 맞아야 탄다

📌 목표: 키 120cm 이상이고 10살 이상이면 바이킹을 탈 수 있다고 알려 준다.

> 🧰 **둘 다 맞아야: and**: 양쪽 조건이 모두 맞아야 참이에요. 하나라도 틀리면 거짓이에요.
>
> ```python
> score = 90
> if score >= 80 and score <= 100:
>     print("A등급")
> ```
> → A등급

① 기능 추가하기: `mini_starter.py`의 `# 단계 2` 아래에 입력

```python
if height >= 120 and age >= 10:
    print("[바이킹] 탑승 가능!")
else:
    print("[바이킹] 키 120cm 이상, 10살 이상이어야 해요.")
```

② 실행하고 확인: 표의 키와 나이를 넣어 3번 실행하고 나온 말 적기

✅ 키와 나이가 모두 맞을 때만 "탑승 가능"이 나왔어요.

## 🪜 단계 3: 범퍼카: 하나만 맞아도 탄다

📌 목표: 10살 이상이거나 보호자와 함께 왔으면 범퍼카를 탈 수 있다고 알려 준다.

> 🧰 **하나만 맞아도: or**: 양쪽 중 하나라도 맞으면 참이에요. `or` 양쪽에는 비교를 각각 다 써요.
>
> ```python
> day = "토"
> if day == "토" or day == "일":
>     print("주말!")
> ```
> → 주말!

① 기능 추가하기: `mini_starter.py`의 `# 단계 3` 아래에 입력

```python
with_parent = input("보호자와 함께 왔나요? (네/아니요): ").strip()
if age >= 10 or with_parent == "네":
    print("[범퍼카] 탑승 가능!")
else:

```

② 실행하고 확인: 표의 나이와 보호자 대답을 넣어 3번 실행하고 나온 말 적기

✅ 둘 중 하나만 맞아도 "탑승 가능"이 나왔어요.

## 🪜 단계 4: 롤러코스터: 깃발로 판정하기

📌 목표: 조건 두 개를 차례로 확인해 탈 수 있는지를 True/False로 보여 준다.

> 🧰 **참과 거짓: True, False**: 조건은 맞으면 `True`(참), 틀리면 `False`(거짓)가 돼요. 첫 글자는 대문자이고 따옴표는 없어요.
>
> ```python
> print(10 > 3)
> print(2 > 5)
> ```
> → True, False

> 🧰 **깃발 변수**: 처음에 깃발을 세워 두고(`True`), 안 되는 조건을 하나라도 만나면 깃발을 내려요(`False`).
>
> ```python
> ok = True
> if 3 > 5:
>     ok = False
> print(ok)
> ```
> → True

① 기능 추가하기: `mini_starter.py`의 `# 단계 4` 아래에 입력

```python
can_ride = True
if height < 130:
    can_ride = False
if age < 12:
    can_ride = False
print(f"[롤러코스터] 탈 수 있나요? {can_ride}")
```

② 실행하고 확인: 표의 키와 나이를 넣어 2번 실행하고 True/False 적기

✅ 조건이 하나라도 안 맞으면 False가 나왔어요.

## 🪜 단계 5: 유령의 집: if 안에 if

📌 목표: 자유이용권이 있는 사람만 나이를 한 번 더 확인해 입장을 알려 준다.

> 🧰 **if 안의 if: 중첩 if**: 첫 조건을 통과한 사람만 두 번째 조건을 확인해요. 안쪽 `if`는 4칸 더 들여 써요.
>
> ```python
> money = 5000
> if money >= 3000:
>     if money >= 5000:
>         print("큰 아이스크림")
>     else:
>         print("작은 아이스크림")
> ```
> → 큰 아이스크림

① 기능 추가하기: `mini_starter.py`의 `# 단계 5` 아래에 입력

```python
if ticket == "네":
    if age >= 9:
        print("[유령의 집] 입장 가능! 무서워도 울지 않기!")
    else:
        print("[유령의 집] 9살 이상만 들어갈 수 있어요.")
else:
    print("[유령의 집] 자유이용권이 필요해요.")
```

② 실행하고 확인: 마지막 줄 적기

✅ 자유이용권이 없으면 나이를 확인하지 않고 바로 "자유이용권이 필요해요"가 나왔어요.

③ 따라가기: 지우 / 9 / 125 / 아니요 / 네를 넣으면?

## 🚀 도전 프로젝트: 자율주행차 판단 AI

**왜 만들까?** 자율주행차는 센서 값 여러 개를 조건으로 묶어 정지·감속·주행을 정해요. 오늘 배운 조건 묶기를 진짜 기술처럼 써 보는 연습이에요.

📌 목표: 센서 정보를 보고 정지·감속·주행·차선 변경 4가지 중 하나를 판단하는 AI를 만든다. 시작 파일에는 정지·감속·주행 3가지가 들어 있고, 차선 변경은 내가 더한다.

> 🧰 **조건을 상자에 담기**: `too_close = distance < 10`처럼 비교 결과(True/False)를 상자에 담으면, 긴 조건을 짧은 이름으로 쓸 수 있어요.

① 실행해 보기: `extension_starter.py`를 그대로 실행

## 🃏 힌트

<details>
<summary>[워밍업] "아니요"를 넣어도 우산을 챙기라고 할 때 ●○○</summary>

`or` 오른쪽의 `"흐림"`은 비교가 아니라 글자뿐이라 늘 참으로 봐요. 흐림은 아래 `if cloud == "네":`가 이미 확인하니, 위 줄은 `if rain == "네":`만 남겨요.

</details>

<details>
<summary>[단계 1] 나이를 넣으면 ValueError가 날 때 ●○○</summary>

숫자만 넣어요. "11살"처럼 글자가 섞이면 `int()`가 숫자로 바꿀 수 없어요.

</details>

<details>
<summary>[단계 2] 조건이 맞는데도 탈 수 없다고 나올 때 ●○○</summary>

`and`는 두 조건이 모두 맞아야 해요. `>=`(이상)의 방향과 숫자를 봐요.

</details>

<details>
<summary>[단계 3] 보호자와 왔는데도 못 탄다고 나올 때 ●○○</summary>

`or` 오른쪽도 완전한 비교로 써요: `with_parent == "네"`. 대답 앞뒤 공백은 `.strip()`이 지워 줘요.

</details>

<details>
<summary>[단계 4] true나 false에서 NameError가 날 때 ●○○</summary>

참·거짓은 첫 글자를 대문자로 `True`, `False`라고 써요. 따옴표는 붙이지 않아요.

</details>

<details>
<summary>[단계 5] else에서 오류가 나거나 엉뚱한 말이 나올 때 ●○○</summary>

안쪽 `if`와 그 `else`는 4칸, 그 아래 `print`는 8칸이에요. 바깥 `else`는 맨 앞(0칸)에 써요.

</details>

<details>
<summary>[새로 만들기] 오늘의 VIP · 무엇부터 할지 모를 때 ●○○</summary>

VIP 깃발을 내려 둔 채로 시작하고, 자유이용권이 있으면서 롤러코스터도 탈 수 있을 때만 깃발을 올려요.

</details>

<details>
<summary>[새로 만들기] 오늘의 VIP · 쓸 도구가 떠오르지 않을 때 ●●○</summary>

새 상자 `vip`(깃발, 처음엔 `False`). `if ticket == "네":` 안에 `if can_ride:`를 넣고 그 안에서 `vip = True`. 마지막에 `if vip:`로 알려 줘요.

</details>

<details>
<summary>[새로 만들기] 오늘의 VIP · 거의 다 됐는데 안 될 때 ●●●</summary>

단계 5 코드 아래에 이어서 입력해요.

```python
vip = False
if ticket == "네":
    if can_ride:
        vip = True
if vip:
    print(f"{name}님은 오늘의 VIP! 줄 서지 않고 타요.")
```

</details>

<details>
<summary>[도전] 속도 센서 · 무엇부터 할지 모를 때 ●○○</summary>

속도를 묻고, 빠를수록 안전거리를 길게 잡아요. 앞차와의 거리가 안전거리보다 짧으면 위험이에요.

</details>

<details>
<summary>[도전] 속도 센서 · 쓸 도구가 떠오르지 않을 때 ●●○</summary>

새 상자 `speed`(속도, `int(input())`)와 `safe`(안전거리, `speed // 2`). `distance < safe`이면 `danger = True`.

</details>

<details>
<summary>[도전] 속도 센서 · 거의 다 됐는데 안 될 때 ●●●</summary>

시작 파일의 `if distance < 10:` 두 줄을 지우고, 그 자리에 넣어요. `danger = False`보다 아래여야 해요.

```python
speed = int(input("현재 속도 km/h (숫자만): "))
safe = speed // 2
if distance < safe:
    danger = True
```

</details>
