## 📇 개념 카드

### 카드 1. True와 False

조건식의 결과는 `True`(참) 또는 `False`(거짓)예요. 변수에 담을 수도 있어요.

```python
age = 11
print(age >= 10)        # True
print(age == 15)        # False
is_kid = age < 13
print(is_kid)           # True
```

✋ **직접 해 보기:** `print(type(True))`를 실행해 보세요. 어떤 종류(type)가 나오나요?

### 카드 2. and, or, not

| 키워드 | 뜻 | 예 |
| --- | --- | --- |
| `and` | 둘 다 참이어야 참 | `height >= 120 and age >= 10` |
| `or` | 하나만 참이어도 참 | `day == "토" or day == "일"` |
| `not` | 참↔거짓 뒤집기 | `not is_raining` |

```python
day = input("요일: ").strip()
if day == "토" or day == "일":
    print("주말이에요! 🎉")
```

✋ **직접 해 보기:** 나이가 13 이상 **그리고** 19 이하이면 "청소년"이라고 출력해 보세요.

⚠️ `day == "토" or "일"`처럼 쓰면 안 돼요. `or` 양쪽에 **완전한 비교**를 써야 해요.

### 카드 3. 중첩 if: if 안의 if

첫 번째 조건을 통과한 경우에만 두 번째 조건을 검사해요. 안쪽 if는 한 번 더 들여쓰기!

```python
ticket = input("표 있어요? ").strip()
if ticket == "네":
    age = int(input("나이: "))
    if age >= 9:
        print("입장!")
    else:
        print("9살부터 입장할 수 있어요.")
```

✋ **직접 해 보기:** 표가 없을 때 "매표소로 가세요"를 출력하는 `else`를 바깥 if에 추가해 보세요.

### 카드 4. 깃발 변수

처음에 깃발을 `True`로 세우고, 조건에 하나라도 걸리면 `False`로 내려요. 마지막에 깃발만 보면 결과를 알 수 있어요. 조건마다 **이유를 따로 알려 줄 수 있는** 게 장점이에요.

```python
ok = True
if height < 130:
    print("키가 작아요.")
    ok = False
if ok:
    print("탑승 가능!")
```

✋ **직접 해 보기:** 나이 조건(12살 미만이면 안 됨)을 하나 더 추가해 보세요.

## 🤖 확장 프로젝트 퀘스트: 자율주행차 판단 AI

> 중고등학생은 미니 1단계 후 이 퀘스트가 **오늘의 완성 기준**이에요. 초등학생은 미니를 마친 뒤 선택해요.

`extension_starter.py`는 신호등, 보행자, 앞차 거리를 보고 정지/감속/출발을 판단해요. 실제 자율주행차도 센서 값을 조건으로 판단해요. 더 똑똑하게 키워 보세요.

### 바꾸기 (완성 기준)

- [ ] 센서를 2개 이상 추가했어요. (예: 현재 속도, 비, 옆 차선)
- [ ] 판단을 4가지 이상으로 늘렸어요. (예: 긴급 정지, 정지, 차선 변경, 감속, 주행)
- [ ] 위험 깃발을 2개 이상 만들고 `and`/`or`/`not`으로 조합했어요.
- [ ] 중첩 if로 "거리가 가까울 때 → 옆 차선이 비었으면 차선 변경, 아니면 감속"을 판단해요.
- [ ] 속도에 따라 안전거리가 바뀌어요. (예: 속도의 절반 m)

### 새로 만들기 (선택)

- 💡 **무작위 테스트 모드**: `random`으로 센서 상황을 만들어 AI 판단 시험하기
- 💡 상황 **안전 점수** 계산하기
- 💡 사람에게도 판단을 묻고 AI와 비교하기 (사람과 AI, 누가 더 안전할까?)

<details>
<summary>힌트 1 (방향)</summary>

판단은 **위험한 것부터** 검사해요. if/elif는 위에서부터 처음 맞는 하나만 실행되니까, 긴급 정지 → 정지 → 차선 변경/감속 → 주행 순서로 써요.

</details>

<details>
<summary>힌트 2 (사용할 함수)</summary>

`person = input(...).strip() == "네"`처럼 쓰면 `person`에 바로 `True`/`False`가 담겨요. 깃발 조합: `emergency = person and distance < 10`.

</details>

<details>
<summary>힌트 3 (거의 코드)</summary>

```python
too_close = distance < speed // 2
if emergency:
    print("🚨 긴급 정지!")
elif light == "빨강" or person:
    print("🛑 정지")
```
