## 🔧 워밍업

`warmup.py`를 실행하고 오류 3개를 고쳐요. (고장 난 자기소개 고치기)

## 🪜 단계 1: 제목 보여 주기

> 🧰 **보여 주기: print()**: 괄호 안의 글자를 화면에 보여 줘요. 글자는 따옴표로 감싸요.

`mini_starter.py`의 `# 단계 1` 아래에 이어 써요.

```python
print("=================================")
print("     🎂 생일 파티 초대장 🎂")
print("=================================")
```

✅ 화면에 제목 3줄이 나왔어요.

## 🪜 단계 2: 질문 4개 물어보기

> 🧰 **물어보기: input()과 이름표 상자**: 질문을 보여 주고 대답을 받아요. 대답은 이름표를 붙인 상자(변수)에 담아요. =는 "오른쪽 대답을 왼쪽 상자에 넣어요"라는 뜻이에요.

`mini_starter.py`의 `# 단계 2` 아래에 이어 써요.

```python
host = input("생일인 사람의 이름은? ")
date = input("파티 날짜는? (예: 5월 3일) ")
place = input("파티 장소는? ")
guest = input("초대할 친구 이름은? ")
```

✅ 질문 4개가 차례로 나오고, 대답을 넣을 수 있었어요.

## 🪜 단계 3: 대답을 넣어 초대장 완성하기

> 🧰 **글자 이어 붙이기: +**: 상자에 든 대답과 따옴표 글자를 이어 붙여요. 띄어쓰기도 직접 넣어요.

> 🧰 **메모 남기기: #**: # 뒤에 쓴 글은 실행되지 않아요. 나중에 볼 메모예요.

`mini_starter.py`의 `# 단계 3` 아래에 이어 써요.

```python
# 초대장 내용
print("---------------------------------")
print(guest + "에게")
print(host + "의 생일 파티에 초대합니다!")
print("날짜: " + date + " / 장소: " + place)
print("꼭 와 줘! - " + host + " 드림")
```

✅ 초대장에 친구 이름, 날짜, 장소가 들어갔어요.
