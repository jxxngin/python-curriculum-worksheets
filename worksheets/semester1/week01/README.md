# 1주차: 생일 파티 초대장 만들기

> 교안 요약이다. 활동은 `lesson.html`에서 한다(인쇄하면 학습지).

## 🎯 오늘의 미션

친구 이름을 넣으면 생일 초대장이 나오는 프로그램을 만들어요.

**오늘의 목표**

- 질문을 하고 대답을 받아 상자(변수)에 담을 수 있다.
- 대답을 글자와 이어 붙여 나만의 초대장을 화면에 보여 줄 수 있다.

완성하면 이렇게 돼요:

```
=================================
        생일 파티 초대장
=================================
생일인 사람의 이름은? 민지
파티 날짜는? (예: 5월 3일) 5월 3일
파티 장소는? 우리 집
초대할 친구 이름은? 서준
---------------------------------
서준에게
민지의 생일 파티에 초대합니다!
날짜: 5월 3일 / 장소: 우리 집
꼭 와 줘! - 민지 드림
```

## 🔧 워밍업

목표: 오류 메시지를 읽고 오류 3개를 고친다. (고장 난 자기소개 고치기)

`warmup.py`를 실행하고 고친다. 팁: SyntaxError 문법 오류(괄호·따옴표 짝 확인) · NameError 없는 이름(철자 확인)

## 🪜 단계 1: 제목 보여 주기

목표: 화면에 초대장 제목 3줄이 나온다.

> 🧰 **보여 주기: print()**: 괄호 안의 글자를 화면에 보여 줘요. 글자는 따옴표로 감싸요.
>
> ```python
> print("파티에 와 줘")
> ```
> → 파티에 와 줘

① 🧩 기능 추가하기: `mini_starter.py`의 `# 단계 1` 아래에 입력

```python
print("=================================")
print("        생일 파티 초대장")
print("=================================")
```

② ▶️ 실행하고 확인: 가운데 제목 줄 적기

✅ 제목 3줄이 나왔어요.

## 🪜 단계 2: 질문 4개 물어보기

목표: 질문 4개에 대답하면 대답이 상자에 담긴다.

> 🧰 **물어보기: input()과 이름표 상자**: 질문을 보여 주고 대답을 받아요. 대답은 이름표를 붙인 상자(변수)에 담아요. `=`는 오른쪽 대답을 왼쪽 상자에 넣는다는 뜻이에요.
>
> ```python
> food = input("좋아하는 간식은? ")
> ```
> → 대답이 food 상자에 들어가요

① 🧩 기능 추가하기: `mini_starter.py`의 `# 단계 2` 아래에 입력

```python
host = input("생일인 사람의 이름은? ")
date = input("파티 날짜는? (예: 5월 3일) ")
place = input("파티 장소는? ")
guest = input("초대할 친구 이름은? ")
```

② ▶️ 실행하고 확인: 넣은 대답 4개를 표에 적기

✅ 질문 4개가 차례로 나왔어요.

## 🪜 단계 3: 대답을 넣어 초대장 완성하기

목표: 대답이 들어간 초대장이 화면에 나온다.

> 🧰 **글자 이어 붙이기: +**: 상자에 든 대답과 따옴표 글자를 이어 붙여요. 띄어쓰기도 직접 넣어요.
>
> ```python
> print(food + "가 최고")
> ```
> → 떡볶이가 최고

> 🧰 **메모 남기기: #**: # 뒤에 쓴 글은 실행되지 않아요. 나중에 볼 메모예요.
>
> ```python
> # 여기부터 초대장 내용
> ```
> → 화면에는 아무것도 안 나와요

① 🧩 기능 추가하기: `mini_starter.py`의 `# 단계 3` 아래에 입력

```python
# 초대장 내용
print("---------------------------------")
print(guest + "에게")
print(host + "의 생일 파티에 초대합니다!")
print("날짜: " + date + " / 장소: " + place)
print("꼭 와 줘! - " + host + " 드림")
```

② ▶️ 실행하고 확인: 친구 이름이 들어간 줄 적기

✅ 초대장에 친구 이름, 날짜, 장소가 들어갔어요.

③ 🔍 따라가기: 하준 / 6월 1일 / 놀이터 / 지우를 넣으면 상자에 든 값은?

## 🚀 도전 프로젝트: RPG 파티원 모집 퀘스트 창

**왜 만들까?** 게임 속 파티 모집 게시판처럼 여러 정보를 한눈에 보이게 정리하는 연습이에요. 오늘 배운 이어 붙이기를 더 길게, 더 보기 좋게 써요.

목표: 최소 레벨, 보상, 집합 장소가 들어간 모집 게시판을 만든다.

① 실행해 보기: `extension_starter.py`를 그대로 실행

② 설계하기: 게시판이 화면에 어떻게 보일지 칸에 그리기

③ 바꾸고 체크하기

- [ ] 게시판 테두리와 제목을 내 디자인으로 바꿨어요.
- [ ] 최소 레벨, 보상, 집합 장소를 물어보고 보여 줬어요.
- [ ] 파티장 한마디를 따옴표 안에 넣어 보여 줬어요. (바깥은 `' '`, 안쪽은 `" "`)

**➕ 더 해 보기**

- 지원자가 가입하는 [시스템] 메시지
- 난이도 별점(★★★☆☆)
- 파티 이름 자동 만들기 (`"파티장: " + leader`)
