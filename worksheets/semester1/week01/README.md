## 📇 개념 카드

### 카드 1. print(): 화면에 보여 주기

괄호 안의 글자를 화면에 출력해요. 글자는 꼭 따옴표 `" "`로 감싸요.

```python
print("안녕하세요!")
print("파이썬 첫 수업이에요.")
print("")   # 빈 줄 하나
```

✋ **직접 해 보기:** 내 이름과 좋아하는 동물을 두 줄로 출력해 보세요.

### 카드 2. 변수: 값을 담는 상자

`이름 = 값` 으로 상자에 값을 넣어요. 나중에 이름만 부르면 안에 든 값이 나와요. 변수 이름은 영어로 지어요.

```python
pet = "고양이"
print(pet)
pet = "강아지"   # 상자 안의 값을 바꿀 수 있어요
print(pet)
```

✋ **직접 해 보기:** `color` 변수에 좋아하는 색을 넣고 출력해 보세요.

### 카드 3. input(): 질문하고 대답 받기

질문을 보여 주고, 사용자가 입력한 글자를 돌려줘요. 보통 변수에 바로 담아요.

```python
name = input("이름이 뭐예요? ")
print(name)
```

✋ **직접 해 보기:** 사는 동네를 물어보고 출력해 보세요.

### 카드 4. 문자열 합치기(+)와 주석(#)

`+`로 글자와 글자를 이어 붙여요. 띄어쓰기도 직접 넣어야 해요. `#` 뒤에 쓴 글은 실행되지 않는 메모(주석)예요.

```python
# 인사말 만들기
name = input("이름: ")
print("안녕, " + name + "!")
print(name + "님 환영해요")
```

✋ **직접 해 보기:** `"안녕," + name` 과 `"안녕, " + name` 의 차이를 출력해서 비교해 보세요.
