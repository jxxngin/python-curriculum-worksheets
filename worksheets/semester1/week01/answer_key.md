# 1주차 교안 정답지: 생일 파티 초대장

교사용. `lesson.html`의 블록 순서대로 정리했다. 실행 결과는 `mini_solution.py`를 실제로 실행해 확인했다.

## 🎯 미션

"완성하면 이렇게 돼요"는 민지 / 5월 3일 / 우리 집 / 서준를 넣고 실행한 화면이다.

## 🔧 워밍업 (고장 난 자기소개 고치기)

| 줄 | 오류 이름 | 고친 방법 |
| --- | --- | --- |
| 8 | SyntaxError (`'(' was never closed`) | 줄 끝에 `)` 추가 |
| 11 | NameError (`name 'foood' is not defined`) | `foood` → `food` |
| 13 | SyntaxError (`unterminated string literal`) | 닫는 따옴표 추가 |

- SyntaxError를 하나씩 먼저 알려 준다. 8번·13번을 고쳐야 실행되면서 11번 NameError가 나온다.

## 🪜 단계 1 · 제목 보여 주기

- 실행하고 확인: 화면에 `=====` 줄, `🎂 생일 파티 초대장 🎂`, `=====` 줄이 나온다.

## 🪜 단계 2 · 질문 4개 물어보기

- 실행하고 확인: 질문 4개가 차례로 나온다. 화면에 따로 출력되는 것은 없다(대답은 상자에 들어갔다).

## 🪜 단계 3 · 대답을 넣어 초대장 완성하기

- 실행하고 확인: 예시 입력(민지 / 5월 3일 / 우리 집 / 서준)이면 `서준에게` / `민지의 생일 파티에 초대합니다!` / `날짜: 5월 3일 / 장소: 우리 집` / `꼭 와 줘! - 민지 드림`

**따라가기** (민지 / 5월 3일 / 우리 집 / 서준을 넣었다면 상자 속에는?, 실행해 확인함)

| host | date | place | guest |
| --- | --- | --- | --- |
| `'민지'` | `'5월 3일'` | `'우리 집'` | `'서준'` |

## ⭐ 내 것으로 바꾸기

- 질문 하나 = `input()` 하나 = 상자 하나. 표의 상자 이름과 코드의 이름이 같은지 본다. 예시는 `mini_solution.py` 맨 아래 주석.
- 완성 기준은 ★ 꼭 하기 3개다. 더 해 보기는 평가에 넣지 않는다.

## 🚀 도전 프로젝트 (RPG 파티원 모집 퀘스트 창)

- 예시 답안은 `extension_solution.py`. 한마디 따옴표 예: `print('파티장: "' + leader_say + '"')`
