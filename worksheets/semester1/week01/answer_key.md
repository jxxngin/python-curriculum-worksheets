# 1주차 워크시트 정답지: 생일 파티 초대장

교사용. `worksheet.html`의 쪽 순서대로 정리했다. 학생마다 답이 다른 칸은 "예시"와 확인할 점을 적었다.

## 1쪽 · 워밍업

| 줄 | 오류 이름 | 고친 방법 |
| --- | --- | --- |
| 8 | SyntaxError (`'(' was never closed`) | 줄 끝에 `)` 추가 |
| 11 | NameError (`name 'foood' is not defined`) | `foood` → `food` |
| 13 | SyntaxError (`unterminated string literal`) | `"오늘도 즐겁게 코딩해요!"`처럼 닫는 따옴표 추가 |

- 파이썬은 문법 오류(SyntaxError)를 먼저 하나씩 알려 준다. 8번 줄을 고치면 13번 줄 오류가 나오고, 둘 다 고쳐야 실행되면서 11번 줄 NameError가 나온다.

**디버거 미션**

| 몇 번째 줄을 실행했을 때? | 생긴 변수 | 들어간 값 |
| --- | --- | --- |
| 7 | name | 학생이 입력한 이름 (예: `'민지'`) |
| 10 | food | 학생이 입력한 음식 (예: `'떡볶이'`) |

- 변수 창에는 글자가 따옴표와 함께 보인다(`'민지'`). 3주차 type() 수업과 연결된다.

## 2쪽 · 개념 카드

| 카드 | 예상 실행 화면 |
| --- | --- |
| 1 | `안녕하세요!` / (빈 줄) / `파이썬 첫 수업` |
| 2 | `강아지` (새 값을 넣으면 예전 값은 사라진다) |
| 3 | `사는 동네는? 해운대` / `해운대` |
| 4 | `안녕,지우` / `안녕, 지우!` |

**직접 해 보기 (예시)**

```python
# 좋아하는 색 소개
name = input("이름: ")
color = input("좋아하는 색: ")
print(name + "님은 " + color + "색을 좋아해요")
```

**생각해 보기:** `"안녕,"`은 쉼표 뒤에 빈칸이 없어서 `안녕,지우`처럼 붙는다. 컴퓨터는 띄어쓰기를 알아서 넣지 않으므로 따옴표 안에 직접 넣어야 한다.

## 3쪽 · 미니 프로젝트

**따라 하기 빈칸:** ① `input` ② `place` ③ `guest` ④ `print`

**2단계 바꾸기:** 학생마다 다르다. 확인할 점은 다음과 같다.
- 표에 쓴 변수 이름과 코드의 변수 이름이 같은가
- 새로 받은 값을 실제로 출력했는가
- 띄어쓰기가 자연스러운가

**3단계 (예시):** 답장 카드에는 `input()` 2개(친구 이름, 한마디)와 변수 2개가 필요하다. 메뉴판에는 `input()` 3개가 필요하다.

## 4쪽 · 확장 프로젝트

- 퀘스트 창 그리기는 정답이 없다. 그린 모양과 실제 출력이 비슷한지 확인한다.
- 한마디를 따옴표 안에 넣는 예: `print('파티장: "' + leader_say + '"')`
- 예시 답안은 `extension_solution.py`에 있다.
