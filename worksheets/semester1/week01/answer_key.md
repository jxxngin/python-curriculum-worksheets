# 1주차 교안 정답지: 생일 파티 초대장

교사용. `lesson.html`의 블록 순서대로 정리했다. 실행 결과는 `mini_solution.py`를 Python 3.11로 실제로 실행해 확인했다.

## 🎯 미션

"완성하면 이렇게 돼요"는 민지 / 5월 3일 / 우리 집 / 서준를 넣고 실행한 화면이다.

## 🔧 워밍업 (고장 난 자기소개 고치기)

| 나타나는 순서 | 줄 | 오류 이름 (실제 메시지) | 고친 방법 |
| --- | --- | --- | --- |
| 1 | 13 | SyntaxError (`unterminated string literal`) | 닫는 따옴표 추가 |
| 2 | 8 | SyntaxError (`'(' was never closed`) | 줄 끝에 `)` 추가 |
| 3 | 11 | NameError (`name 'foood' is not defined`) | `foood` → `food` |

- SyntaxError는 실행 전에 하나씩 나온다(13번 → 8번). 둘 다 고치면 실행되고, 대답을 넣은 뒤 11번 NameError가 나온다.

## 🪜 단계 2 · 질문 4개 물어보기

- 실행하고 확인: 질문 4개가 차례로 나온다. 표에는 학생이 넣은 대답을 적는다.

## 🪜 단계 3 · 대답을 넣어 초대장 완성하기

- 실행하고 확인: 친구 이름 바로 뒤에 "에게"가 붙은 줄. 예: `서준에게` (띄어쓰기 없음)
