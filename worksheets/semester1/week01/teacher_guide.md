# 1주차 교사 가이드: 생일 파티 초대장

## 수업 목표

- print(), input(), 변수, 문자열 합치기(+), 주석(#)을 사용한다.
- 오류 메시지를 읽고 줄 번호로 오류 위치를 찾는 습관을 시작한다.
- 코드를 한 줄씩 따라가며 변수 값을 추적하는 습관(따라가기 미션)을 시작한다.

## 110분 시간 배분

교안: `lesson.html`. 시간은 기준 기본값(15/40/10/30/15분, ±5분)을 따른다.

## 핵심 설명 포인트

- 블록 코딩의 "말하기" 블록 = `print()`, "묻고 기다리기" + "대답" = `input()`. 비유로 시작하면 빠르게 넘어간다.
- 변수는 이름표 붙은 상자. `=`는 "같다"가 아니라 "오른쪽 값을 왼쪽 상자에 넣는다". 다음 주에 `==`와 구분할 때 다시 강조한다.
- `+`는 띄어쓰기를 자동으로 넣지 않는다. `"안녕," + name` 출력 결과로 직접 확인시킨다.
- 따옴표 안은 글자 그대로, 따옴표 밖은 변수 이름. `print("name")`과 `print(name)` 비교.
- 이번 주는 `+` 이어 붙이기만 사용한다. f-string은 3주에 배우므로 학생이 검색해 와도 다음에 배운다고 안내한다.
- 도전 프로젝트에서 따옴표를 출력하려면 바깥 따옴표를 다른 종류로 쓴다(`'"' + comment + '"'`).

## 자주 나오는 오류와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| `SyntaxError: '(' was never closed` | 괄호 닫기 누락 | 괄호 짝 맞추기. 여는 괄호와 닫는 괄호 개수를 손가락으로 세게 한다 |
| `SyntaxError: unterminated string literal` | 따옴표 닫기 누락 | 같은 종류의 따옴표로 닫는다 |
| `NameError: name 'foood' is not defined` | 변수 철자 틀림, 따옴표 없는 글자 | 변수를 만든 줄과 쓰는 줄의 철자 비교 |
| 한글 자판 상태로 괄호·따옴표 입력 | 전각 문자 `（` `“` 입력 | 영문 자판으로 다시 입력 |
| 결과 글자가 붙어서 나옴 | 띄어쓰기 누락 | 따옴표 안에 공백 추가 |
| `print` 대문자 `Print` | 대소문자 구분 | 파이썬은 대소문자를 구분한다고 안내 |

## 워밍업 정답

1. 8번째 줄: `print("반가워요, " + name + "님!"` → 닫는 괄호 `)` 추가 (`SyntaxError`)
2. 11번째 줄: `foood` → `food` (`NameError`)
3. 13번째 줄: `print("오늘도 즐겁게 코딩해요!)` → 닫는 따옴표 `"` 추가 (`SyntaxError`)

참고: 실제 순서는 13번(SyntaxError) → 8번(SyntaxError) → 11번(NameError)이다(Python 3.11). SyntaxError는 실행 전에 하나씩 나오고, 둘 다 고쳐야 실행되면서 NameError가 나온다. "오류는 하나씩 나타난다"는 점을 짚어 준다.

## 진도 차이 대응

- 빠른 학생: 새로 만들기 → 도전 프로젝트 새로 만들기. 테두리 디자인(ASCII 아트) 꾸미기에 시간을 쓰게 해도 좋다.
- 느린 학생: 타자 속도가 원인인 경우가 많다. 단계 3까지 실행 + ★ 1~2개를 최소 목표로 한다.
- 다음 주에 모든 학생이 같은 편집기로 파일을 열고 실행할 수 있는지 확인한다.
- 인쇄: 양면 인쇄를 권장한다.
