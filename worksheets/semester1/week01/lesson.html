괄호 안의 글자를 화면에 보여 줘요. 글자는 따옴표로 감싸요.

print("파티에 와 줘!")

→ 파티에 와 줘!

🧰 도구 카드 · 물어보기: input()과 이름표 상자

질문을 보여 주고 대답을 받아요. 대답은 이름표를 붙인 상자(변수)에 담아요. =는 "오른쪽 대답을 왼쪽 상자에 넣어요"라는 뜻이에요.

food = input("좋아하는 간식은? ")

→ 대답이 food 상자에 들어가요

⌨️ 따라 쓸 코드
host = input("생일인 사람의 이름은? ")date = input("파티 날짜는? (예: 5월 3일) ")place = input("파티 장소는? ")guest = input("초대할 친구 이름은? ")
▶️ 실행하고 확인
  • 질문 4개가 차례로 나오고, 대답을 넣을 수 있었어요.

🧰 도구 카드 · 글자 이어 붙이기: +

상자에 든 대답과 따옴표 글자를 이어 붙여요. 띄어쓰기도 직접 넣어요.

→ 떡볶이가 최고!

⭐ 내 것으로 바꾸기 오늘의 완성 기준

📋 할 일

  1. 표에 바꿀 내용을 먼저 적어요.
  2. 코드를 고치고 실행해요.
  3. ★ 꼭 하기 3개를 체크하면 완성!
더 물어볼 질문 (화면에 보일 글자)담을 상자 이름 (영어)
예) 파티 시간은?party_time
★ 꼭 하기 (이 3개를 하면 완성!)
  • 제목과 꾸미기 선(---, ***)을 내 스타일로 바꿨어요.
  • 질문을 1개 더 만들고, 대답을 초대장에 넣었어요.
  • 띄어쓰기가 자연스러워요.
➕ 더 해 보기
  • 질문을 2개 이상 더 만들었어요.
  • 메모(#)를 1개 이상 남겼어요.

🚀 도전 프로젝트 RPG 파티원 모집 퀘스트 창 · 일찍 끝낸 사람

📋 할 일

  1. extension_starter.py를 그대로 실행해 봐요.
  2. 내 퀘스트 창이 화면에 어떻게 보일지 아래 칸에 그려요.
  3. 코드를 바꾸고 실행해서 체크해요.

모험을 함께 떠날 친구를 모집하는 게시판을 만들어요. 테두리 글자(+ = | *)로 꾸며 봐요.

  • 게시판 테두리와 제목을 나만의 디자인으로 바꿨어요.
  • 최소 레벨, 보상, 집합 장소를 물어보고 보여 줬어요.
  • 파티장 한마디를 따옴표 안에 넣어 보여 줬어요. (바깥은 ' ', 안쪽은 " ")
➕ 더 해 보기
  • 지원자가 가입하는 [시스템] 메시지
  • 난이도 별점(★★★☆☆)
  • 파티 이름 자동 만들기 (leader + "와 친구들")

🃏 힌트 카드 막히면 1번부터 차례로

단계 1●○○

print( ) 괄호 안에 따옴표로 감싼 글자를 넣어요. 따옴표는 열고 닫는 두 개!

단계 2●○○

질문 하나 = input() 하나 = 상자 하나. 상자이름 = input("질문") 모양이에요.

단계 3●○○

상자 이름은 따옴표 밖에 써요. 글자와 상자는 +로 이어요. 단계 2에서 만든 상자 이름을 그대로 써야 해요.
