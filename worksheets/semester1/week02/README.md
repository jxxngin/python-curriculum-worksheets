## 🪜 단계 1: 첫 번째 질문 보여 주기

📌 목표: 이름과 1번 질문을 묻고 대답을 상자에 담는다.

> 🧰 **앞뒤 빈칸 지우기: strip()**: 대답 앞뒤에 실수로 넣은 빈칸(스페이스)을 지워요. `input()` 뒤에 점(`.`)을 찍고 붙여요.
>
> ```python
> pet = input("키우고 싶은 동물은? ").strip()
> ```
> → " 강아지 "라고 넣어도 "강아지"가 들어가요

## 🪜 단계 2: 고른 답에 따라 다른 말 하기

📌 목표: 1을 넣으면 치킨파, 2를 넣으면 피자파, 그 밖에는 안내가 나온다.

> 🧰 **갈림길: if / else와 ==**: `==`는 "두 값이 같나요?"라고 묻는 기호예요(`=`는 상자에 넣기). 맞으면 `if` 아래 줄, 아니면 `else` 아래 줄을 실행해요. 줄 끝에 `:`, 안쪽 줄은 4칸 들여 써요.
>
> ```python
> if weather == "비":
>     print("우산 챙기기")
> else:
>     print("밖에서 놀기")
> ```
> → weather가 "비"면 우산 챙기기

> 🧰 **갈림길 더하기: elif**: `if`가 아니면 다음 조건을 물어요. 위에서부터 처음 맞는 하나만 실행돼요.
>
> ```python
> if pick == "1":
>     print("1번")
> elif pick == "2":
>     print("2번")
> ```
> → pick이 "2"면 2번

① 기능 추가하기: `mini_starter.py`의 `# 단계 2` 아래에 입력

```python
if answer1 == "1":
    print("치킨파 " + name + "! 바삭바삭 최고!")
elif answer1 == "2":
    print("피자파 " + name + "! 치즈가 쭈욱~")
else:
    print("1이나 2만 골라 주세요.")
```

② 실행하고 확인: 1, 2, 3을 하나씩 넣어 3번 실행하고 나온 말 적기

✅ 넣을 때마다 다른 말이 나왔어요.

## 🚀 도전 프로젝트: 밸런스 게임 성향 테스트

**왜 만들까?** 인터넷의 성격 유형 테스트가 이 원리로 돌아가요. 답을 이어 붙여 코드로 만들고 코드에 따라 결과를 고르는 방법을 연습해요.

📌 목표: 질문 3개의 답으로 성향 코드(예: ABA)를 만들고, 코드마다 결과를 보여 준다.

> 🧰 **성향 코드: 이어 붙이고 비교하기**: 답을 `+`로 이어 붙이면 "AB" 같은 코드가 돼요. 그 코드를 `==`로 비교해요.

① 실행해 보기: `extension_starter.py`를 그대로 실행

② 설계하기: 주제를 고르고 질문 3개와 A·B 선택지를 표에 적기

주제: 급식 취향, 게임 스타일, 좀비 생존, 공부 스타일, 초능력, 여행 스타일 중 하나

|   | 질문 | A | B |
| --- | --- | --- | --- |
| Q1 |   |   |   |
| Q2 |   |   |   |
| Q3 |   |   |   |

질문이 3개면 성향 코드는 모두 ____가지예요.

③ 바꾸고 체크하기

- [ ] 주제를 골라 질문과 결과를 내 것으로 바꿨어요.
- [ ] 질문을 3개로 늘리고, 성향 코드마다 결과를 만들었어요.
- [ ] 결과마다 한 줄 설명이 나와요.

**➕ 더 해 보기**
