## 📇 개념 카드

### 카드 1. if: 만약 ~라면

조건이 맞으면 아래에 **들여쓰기(스페이스 4칸)** 된 줄을 실행해요. 조건 끝에는 꼭 `:`을 붙여요.

```python
answer = input("파이썬 좋아해요? ")
if answer == "네":
    print("저도요!")
print("이 줄은 항상 실행돼요.")
```

✋ **직접 해 보기:** "네" 말고 "응"을 입력하면 어떻게 되는지 확인해 보세요.

### 카드 2. == 와 =

`=`는 상자에 값을 **넣기**, `==`는 두 값이 **같은지 묻기**예요. 숫자처럼 보여도 `input()`으로 받은 값은 글자라서 `"1"`처럼 따옴표를 붙여 비교해요.

```python
pick = input("1 또는 2: ")   # 넣기
if pick == "1":              # 같은지 묻기
    print("1번을 골랐어요")
```

✋ **직접 해 보기:** `"1"`을 `1`(따옴표 없이)로 바꿔서 실행해 보세요. 무슨 일이 생기나요?

### 카드 3. elif와 else: 아니면?

`elif`는 "그게 아니고 만약 ~라면", `else`는 "위의 것이 모두 아니면"이에요. 위에서부터 차례로 검사해서 **처음 맞는 것 하나만** 실행해요.

```python
pick = input("1. 여름  2. 겨울: ")
if pick == "1":
    print("수박 먹자!")
elif pick == "2":
    print("눈사람 만들자!")
else:
    print("1이나 2를 골라 주세요")
```

✋ **직접 해 보기:** `3. 봄`을 추가해 보세요.

### 카드 4. strip(): 앞뒤 빈칸 지우기

실수로 스페이스를 넣고 입력하면 `" 1"`이 되어 `"1"`과 달라요. `strip()`이 앞뒤 빈칸을 지워 줘요.

```python
pick = input("번호: ").strip()
if pick == "1":
    print("정확히 1번!")
```

✋ **직접 해 보기:** `.strip()`을 지우고 스페이스+1을 입력해 보세요.
