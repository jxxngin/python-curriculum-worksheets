치킨이냐 피자냐, 그것이 문제로다! ⚖️ 둘 중 하나만 골라야 하는 밸런스 게임은 친구들과 하면 정말 재밌어요. 내가 고른 답에 따라 다른 말을 해 주는 프로그램을 만들어 봐요.

완성하면 이렇게 돼요:

```
⚖️ 밸런스 게임을 시작합니다! ⚖️
플레이어 이름: 하린
[1번 질문] 평생 한 가지만 먹어야 한다면?
1. 치킨   2. 피자
선택 (1 또는 2): 1
치킨파 하린! 바삭바삭 최고!

[2번 질문] 하나만 고른다면?
1. 하늘을 나는 능력   2. 순간 이동 능력
선택 (1 또는 2): 2
🏅 오늘의 칭호: [순간 이동하는] 하린
```

## 🔧 워밍업

`warmup.py`를 실행하고 오류 3개를 고쳐요. (고장 난 간식 고르기 고치기)

## 🪜 단계 1: 첫 번째 질문 보여 주기

> 🧰 **앞뒤 빈칸 지우기: strip()**: 대답 앞뒤에 실수로 넣은 빈칸(스페이스)을 지워 줘요. input() 뒤에 점(.)을 찍고 붙여요.

`mini_starter.py`의 `# 단계 1` 아래에 이어 써요.

```python
print("⚖️ 밸런스 게임을 시작합니다! ⚖️")
name = input("플레이어 이름: ")
print("[1번 질문] 평생 한 가지만 먹어야 한다면?")
print("1. 치킨   2. 피자")
answer1 = input("선택 (1 또는 2): ").strip()
```

✅ 제목과 1번 질문, 선택지가 나오고 번호를 넣을 수 있었어요.

## 🪜 단계 2: 고른 답에 따라 다른 말 하기

> 🧰 **갈림길 만들기: if / else와 ==**: ==는 "두 값이 같나요?"라고 묻는 기호예요(=는 상자에 넣기). 맞으면 if 아래 줄, 아니면 else 아래 줄을 실행해요. 줄 끝에 :, 안쪽 줄은 4칸 들여 써요.

> 🧰 **갈림길 더하기: elif**: if가 아니면 다음 조건을 또 물어봐요. 위에서부터 처음 맞는 하나만 실행돼요.

`mini_starter.py`의 `# 단계 2` 아래에 이어 써요.

```python
if answer1 == "1":
    print("치킨파 " + name + "! 바삭바삭 최고!")
elif answer1 == "2":
    print("피자파 " + name + "! 치즈가 쭈욱~")
else:
    print("앗, 1이나 2만 골라 주세요.")
```

✅ 1, 2, 3을 하나씩 넣어 3번 실행했어요. / 넣을 때마다 다른 말이 나왔어요.

## 🪜 단계 3: 두 번째 질문 보여 주기

`mini_starter.py`의 `# 단계 3` 아래에 이어 써요.

```python
print("")
print("[2번 질문] 하나만 고른다면?")
print("1. 하늘을 나는 능력   2. 순간 이동 능력")
answer2 = input("선택 (1 또는 2): ").strip()
```

✅ 한 줄 띄고 2번 질문이 나왔어요.

## 🪜 단계 4: 오늘의 칭호 붙여 주기

`mini_starter.py`의 `# 단계 4` 아래에 이어 써요.

```python
title = "엉뚱한"
if answer2 == "1":
    title = "구름 위를 나는"
elif answer2 == "2":
    title = "순간 이동하는"
print("🏅 오늘의 칭호: [" + title + "] " + name)
```

✅ 마지막에 내 칭호가 나왔어요. / 1·2가 아닌 답이면 "엉뚱한" 칭호가 나왔어요.
