## 1쪽 · 워밍업

| 줄 | 오류 이름 | 고친 방법 |

- 확인할 점: 조건이 맞으면 나머지 elif/else는 건너뛴다.

## 2쪽 · 개념 카드

| 카드 | 예상 실행 화면 |
| --- | --- |
| 1 ("응") | `파이썬 좋아해요? 응` / `이 줄은 항상 실행돼요.` |
| 2 (1 입력) | `1번을 골랐어요`. 코드의 `"1"`을 `1`로 바꾸면 아무것도 안 나온다(글자 `"1"` ≠ 숫자 `1`). |
| 3 ("3") | `1이나 2를 골라 주세요` |
| 4 (스페이스+1) | `정확히 1번!`. `.strip()`을 지우면 `" 1"` ≠ `"1"`이라 아무것도 안 나온다. |

**직접 해 보기:** `elif`는 `else`보다 위에 써야 한다.

```python
elif pick == "3":
    print("꽃구경 가자!")
```

**생각해 보기:** `=`는 변수에 값을 넣을 때 쓰고, `==`는 두 값이 같은지 물어볼 때 쓴다(if 조건).

## 3쪽 · 미니 프로젝트

**따라 하기 빈칸:** ① `strip` ② `==` ③ `if` ④ `elif` ⑤ `else`

**2단계:** 선택지 3개짜리 질문은 `elif`가 2번 들어간다(`if 1 / elif 2 / elif 3 / else`).

## 4쪽 · 확장 프로젝트

- 결과 코드 8가지: AAA, AAB, ABA, ABB, BAA, BAB, BBA, BBB
- 경우의 수: 2 × 2 × 2 = **8가지**
- 소문자 처리: 답을 받자마자 `if q1 == "a": q1 = "A"`처럼 바꾸면, 결과 조건(8개)은 그대로 둬도 된다.
