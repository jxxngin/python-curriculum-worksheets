🧰 도구 카드 · 앞뒤 빈칸 지우기: strip()

대답 앞뒤에 실수로 넣은 빈칸(스페이스)을 지워 줘요. input() 뒤에 점(.)을 찍고 붙여요.

pet = input("키우고 싶은 동물은? ").strip()

→ " 강아지 "라고 넣어도 pet 상자에는 "강아지"가 들어가요

🧰 도구 카드 · 갈림길 만들기: if / else와 ==

==는 "두 값이 같나요?"라고 묻는 기호예요(=는 상자에 넣기). 맞으면 if 아래 줄, 아니면 else 아래 줄을 실행해요. 줄 끝에 :, 안쪽 줄은 4칸 들여 써요.

if weather == "비":    print("우산 챙겨요!")else:    print("신나게 놀아요!")

→ weather가 "비"면 우산 챙겨요!, 아니면 신나게 놀아요!

🧰 도구 카드 · 갈림길 더하기: elif

if가 아니면 다음 조건을 또 물어봐요. 위에서부터 처음 맞는 하나만 실행돼요.

if pick == "1":    print("1번을 골랐어요")elif pick == "2":    print("2번을 골랐어요")

→ pick이 "2"면 2번을 골랐어요

⌨️ 따라 쓸 코드

답 두 개를 +로 이어 붙이면 "AB" 같은 코드가 돼요. 그 코드를 ==로 비교해요.

code = "B" + "A"if code == "BA":    print("자유로운 탐험가")

→ 자유로운 탐험가

질문이 3개면 성향 코드는 모두 가지예요.

  • 주제를 골라 질문과 결과를 내 것으로 바꿨어요.
  • 질문을 3개로 늘리고, 성향 코드마다 결과를 만들었어요.
  • 결과마다 한 줄 설명이 나와요.
➕ 더 해 보기

  • A·B가 아닌 답을 넣으면 else로 안내하기
