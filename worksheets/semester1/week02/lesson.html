🧰 앞뒤 빈칸 지우기: strip()

대답 앞뒤에 실수로 넣은 빈칸(스페이스)을 지워요. input() 뒤에 점(.)을 찍고 붙여요.

pet = input("키우고 싶은 동물은? ").strip()

→ " 강아지 "라고 넣어도 "강아지"가 들어가요

단계 2 고른 답에 따라 다른 말 하기

📌 목표: 1을 넣으면 치킨파, 2를 넣으면 피자파, 그 밖에는 안내가 나온다.
🧰 갈림길: if / else와 ==

==는 "두 값이 같나요?"라고 묻는 기호예요(=는 상자에 넣기). 맞으면 if 아래 줄, 아니면 else 아래 줄을 실행해요. 줄 끝에 :, 안쪽 줄은 4칸 들여 써요.

if weather == "비":    print("우산 챙기기")else:    print("밖에서 놀기")

→ weather가 "비"면 우산 챙기기

🧰 갈림길 더하기: elif

if가 아니면 다음 조건을 물어요. 위에서부터 처음 맞는 하나만 실행돼요.

if pick == "1":    print("1번")elif pick == "2":    print("2번")

→ pick이 "2"면 2번

🚀 도전 프로젝트 밸런스 게임 성향 테스트 · 일찍 끝낸 사람

왜 만들까? 인터넷의 성격 유형 테스트가 이 원리로 돌아가요. 답을 이어 붙여 코드로 만들고 코드에 따라 결과를 고르는 방법을 연습해요.

📌 목표: 질문 3개의 답으로 성향 코드(예: ABA)를 만들고, 코드마다 결과를 보여 준다.
🧰 성향 코드: 이어 붙이고 비교하기

답을 +로 이어 붙이면 "AB" 같은 코드가 돼요. 그 코드를 ==로 비교해요.

code = "B" + "A"if code == "BA":    print("자유로운 탐험가")

→ 자유로운 탐험가
