# 8주차 교사 가이드: 탐정의 용의자 명단

## 수업 목표

- 리스트에 여러 값을 담고 칸 번호(0부터)로 꺼낸다.
- `append()`로 값을 더하고, `in` / `not in`으로 들어 있는지 확인한다.
- `random.choice()`로 리스트에서 하나를 무작위로 고른다. (보너스: `random.shuffle()`)
- (도전) 이긴 후보를 새 리스트에 모으고 라운드마다 바꿔 끼운다.

## 핵심 설명 포인트

- 리스트는 "칸이 여러 개인 상자" 또는 "기차"다. 칸 번호가 0부터라는 점을 워밍업(메시지 없는 오류)과 단계 1에서 두 번 확인한다.
- `print(suspects)`는 대괄호와 따옴표까지 그대로 보여 준다. 화면의 `['옆집 고양이', …]`가 리스트 모양이라는 것만 짚는다.
- `append()`는 리스트에 붙어 있는 기능이라 `리스트.append(값)`처럼 점을 찍는다. 워밍업의 `.add`는 리스트에 없는 기능이라 AttributeError가 난다.
- `in`은 결과가 True/False다(6주 깃발과 연결). `not in`은 6주의 `not`과 같은 뜻이다.
- 단계 4는 7주의 `while` + `continue`를 다시 쓴다. 명단에 없는 이름은 `continue`로 돌아가 기회(`tries`)를 쓰지 않는다. 따라가기의 "피자" 바퀴가 이것을 보여 준다.
- `random.choice()`는 매번 새로 뽑는다. 같은 사람이 다시 범인이 되어도 정상이다. 수업 중 확인이 필요하면 `print(culprit)`을 잠깐 넣고, 끝나면 줄 맨 앞에 `#`을 붙이게 한다.
- `len()`과 `for`는 2학기 개념이다. 도전 시작 파일이 후보 수를 `size = 8`로 직접 적은 까닭이다. 물어보면 "2학기에 배운다"로 넘긴다.
- `random.shuffle()`은 커리큘럼의 보너스다. 바꾸기의 더 해 보기와 도전의 더 해 보기에만 두었다.

## 자주 나오는 오류와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| `SyntaxError` (리스트 줄) | 따옴표·쉼표·대괄호 짝이 안 맞음 | 이름마다 따옴표, 이름 사이에 쉼표, `[` `]` 짝 |
| `AttributeError: 'list' object has no attribute …` | `add`, `apend`처럼 함수 이름이 틀림 | `append` |
| `IndexError: list index out of range` | 없는 칸 번호 | 칸 번호는 0부터, 칸 수보다 하나 작은 번호까지 |
| `NameError: name 'random' is not defined` | `import random`이 없거나 아래에 있음 | `random.choice()`보다 위에 |
| 명단에 있는데 "없는 사람" | 띄어쓰기·글자가 다름 | 명단과 똑같이 입력 |
| 정답을 맞혀도 계속 물음 | `break` 들여쓰기 | `if guess == culprit:` 아래 8칸 |

## 워밍업 정답

순서: 8번(메시지 없음, 실행하면 첫 줄에 바로 보인다) → 10번(AttributeError) → 12번(IndexError).

1. 8번째 줄: `snacks[1]` → `snacks[0]` (첫 번째 후보가 `과자`로 나온다)
2. 10번째 줄: `snacks.add(...)` → `snacks.append("아이스크림")` (AttributeError, 힌트 블록의 `워밍업` 카드에 고치는 모양이 있다)
3. 12번째 줄: `snacks[4]` → `snacks[3]` (IndexError, 4칸이라 번호는 0~3)

다 고치면 `마지막 후보: 아이스크림`, `🍬 오늘의 간식: …`이 나온다. 오늘의 간식은 넷 중 하나를 새로 뽑으므로 친구와 달라도, 같은 간식이 또 나와도 정상이다.
