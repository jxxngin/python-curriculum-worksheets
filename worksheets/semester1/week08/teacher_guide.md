# 8주차 교사 가이드: 탐정의 용의자 명단

## 수업 목표

- 리스트를 만들고 인덱스(0부터)로 값을 꺼낸다.
- append()로 리스트에 값을 추가한다.
- in / not in으로 포함 여부를 검사한다.
- random.choice()로 무작위 선택, (보너스) random.shuffle()로 섞기.

## 핵심 설명 포인트

- 리스트는 "칸이 여러 개인 변수". 지금까지는 변수 하나에 값 하나였지만, 리스트는 한 이름으로 여러 값을 관리한다.
- 인덱스는 0부터. 4칸짜리 리스트의 마지막 칸은 `[3]`. IndexError가 나면 "칸 수 - 1"을 넘었는지 확인.
- `print(리스트)`는 `['a', 'b']`처럼 대괄호와 따옴표까지 보인다. 예쁘게 출력하는 법(for, join)은 2학기 이후. 이번 주는 그대로 보여 줘도 된다.
- append는 `리스트.append(값)`처럼 점(.) 뒤에 붙이는 함수(메서드)다. `append(snacks, 값)`이나 `snacks = snacks.append(값)`(결과가 None)은 흔한 실수.
- in은 6주의 조건식과 같이 True/False를 낸다. `not in`은 6주 not의 연장으로 설명.
- random.choice는 리스트가 있어야 쓸 수 있다. 4주의 randint와 비교: "숫자 범위에서 뽑기 vs 명단에서 뽑기".
- shuffle은 결과를 돌려주지 않고 리스트 자체를 바꾼다. `colors = random.shuffle(colors)`로 쓰면 None이 된다.
- len(), for, remove()는 2학기 4주 내용이라 이번 주에 쓰지 않는다. 확장 월드컵은 후보 수를 `size` 변수로 따로 관리하고 `while i < size` + `i = i + 2`로 순회한다. 학생이 len()을 알고 있으면 "2학기에 정식으로 배운다"고만 말해 준다.
- 미니 따라 하기 starter는 빈칸 4(`in` 자리)가 키워드라서 채우기 전에는 SyntaxError가 나는 것이 정상이다(7주와 같다).

## 자주 나오는 오류와 대처

| 증상 | 원인 | 대처 |
| --- | --- | --- |
| `SyntaxError: '[' was never closed` | 닫는 대괄호 누락 | 괄호 짝 세기 |
| `IndexError: list index out of range` | 칸 수 이상 번호 사용 | 0부터 세기, 기차 그림 |
| `AttributeError: ... has no attribute 'add'` | 함수 이름 착각(add, push) | `append` |
| 리스트가 `None`이 됨 | `x = x.append(...)` 또는 `x = random.shuffle(x)` | 대입 없이 호출만 |
| 명단에 있는데 "없다"고 나옴 | 띄어쓰기·앞뒤 공백 차이 | `.strip()`, 정확히 같은 글자 |
| 월드컵이 같은 대결을 건너뜀/반복 | `i = i + 2` 위치·continue 순서 | `print(i)`로 i 값 추적 |
| `IndexError` (월드컵 `i + 1`) | size가 실제 후보 수와 다름(홀수 등) | 후보 수를 2의 거듭제곱(8, 16)으로 |

## 워밍업 정답

1. 7번째 줄: `snacks = ["젤리", "과자", "초콜릿"` → 끝에 `]` (SyntaxError)
2. 10번째 줄: `snacks.add(...)` → `snacks.append(...)` (AttributeError)
3. 12번째 줄: `snacks[4]` → `snacks[3]` (IndexError, 네 번째 칸은 3번)

## 미니 따라 하기 정답

빈칸 1 `0`, 빈칸 2 `append`, 빈칸 3 `choice`, 빈칸 4 `in`

## 진도 차이 대응

- 빠른 학생: 미니 3단계(조사 기록, 공범 모드) → 확장 월드컵 16강.
- 느린 학생: 따라 하기 + 사건 바꾸기 + 용의자 여러 명 추가(while + append)까지 최소 목표. 중복 검사는 힌트를 보고 따라 써도 된다.
- 중고등: 월드컵의 "라운드 반복 안에 대결 반복" 구조(중첩 while)와 `candidates = winners` 교체가 핵심. 탈락자 리스트까지 하면 다음 주 설계도에 쓸 만한 리스트 활용이 된다.
- 9주는 설계와 보충 주간이다. 1~8주 개념이 흔들리는 학생은 보충 문제로, 나머지는 기말 설계도로 들어간다고 예고한다.
