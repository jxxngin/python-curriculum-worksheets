📌 목표: 용의자 3명을 리스트에 담아 보여 주고, 첫 번째 용의자를 꺼낸다.
🧰 여러 값을 한 상자에: 리스트

대괄호 [ ] 안에 쉼표로 값을 늘어놓아요. 칸 번호는 0부터 세고, 이름[번호]로 꺼내요.

→ 떡볶이, 라면

단계 2 수상한 사람 더하기

📌 목표: 수상한 사람을 한 명 물어 명단 맨 뒤에 더한다.
🧰 맨 뒤에 붙이기: append()

리스트.append(값)은 리스트 맨 뒤에 값을 하나 붙여요. 빈 리스트 []에서 시작해도 돼요.

team = []team.append("지우")print(team)

→ ['지우']

단계 4 명단에 있는 사람만 조사하기

📌 목표: 범인을 3번 묻고, 명단에 없는 이름은 기회를 쓰지 않고 다시 묻는다.
🧰 들어 있나요?: in, not in

값 in 리스트는 들어 있으면 True예요. not in은 반대예요.

foods = ["떡볶이", "김밥"]print("김밥" in foods)print("피자" not in foods)

→ True, True

새 상자 checked = [](반복 전에). if guess in checked:면 알려 주고 continue, 아니면 checked.append(guess).

주석이 알려 주는 두 자리에 넣어요.

도전우승까지 반복 · 무엇부터 할지 모를 때●○○

지금 반복 전체가 라운드 하나예요. 그 반복을 큰 반복으로 감싸서 후보가 1명 남을 때까지 되풀이해요.

도전우승까지 반복 · 쓸 도구가 떠오르지 않을 때●●○

while size > 1: 안에 winners = [], i = 0, 지금의 대결 반복을 넣어요. 라운드가 끝나면 candidates = winners, size = size // 2.

도전우승까지 반복 · 거의 다 됐는데 안 될 때●●●

시작 파일의 winners = []부터 끝까지를 아래로 바꿔 써요.

while size > 1:    winners = []    i = 0    while i < size:        left = candidates[i]        right = candidates[i + 1]        print(f"1번 {left}  VS  2번 {right}")        pick = input("더 좋은 쪽 번호(1/2): ").strip()        if pick == "1":            winners.append(left)        else:            winners.append(right)        i = i + 2    candidates = winners    size = size // 2print(f"우승: {candidates[0]}")
