## 🎯 오늘의 미션

용의자 명단(리스트)에 사람을 더하고, 컴퓨터가 몰래 고른 범인을 3번 안에 찾는 추리 게임을 만들어요.

**오늘의 목표**

- 리스트에 여러 값을 담고 칸 번호(`[0]`)로 꺼낼 수 있다.
- `append()`로 리스트에 값을 더하고, `in`으로 들어 있는지 확인할 수 있다.
- `random.choice()`로 리스트에서 하나를 무작위로 고를 수 있다.

완성하면 이렇게 돼요:

```
사라진 생일 케이크 사건

가장 먼저 의심받는 사람: 옆집 고양이
수상한 사람을 한 명 더 적어 주세요: 옆 반 친구
새 명단: ['옆집 고양이', '배고픈 동생', '택배 기사님', '옆 반 친구']
범인이 정해졌어요. 기회는 3번!
범인은 누구일까요? 택배 기사님

범인은 누구일까요? 옆 반 친구
정답! 범인을 찾았어요.
사건 기록: 범인은 옆 반 친구
```

## 🪜 단계 1: 용의자 명단 만들기

📌 목표: 용의자 3명을 리스트에 담아 보여 주고, 첫 번째 용의자를 꺼낸다.

> 🧰 **여러 값을 한 상자에: 리스트**: 대괄호 `[ ]` 안에 쉼표로 값을 늘어놓아요. 칸 번호는 0부터 세고, `이름[번호]`로 꺼내요.
>
> ```python
> foods = ["떡볶이", "김밥", "라면"]
> print(foods[0])
> print(foods[2])
> ```
> → 떡볶이, 라면

① 기능 추가하기: `mini_starter.py`의 `# 단계 1` 아래에 입력

```python
print("사라진 생일 케이크 사건")
suspects = ["옆집 고양이", "배고픈 동생", "택배 기사님"]
print(f"용의자 명단: {suspects}")
print(f"가장 먼저 의심받는 사람: {suspects[0]}")
```

② 실행하고 확인: 마지막 줄 적기

✅ 명단과 첫 번째 용의자가 나왔어요.

## 🪜 단계 2: 수상한 사람 더하기

📌 목표: 수상한 사람을 한 명 물어 명단 맨 뒤에 더한다.

> 🧰 **맨 뒤에 붙이기: append()**: `리스트.append(값)`은 리스트 맨 뒤에 값을 하나 붙여요. 빈 리스트 `[]`에서 시작해도 돼요.
>
> ```python
> team = []
> team.append("지우")
> print(team)
> ```
> → ['지우']

① 기능 추가하기: `mini_starter.py`의 `# 단계 2` 아래에 입력

```python
new = input("수상한 사람을 한 명 더 적어 주세요: ").strip()
suspects.append(new)
print(f"새 명단: {suspects}")
```

② 실행하고 확인: "새 명단" 줄 적기

✅ 내가 적은 사람이 명단 맨 뒤에 붙었어요.

## 🪜 단계 3: 범인 몰래 뽑기

📌 목표: 명단에서 범인을 무작위로 한 명 고르고, 기회 상자를 0으로 준비한다.

> 🧰 **무작위로 하나 고르기: random.choice()**: 리스트에서 하나를 무작위로 골라요. 쓰기 전에 `import random`이 있어야 해요.
>
> ```python
> import random
> colors = ["빨강", "파랑", "노랑"]
> print(random.choice(colors))
> ```
> → 셋 중 하나를 새로 뽑아요. 같은 색이 또 나올 수도 있어요

① 기능 추가하기: `mini_starter.py`의 `# 단계 3` 아래에 입력

```python
import random
culprit = random.choice(suspects)
tries = 0
print("범인이 정해졌어요. 기회는 3번!")
```

② 실행하고 확인: 마지막 줄 적기

✅ 범인이 정해졌다는 말이 나왔어요. 범인은 아직 비밀이에요.

## 🪜 단계 4: 명단에 있는 사람만 조사하기

📌 목표: 범인을 3번 묻고, 명단에 없는 이름은 기회를 쓰지 않고 다시 묻는다.

> 🧰 **들어 있나요?: in, not in**: `값 in 리스트`는 들어 있으면 `True`예요. `not in`은 반대예요.
>
> ```python
> foods = ["떡볶이", "김밥"]
> print("김밥" in foods)
> print("피자" not in foods)
> ```
> → True, True

① 기능 추가하기: `mini_starter.py`의 `# 단계 4` 아래에 입력

```python
while tries < 3:
    guess = input("범인은 누구일까요? ").strip()
    if guess not in suspects:
        print("명단에 없는 사람이에요.")
        continue
    tries = tries + 1
```

② 실행하고 확인: 수상한 사람으로 삼촌을 적은 뒤, 표의 이름을 차례로 넣고 어떻게 됐는지 적기

✅ 명단에 없는 이름은 알려 주고, 명단에 있는 이름을 3번 넣으니 끝났어요.

## 🪜 단계 5: 범인 판정하기

📌 목표: 범인을 맞히면 바로 멈추고, 틀리면 알리바이를 알려 주고, 마지막에 범인을 공개한다.

    if guess == culprit:

② 실행하고 확인: 마지막 줄 적기

✅ 맞히면 "정답!"이 나오고 바로 사건 기록이 나왔어요. / 3번 다 틀리면 사건 기록에서 범인을 알려 줬어요.

③ 따라가기: 범인이 배고픈 동생이고, 새 사람으로 삼촌을 적은 뒤 택배 기사님 / 피자 / 배고픈 동생을 넣으면?

## 🚀 도전 프로젝트: 이상형 월드컵

**왜 만들까?** 후보를 둘씩 붙여 이긴 쪽만 새 리스트에 모으는 방식은 토너먼트 대진표와 같아요. 리스트를 라운드마다 새로 만들고 바꿔 끼우는 연습이에요.

📌 목표: 후보 8개로 우승자가 나올 때까지 이어지는 월드컵을 만든다. 시작 파일은 8강 한 라운드만 하고 4강 진출 명단을 보여 준다. 내 주제로 바꾸고, 우승자가 나올 때까지 라운드를 되풀이하고, 1·2가 아닌 입력은 같은 대결을 다시 묻게 한다.

> 🧰 **리스트 바꿔 끼우기**: `candidates = winners`처럼 쓰면 이긴 후보 리스트가 다음 라운드의 후보가 돼요. 새 라운드 전에 `winners = []`로 비워요.

① 실행해 보기: `extension_starter.py`를 그대로 실행

② 대진표 적기: 내 주제와 후보 8개를 칸 번호 아래에 적고, 시작 파일을 실행해 질문에 답하기

시작 파일에서 1만 계속 넣으면 4강에는 몇 번 칸 후보들이 올라가나요? ____

③ 바꾸고 체크하기

- [ ] 주제와 후보 8개를 내 것으로 바꿨어요.
- [ ] 우승자가 나올 때까지 라운드를 되풀이해요. (`candidates = winners`, `size = size // 2`)

<details>
<summary>[새로 만들기] 조사 기록 · 쓸 도구가 떠오르지 않을 때 ●●○</summary>

새 상자 `checked = []`(반복 전에). `if guess in checked:`면 알려 주고 `continue`, 아니면 `checked.append(guess)`.

</details>

<details>
<summary>[새로 만들기] 조사 기록 · 거의 다 됐는데 안 될 때 ●●●</summary>

주석이 알려 주는 두 자리에 넣어요.

```python
# 단계 3의 tries = 0 아래에
checked = []
# 단계 4의 tries = tries + 1 바로 위에
    if guess in checked:
        print("이미 조사한 사람이에요.")
        continue
    checked.append(guess)
```

</details>

<details>
<summary>[도전] 우승까지 반복 · 무엇부터 할지 모를 때 ●○○</summary>

지금 반복 전체가 라운드 하나예요. 그 반복을 큰 반복으로 감싸서 후보가 1명 남을 때까지 되풀이해요.

</details>

<details>
<summary>[도전] 우승까지 반복 · 쓸 도구가 떠오르지 않을 때 ●●○</summary>

`while size > 1:` 안에 `winners = []`, `i = 0`, 지금의 대결 반복을 넣어요. 라운드가 끝나면 `candidates = winners`, `size = size // 2`.

</details>

<details>
<summary>[도전] 우승까지 반복 · 거의 다 됐는데 안 될 때 ●●●</summary>

시작 파일의 `winners = []`부터 끝까지를 아래로 바꿔 써요.

```python
while size > 1:
    winners = []
    i = 0
    while i < size:
        left = candidates[i]
        right = candidates[i + 1]
        print(f"1번 {left}  VS  2번 {right}")
        pick = input("더 좋은 쪽 번호(1/2): ").strip()
        if pick == "1":
            winners.append(left)
        else:
            winners.append(right)
        i = i + 2
    candidates = winners
    size = size // 2
print(f"우승: {candidates[0]}")
```

</details>
