## 📇 개념 카드

### 카드 1. 리스트: 여러 값을 담는 기차

대괄호 `[ ]` 안에 쉼표로 값을 나열해요. 칸 번호는 **0부터** 시작해요.

```python
foods = ["떡볶이", "김밥", "라면"]
print(foods)
print(foods[0])     # 떡볶이
print(foods[2])     # 라면
```

✋ **직접 해 보기:** 내가 좋아하는 과일 4개로 리스트를 만들고 마지막 과일만 출력해 보세요.

### 카드 2. append(): 맨 뒤에 붙이기

`리스트.append(값)`은 리스트의 맨 뒤에 값을 하나 붙여요. 빈 리스트 `[]`에서 시작해도 돼요.

```python
team = []
team.append("지우")
team.append("민호")
print(team)          # ['지우', '민호']
```

✋ **직접 해 보기:** `while`로 이름을 3번 입력받아 `team`에 붙여 보세요.

### 카드 3. in: 들어 있나요?

`값 in 리스트`는 들어 있으면 `True`, 없으면 `False`예요. `not in`은 반대예요.

```python
foods = ["떡볶이", "김밥", "라면"]
print("김밥" in foods)      # True
if "피자" not in foods:
    print("피자는 없어요")
```

✋ **직접 해 보기:** 메뉴를 입력받아 리스트에 있으면 "주문 완료", 없으면 "품절"을 출력해 보세요.

### 카드 4. random.choice()와 shuffle()

`random.choice(리스트)`는 하나를 무작위로 골라 줘요. 보너스로 `random.shuffle(리스트)`는 리스트 순서를 섞어요.

```python
import random
colors = ["빨강", "파랑", "노랑"]
print(random.choice(colors))
random.shuffle(colors)
print(colors)
```

✋ **직접 해 보기:** 오늘의 청소 당번을 뽑는 프로그램을 만들어 보세요.

## 🧪 확장 프로젝트 퀘스트: 이상형 월드컵 🏆

> 중고등학생은 미니 1단계 후 이 퀘스트가 **오늘의 완성 기준**이에요. 초등학생은 미니를 마친 뒤 선택해요.

`extension_starter.py`는 그대로 실행돼요. 후보 8개를 둘씩 붙여서 이긴 쪽을 새 리스트 `winners`에 `append()`해요. 지금은 8강에서 끝나요. 칸 번호 `i`와 `i + 1`로 두 후보를 꺼내고, `i = i + 2`로 다음 짝으로 넘어가는 부분을 디버거로 살펴보세요.

바꾸기 (완성 기준)
- [ ] 주제와 후보 8개를 내 것으로 바꿨어요.
- [ ] 우승자가 나올 때까지 반복해요. (`candidates = winners`, 후보 수 `size`는 절반으로)
- [ ] 라운드마다 "8강 / 4강 / 결승" 제목을 보여 줘요.
- [ ] 1, 2가 아닌 입력은 같은 대결을 다시 물어봐요. (`continue`)
- [ ] 보너스: `random.shuffle()`로 대진표를 섞어요.

새로 만들기 (선택): 💡 탈락자 명단 리스트 💡 `?`를 입력하면 컴퓨터가 `random.choice()`로 대신 골라 주기 💡 16강으로 늘리기

<details>
<summary>힌트 1 (방향)</summary>

지금 있는 "한 라운드" 반복을 통째로 또 하나의 `while` 안에 넣어요. 라운드가 끝나면 이긴 후보 리스트가 다음 라운드의 후보가 되고, 후보 수는 절반이 돼요. 후보가 1개 남으면 멈춰요.

</details>

<details>
<summary>힌트 2 (사용할 함수)</summary>

`while size > 1:` 안에서 `winners = []`, `i = 0`으로 매 라운드 새로 시작. 라운드 끝에 `candidates = winners`, `size = size // 2`. 우승자는 `candidates[0]`.

</details>

<details>
<summary>힌트 3 (거의 코드)</summary>

```python
while size > 1:
    winners = []
    i = 0
    while i < size:
        # (원래 있던 대결 코드)
        i = i + 2
    candidates = winners
    size = size // 2
print(f"우승: {candidates[0]}")
```

</details>
