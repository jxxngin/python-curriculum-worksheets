## 2쪽 · 개념 카드

| 카드 | 예상 실행 화면 |
| --- | --- |
| 1 | `떡볶이` / `라면` |
| 2 | `['지우', '민호']` |
| 3 | `True` / `True` |
| 4 | 빨강·파랑·노랑 중 하나 / 섞인 리스트 (예: `['노랑', '빨강', '파랑']`). 실행할 때마다 다르다. |

**직접 해 보기 (예시)**

```python
import random
friends = ["지우", "민호", "서연"]
new = input("이름 하나 더: ").strip()
friends.append(new)
print(f"청소 당번: {random.choice(friends)}")
```

**생각해 보기:** 4개면 마지막 칸 번호는 **3**이다(0부터 센다). `foods[4]`는 IndexError가 난다.

## 3쪽 · 미니 프로젝트

**따라 하기 빈칸:** ① `0` ② `append` ③ `choice` ④ `in`

- ①을 쓰면 첫 줄 출력은 `가장 먼저 의심받는 사람: 옆집 고양이`다.

**2단계 확인 포인트**
- 용의자를 '끝'까지 추가하려면 `while True:` + `if new == "끝": break`가 필요하다.
- 이미 있는 이름은 `if new in suspects:`로 검사한다.

## 4쪽 · 확장 프로젝트 (이상형 월드컵)

- 대진표는 학생마다 다르다. 8강 → 4강 4칸 → 결승 2칸 → 우승 1칸 구조면 된다.
- 반복 구조: `while size > 1:` 안에서 라운드를 진행하고, 끝날 때 `candidates = winners`, `size = size // 2`로 바꾼다.
- 라운드 제목은 size가 8이면 8강, 4면 4강, 2면 결승이다.
