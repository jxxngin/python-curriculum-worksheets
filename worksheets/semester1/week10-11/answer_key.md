# 10~11주차 워크시트 정답지: 기말 프로젝트

교사용. 프로젝트 주간이라 대부분 학생마다 답이 다르다. 정답이 있는 칸과 확인할 점을 정리했다.

## 1쪽 · 워밍업 (탐험가의 가방)

| 줄 | 오류 이름 | 고친 방법 |
| --- | --- | --- |
| 9 | AttributeError (`module 'time' has no attribute 'slep'`) | `time.sleep(2)` |
| 14 | SyntaxError (`expected ':'`) | `if want in items:` |
| 18 | NameError (`name 'tries' is not defined`) | while 전에 `tries = 0`. 없는 물건을 입력해야 나타난다. |

**디버거 미션** ("칼" → "지도")

| 입력 | want in items | tries | 반복이 끝났나요? |
| --- | --- | --- | --- |
| 칼 | False | 1 | 아니요 |
| 지도 | True | 1 (그대로) | 예 (break) |

## 2쪽 · 명령 카드 time.sleep()

**예상 실행 화면:** `문을 여는 중...` → (2초 멈춤) → `철컥! 문이 열렸어요.`

**직접 해 보기 (예시)**

```python
import time
n = 3
while n > 0:
    print(n)
    time.sleep(1)
    n = n - 1
print("시작!")
```

**최소 완성 기준:** 커리큘럼 기준과 같다. 채점은 이 체크리스트로 한다.

## 3~4쪽 · 일정표와 주제별 설계 확인할 점

- 10주 2교시까지 최소 기준을 모두 만들었는가. 늦으면 11주 1교시에 마무리하고, 추가 기능은 최소 기준을 다 채운 뒤에 한다.
- 방탈출: 탈출 판정은 `"3번 열쇠" in keys`처럼 리스트 검사로 한다. 목숨이 0이면 반복을 멈추고 실패를 출력한다.
- 펫: 수치가 0~10을 넘지 않게 자르는 코드가 있는가. 행복도 계산식과 성공 기준이 실제로 달성 가능한가(예: `happy = mood * 10 - hunger * 5`, 기준 60).
- 창업: 하루 평균 수입 × 7일이 목표 금액과 비슷한가. 너무 쉽거나 너무 어려우면 목표를 조정한다.

## 5쪽 · 발표 평가표

정답이 없다. 기준은 최소 완성 기준 충족, 4개 개념(조건·while·리스트·random) 사용, 성공·실패 모두 오류 없이 실행되는가다.
