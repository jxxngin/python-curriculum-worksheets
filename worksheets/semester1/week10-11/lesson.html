방탈출방 3개를 어떻게 만들지 모를 때●○○

"방 반복" 안에 "문제 반복"이 들어 있어요. 바깥 반복은 방 번호(1~3), 안쪽 반복은 맞힐 때까지예요.

방탈출목숨이 0이 돼도 계속될 때●●○

바깥은 while room <= 3 and lives > 0:, 안쪽은 while lives > 0:. 틀리면 lives = lives - 1, 맞히면 keys.append(...) 뒤 break.

방탈출방 반복이 거의 다 됐는데 안 될 때●●●

시작 파일의 print("\n=== 1번 방…")부터 끝까지를 아래로 바꿔 써요. 방마다 다른 문제는 if room == 2:로 나누고, 맨 아래에서 if "3번 열쇠" in keys:로 탈출을 판정해요.

room = 1while room <= 3 and lives > 0:    print(f"=== {room}번 방 ===")    while lives > 0:        a = random.randint(1, 20)        b = random.randint(1, 20)        reply = int(input(f"{a} + {b} = "))        if reply == a + b:            keys.append(f"{room}번 열쇠")            print("철컥! 열쇠를 얻었어요.")            break        lives = lives - 1        print(f"땡! 남은 목숨: {lives}")    room = room + 1
펫행동을 어떻게 더할지 모를 때●○○

if action == "1": 덩어리 아래에 elif action == "2":, elif action == "3":을 이어 써요. 질문 글자에도 2·3번을 보여 줘요.

펫수치가 10을 넘거나 0보다 작아질 때●●○

if mood > 10: 안에서 mood = 10, if mood < 0: 안에서 mood = 0. 배고픔도 같아요. 턴 끝(turn = turn + 1 위)에 넣어요.

펫행복도 판정이 거의 다 됐는데 안 될 때●●●

시작 파일 맨 아래(반복 밖, 0칸)에 넣어요.

happy = mood * 10 - hunger * 5print(f"행복도: {happy}점")if happy >= 60:    print("성공! 행복한 하루였어요.")else:    print("실패... 내일 다시 도전!")
창업무엇부터 할지 모를 때●○○

하루 = 반복 한 번이에요. 상품 고르기 → 가격 → 손님 수(무작위) → 사건 → 매출 순서로 만들어요.

창업상품을 고르게 하고 싶을 때●●○

item = input("오늘 팔 상품: ").strip()을 받고, if item not in products:면 알려 주고 continue. 새 상품은 products.append(...).

창업목표 금액 판정이 거의 다 됐는데 안 될 때●●●

goal 줄은 반복 전(money = 10000 아래)에, 판정은 맨 아래(0칸)에 넣어요.

goal = 50000if money >= goal:    print(f"목표 {goal}원 달성!")else:    print(f"목표까지 {goal - money}원 부족해요.")
새로 만들기무작위 사건 · 무엇부터 할지 모를 때●○○

한 턴(한 방·하루)이 끝날 때마다 주사위를 굴려, 정한 숫자가 나오면 사건이 일어나게 해요.

새로 만들기무작위 사건 · 쓸 도구가 떠오르지 않을 때●●○

새 상자 event(random.randint(1, 6)). if event == 1:이면 사건 1, elif event == 2:면 사건 2. 나머지 숫자는 아무 일도 없어요.

새로 만들기무작위 사건 · 거의 다 됐는데 안 될 때●●●
