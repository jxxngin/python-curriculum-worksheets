## 🃏 명령 카드: time.sleep()

`time.sleep(초)`는 그 시간만큼 프로그램을 잠깐 멈춰요. 두근두근 연출에 써요. 소수(0.5초)도 돼요.

```python
import time
print("문을 여는 중...")
time.sleep(2)
print("철컥! 문이 열렸어요.")
```

✋ **직접 해 보기:** 3, 2, 1을 1초 간격으로 세고 "시작!"을 출력해 보세요. (`while` + `time.sleep(1)`)

⚠️ 너무 길게 기다리면 지루해요. 한 번에 0.5~2초가 적당해요.

## 💡 주제별 힌트

<details>
<summary>힌트 1 (방향)</summary>

- 방탈출: "방 반복" 안에 "문제 반복"이 들어 있는 **이중 반복**이에요. 바깥은 방 번호, 안쪽은 맞힐 때까지.
- 펫: 한 턴 = 반복 한 번. 행동에 따라 수치를 바꾸고, 마지막에 행복도를 계산해요.
- 창업: 하루 = 반복 한 번. 상품 고르기 → 가격 → 손님 수(무작위) → 사건 → 매출 순서.

</details>

<details>
<summary>힌트 2 (사용할 함수)</summary>

- 방탈출: `while room <= 3 and lives > 0:` 안에 `while lives > 0:`. 맞히면 `keys.append(...)` + `break`, 틀리면 `lives = lives - 1`.
- 펫: `if action == "2":` 안에서 `mood = mood + 3`. 수치 범위는 `if mood > 10: mood = 10`.
- 창업: `if item not in products: continue`, 사건은 `event = random.randint(1, 5)` + `if/elif`.

</details>

<details>
