<summary>[방탈출] 방 반복이 거의 다 됐는데 안 될 때 ●●●</summary>

시작 파일의 `print("\n=== 1번 방…")`부터 끝까지를 아래로 바꿔 써요. 방마다 다른 문제는 `if room == 2:`로 나누고, 맨 아래에서 `if "3번 열쇠" in keys:`로 탈출을 판정해요.

```python
room = 1
while room <= 3 and lives > 0:
    print(f"=== {room}번 방 ===")
    while lives > 0:
        a = random.randint(1, 20)
        b = random.randint(1, 20)
        reply = int(input(f"{a} + {b} = "))
        if reply == a + b:
            keys.append(f"{room}번 열쇠")
            print("철컥! 열쇠를 얻었어요.")
            break
        lives = lives - 1
        print(f"땡! 남은 목숨: {lives}")
    room = room + 1
```

</details>
