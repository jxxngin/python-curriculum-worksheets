# 파이썬 1년 커리큘럼 워크시트

초등 고학년~중고등 소그룹 파이썬 수업용 주차별 워크시트.

- 커리큘럼 원본: [curriculum/curriculum.md](curriculum/curriculum.md)
- 진행 상황: [PROGRESS.md](PROGRESS.md)
- 워크시트: [worksheets/semester1](worksheets/semester1)
- 작성 규칙: [CLAUDE.md](CLAUDE.md)

주차마다 프린트용 A4 워크시트(`worksheet.html`, 브라우저에서 열고 A4로 인쇄)와 화면용 활동 안내(`README.md`), 실습용 파이썬 파일, 교사용 정답지(`answer_key.md`)와 교사 가이드가 있다.

워크시트는 Claude Code 클라우드 예약 루틴이 자동으로 만들어 커밋한다. 한 번에 남은 주차를 모두 만들고, 사용량이 떨어져 끊기면 다음 예약 실행(4시간마다)이 이어서 만든다.
