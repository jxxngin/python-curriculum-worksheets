# 01. 교안 형식 (웹 우선, 인쇄 가능)

교안은 **화면에서 위에서 아래로 읽는 한 장의 웹 페이지**다. 같은 파일을 인쇄하면 활동마다 새 쪽에서 시작하는 학습지가 된다. 파일은 주차마다 `lesson.html` 하나다.

저장소 주인 피드백(2026-11-04)
- 레이아웃이 더 심플했으면 좋겠다.
- 컬러로 바꿔 달라(눈에 잘 안 들어온다).
- A4에 꽉꽉 채우는 학습지보다, 나중에 웹에서 교안으로 쓸 수 있는 형태까지 고려한다.
- (앞선 피드백) 할 일이 먼저 보여야 하고, 한 번에 많은 정보를 담지 않으며, 일렬로 쭉, 쓰는 칸은 크게, 흐름이 매주 같아야 한다.

> 1학기에 이미 만든 `worksheet.html`(A4 고정 쪽 형식)은 예전 형식이다. 틀은 [templates/legacy/a4-worksheet-template.html](templates/legacy/a4-worksheet-template.html)에 보관했다. 새로 만들거나 고칠 때는 이 문서의 교안 형식을 쓴다.

## 원칙

1. **심플하게.** 활동 하나 = 흰 카드(블록) 하나. 굵은 테두리와 겹친 상자를 쓰지 않고, 여백과 색 막대로 구분한다.
2. **컬러로, 그러나 화려하지 않게.** 색은 준비·만들기·더 하기 3가지만 쓰고, 색만으로 구분하지 않는다. 같은 활동에는 늘 같은 색과 이모지를 붙인다(색을 못 보는 아이, 흑백 인쇄 대비).
3. **할 일이 먼저.** 모든 블록은 제목 바로 아래 "📋 할 일"(번호 붙은 행동 1~3개)로 시작한다.
4. **한 블록에 한 활동, 위에서 아래로 한 줄.** 좌우로 나란히 놓지 않는다. 화면 폭이 넓어도 본문 폭은 820px로 둔다. 휴대폰에서도 그대로 읽힌다.
5. **매주 같은 흐름.** 블록 순서, 블록 안 순서, 색과 이름표가 매주 같다.
6. **쓰는 칸은 크게.** 인쇄해서 손으로 쓸 수 있는 크기로 둔다(아래 "칸 크기").

## 틀

- [templates/lesson-template.html](templates/lesson-template.html)을 복사해서 시작한다.
- `<style>`의 공통 스타일은 그대로 둔다. 꼭 필요한 것만 "주차별 추가" 표시 아래에 덧붙인다. 검사 도구가 공통 스타일이 템플릿과 같은지 확인한다.
- 외부 리소스는 Google Fonts만 쓴다. 그림 파일과 스크립트는 쓰지 않는다(웹 기능은 [decisions.md](decisions.md) P12).

## 활동 블록과 색 (고정 흐름)

색은 수업 흐름 3묶음으로 3가지만 쓴다(저장소 주인 선택, P13): **준비 파랑 · 만들기 초록 · 더 하기 주황**

| 순서 | 블록 (`section.block.○○`) | 색 묶음 | 이름표 |
| --- | --- | --- | --- |
| 1 | `mission` 오늘의 미션: 이야기, 완성하면 이렇게 돼요, 오늘 할 일 | 준비(파랑) | 🎯 |
| 2 | `warmup` 워밍업: 고장 난 코드 고치기 | 준비(파랑) | 🔧 |
| 3~ | `step` 단계 1, 2, 3 … (기능 하나 = 단계 하나 = 블록 하나) | 만들기(초록) | 🪜 |
| 다음 | `change` 내 것으로 바꾸기 (오늘의 완성 기준) + 친구에게 보여 주기 | 만들기(초록) | ⭐ |
| 다음 | `new` 새로 만들기(선택) + 오늘의 마무리 | 만들기(초록) | 💡 ✅ |
| 다음 | `challenge` 도전 프로젝트 (일찍 끝낸 사람) | 더 하기(주황) | 🚀 |
| 마지막 | `hints` 힌트 카드 | 더 하기(주황) | 🃏 |

- 블록 안의 도구 카드는 회색 바탕(🧰)이다. 새 색을 더하지 않는다.
- 검사 도구가 블록 순서와, 블록마다 할 일 상자가 있는지 확인한다.

### 단계 블록 안의 고정 순서

1. 제목: `단계 N` 이름표 + 만들 기능 (예: "제목 보여 주기")
2. 📋 할 일
3. 🧰 도구 카드: 그 단계에 처음 나오는 개념만. 없으면 생략
4. ⌨️ 따라 쓸 코드: 이 단계에서 **새로 쓰는 줄만**. 2단계부터는 첫 줄에 회색 주석으로 "# … 단계 N 코드 아래에 이어서 써요"
5. ▶️ 실행하고 확인: 큰 쓰는 칸 + 성공 체크("□ 화면에 ○○가 나왔어요")

## 머리

- 주차 칩: `N학기 · N주차 · 부제`
  - 부제: 개념 주차는 그 주 개념을 "~하기"로(예: 묻고 답하기, 갈림길 만들기), 프로젝트 주차는 주차 성격(중간 프로젝트, 설계와 보충, 기말 프로젝트)
- 제목: 미니 프로젝트 이름
- 이름, 날짜 쓰는 줄

## 프로젝트 주차

| 주차 | 블록 |
| --- | --- |
| 중간 (5주) | mission / warmup / 주제별 퀘스트(step 자리) / 기획서 / 발표와 평가 / hints |
| 설계와 보충 (9주) | mission / warmup / 설계도 ①② / 보충 문제 / hints |
| 기말 (10~11주) | mission / warmup / 명령 카드 + 최소 완성 기준 / 일정표·친구 테스트 / 설계 / 발표·돌아보기 / hints |

프로젝트 주차에 필요한 블록 종류와 색은 처음 만들 때 정해서 템플릿과 이 표에 더한다.

## 칸 크기

| 칸 | 클래스 | 최소 크기 |
| --- | --- | --- |
| 실행 결과·서술 쓰는 칸 | `.write` | 높이 160px(인쇄 약 42mm), 줄 간격 40px |
| 작은 쓰는 칸 | `.write.small` | 높이 90px |
| 표의 쓰는 칸 | `table.fill td.w` | 높이 56px |
| 그리기 칸 | `.draw` | 높이 260px |
| 코드 빈칸 | `.blank` | 너비 90px |

## 부품

| 부품 | 클래스 | 쓰는 곳 |
| --- | --- | --- |
| 활동 블록 | `section.block.mission` 등 | 활동 하나 |
| 할 일 | `.todo` > `h3` + `ol` | 모든 블록 맨 위 |
| 도구 카드 | `.tool` > `.th` | 단계 안에서 새 개념 소개 |
| 코드 | `pre.code` > `span.l` (줄 번호), `pre.code.nonum` | 워밍업, 따라 쓸 코드, 도구 카드 예시 |
| 줄 번호 맞추기 | `style="counter-reset: ln N"` | N+1번 줄부터 보여 줄 때 |
| 코드 빈칸 | `span.blank[data-n]` | 바꾸기·힌트에서만 |
| 실행 화면 | `.screen` > `.bar` + `.body` | 완성하면 이렇게 돼요 |
| 쓰는 칸 | `.write`, `.write.small` | 실행하고 확인, 서술 |
| 표 | `table.fill` | 워밍업 표, 설계 표, 따라가기 |
| 체크리스트 | `ul.check` | 성공 체크, 완성 기준, 마무리 |
| 그리기 칸 | `.draw` | 화면 디자인, 순서도 |
| 힌트 카드 | `.hints-grid` > `.hint` | 힌트 블록 |
| 이름표 | `.label` | "⌨️ 따라 쓸 코드" 같은 작은 제목 |

## 화면과 인쇄

- **화면:** 본문 폭 820px, 글자 17px, 휴대폰(560px 이하)에서는 여백과 글자를 줄인다. 긴 코드 줄은 가로로 스크롤된다.
- **인쇄:** `@page { size: A4; margin: 12mm; }`
  - 미션을 뺀 활동 블록은 새 쪽에서 시작한다.
  - 할 일, 도구 카드, 코드, 쓰는 칸, 표, 힌트 카드는 쪽 사이에서 끊기지 않는다.
  - 긴 코드 줄은 줄바꿈된다.
  - 인쇄 설정: Ctrl+P → A4, "배경 그래픽" 켜기, 머리글·바닥글 끄기
- 점검 방법은 [04-review-checklist.md](04-review-checklist.md)에 있다.
- 이름표(`.label`)와 바로 다음 부품(코드, 쓰는 칸, 표)은 `.keep`으로 묶어 같은 쪽에 둔다. 이름표만 쪽 끝에 홀로 남지 않게 한다(생성 도구가 자동으로 묶는다) (2차 피드백)
- 인쇄 분량: 블록마다 새 쪽 구성은 그대로 둔다. 종이를 줄이려면 **양면 인쇄**를 쓴다(교사 가이드에 안내) (2차 피드백)
