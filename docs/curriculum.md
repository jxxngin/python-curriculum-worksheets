# 파이썬 1년 커리큘럼 (초등 고학년\~중고등)

Sep 28, 2026 · @Someone

블록 코딩 경험이 있는 초등 고학년부터 중고등학생까지, 6명 미만 소그룹을 위한 4학기(학기당 11주, 주 1회 110분) 파이썬 과정이다. 1학기는 글자, 2학기는 그림(터틀), 3학기는 데이터, 4학기는 게임(pygame)을 다루며, 매주 새 개념을 미니 프로젝트로 익히고 학기마다 중간·기말 프로젝트로 키운다. 잘하는 학생이나 중고등학생은 같은 개념을 확장 프로젝트로 더 깊게 활용한다.

## 운영 방식

학생마다 진도가 달라도 스스로 따라갈 수 있도록, 매주 개념 하나를 미니 프로젝트로 익히고 학기 중간과 끝에 그것을 키우는 구조로 운영한다.

| 구분 | 방식 |
| --- | --- |
| 학기 구성 | 1\~4주와 6\~8주는 새 개념과 미니 프로젝트, 5주는 중간 프로젝트, 9주는 설계와 보충, 10\~11주는 기말 프로젝트 |
| 주차별 미니 프로젝트 | 따라 하기(빈칸 3\~5개 채우기, 모두) → 바꾸기(내 것으로 바꾸고 기능 추가, 그날의 완성 기준) → 새로 만들기(새 기능 스스로 설계, 선택) |
| 주차별 확장 프로젝트 | 미니 프로젝트와 같은 개념을 중고등학생이 흥미로워할 주제로 더 깊게 활용. 빈칸 템플릿 없이 바꾸기부터 시작. 중고등은 미니 프로젝트를 따라 하기까지 하고 확장 프로젝트가 그날의 완성 기준, 초등은 미니 프로젝트를 마친 뒤 선택 |
| 중간 프로젝트 | 교과 연계 프로젝트. 미니는 제시된 주제를 고르거나 1\~4주 미니 프로젝트를 교과 주제로 바꿔 키우고, 확장은 1\~4주 개념을 모두 섞어 쓰는 새 교과 주제로 만든다 |
| 기말 프로젝트 | 1\~9주에 배운 개념을 모두 쓰는 교과 연계 프로젝트. 제시된 주제 중 하나를 고르거나 1\~9주 미니·확장 프로젝트를 교과 주제로 바꿔 키우기 |
| 진도 차이 대응 | 퀘스트 카드와 3단계 힌트로 각자 진행, 5주와 9주가 완충 주간, 발표일은 공통으로 고정 |
| 매주 워밍업 | 오류 메시지 읽고 고치기, 코드를 한 줄씩 따라가며 변수 값 확인하기 (2026-11-04 수정: 원래 "Thonny 디버거로 한 줄씩 실행해 보기". Thonny를 쓰지 않기로 해서 편집기와 상관없는 방식으로 바꿈. docs/decisions.md 참고) |

### 주차별 보완 메모

- 1학기 7주 확장 숫자 야구: 서로 다른 세 자리 숫자를 뽑는 부분은 따라 하기 코드로 제공
- 1학기 4주 확장 피자 가성비 계산기: 새로 만들기에 오늘의 할인 쿠폰(random)과 두 피자의 가격 차이(abs()) 추가
- 2학기 4주 미니 세계의 산 높이 정렬: 바꾸기에서 산 하나를 빼고(remove()) 다시 정렬, 새로 만들기에서 \[높이, 이름\]을 함께 정렬하는 기본 코드 제공
- 2학기 7주 확장 투석기 게임: 포물선 계산에 필요한 삼각함수(math.sin·cos)는 따라 하기 코드에 공식으로 제공
- 3학기 8주 미니 마음 읽는 숫자 AI: 새로 만들기에서 차례로 찾기와 반씩 좁히기의 횟수·시간을 time.time()으로 비교
- 3학기 7주 미니 10초 맞히기: 친구별 최고 기록판을 딕셔너리({이름: 남은 차이})로 만들고, 새 기록이 10초에 더 가까우면 갱신해 순위 출력(완성 조건). 기록판은 6주 파일로 저장해 다음 시간에 이어 쓰고, 처음 실행해 파일이 없을 때는 try/except(FileNotFoundError)로 처리

### 3학기 기말 프로젝트 후보 (미정)

## 4학기: 움직이는 게임 (pygame)

1\~3학기 기초를 게임으로 모아 쓰며 실시간 움직임과 클래스를 새로 배운다. 학생은 난이도별 게임(하·중) 중 하나를 골라 11주 동안 한 게임을 키운다. 두 게임은 같은 주차에 비슷한 개념을 다루지만 게임마다 필요한 개념이 달라 표를 나눈다. 상 난이도(몬스터 수집 RPG)는 미정이며 추후 도입 예정이다. 초등은 창·게임 루프 기본 틀을 받아 시작하고, 기말은 1년 최종 결산 게임이다.

## 참고

- 교과 연계는 2022 개정 교육과정 기준이다. 5\~6학년 수학·과학은 검정 교과서라 학기와 단원 순서가 출판사마다 다르므로, 적용할 때 학교 교과서 목차와 맞춰본다.
- 파이썬 round()는 끝자리가 5일 때 짝수 쪽으로 맞춰서 round(2.5)가 2가 된다. 학교에서 배우는 반올림과 다르다는 점을 미리 알려주거나 탐구 거리로 쓴다.
- 개념 범위 기준: 중학교 정보 성취기준에 있고 프로젝트에 쓰이는 개념은 필수, 고등학교 정보나 PCEP(파이썬 입문 자격)에만 있는 개념은 확장, 이미 배운 문법으로 대신할 수 있는 줄임 문법과 추상적인 개념은 제외한다. 확장(확장 프로젝트나 명령 카드로 선택): 문자열·리스트 슬라이싱, 2차원 리스트, 기본값 매개변수, join(), isdigit(), 재귀. 제외(다음 과정에서): 클래스(4학기 pygame), 리스트 컴프리헨션, lambda, set, match, 제너레이터, 비트 연산, json, datetime.
- 중·고등 정보 교과와 연계되는 부분(리스트, 중첩 제어 구조, 함수와 디버거, 인공지능과 데이터, 암호화, 정렬·탐색 비교)은 맛보기 수준으로 경험한다. 확장 프로젝트의 교과 연계는 중학교 과정 기준이며, 학년과 단원은 학교 교과서 목차와 맞춰본다.

학기·주차별 교과 연계 정보는 교과 연계 탭에 따로 정리했다.
