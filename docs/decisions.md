- 선택지
  - A (추천): 체크리스트에 필수(★) 최대 3개 + 나머지는 "도전"으로 표시한다. 완성 기준은 필수만이다.
  - B: 체크리스트를 3개로 줄이고 나머지는 3단계 새로 만들기로 옮긴다.
  - C: 지금대로 둔다.

### P4. 섹션별 시간 기본값

### P6. 따라가기 미션 확인 도구

## 결정 이력

### 2026-11-04 (편집기)

- **Thonny를 쓰지 않는다.** 커리큘럼 운영 방식에 "Thonny 디버거로 한 줄씩 실행해 보기"가 명시되어 있었지만 쓰지 않기로 했다. `docs/curriculum.md`의 해당 줄도 수정했다(원문은 괄호 안에 남김).
- **편집기 중립:** 워크시트·README·교사 가이드·정답지·파이썬 주석에서 특정 편집기 이름, 단축키, 디버거·변수 창 같은 기능을 쓰지 않는다.
- **디버거 미션 → 따라가기 미션:** 종이 위에서 코드를 한 줄씩 따라가며 표를 채우고, 실행 결과나 `print()`로 확인한다. 기존 표 활동은 그대로 살렸다. (대안과 추천은 결정 대기 P6)

### 2026-11-02

- **형식:** 처음에는 MD 문서 + 파이썬 파일로 만들었다. 이후 "선생님 예시처럼 프린트해서 아이들이 직접 쓰는 A4 학습지"로 바꿨다. 이 출력물의 이름은 **워크시트**(`worksheet.html`)다. README.md는 화면용 활동 안내로 남겼다.
- **커리큘럼에 형식 지시가 없음:** 커리큘럼에는 A4·출력 형식 지시가 없다. 퀘스트 카드, 3단계 힌트, 명령 카드, 설계도, 빈칸 채우기만 정해져 있다. 형식은 이 기준 문서가 정한다.
- **제작 방식:** Claude Code 클라우드 예약 루틴(Opus)으로 컴퓨터를 켜 두지 않고 만든다. 한 번에 남은 주차를 모두 만들고, 사용량이 떨어지면 다음 실행이 이어서 만든다. 다 만들면 자동으로 멈춘다.
- **저장소:** 공개(public)로 둔다.
- **1주차 워크시트 승인:** "일단 괜찮은 거 같아." 이후 1학기 전체를 같은 형식으로 만들었다.

### 2026-11-04 (1학기 점검 피드백)

- **정답지:** 주차마다 `answer_key.md`를 만든다.
- **시간 근거:** "바꾸기 30분"은 커리큘럼 근거가 없는 추정이었다. 커리큘럼은 110분만 정한다(P4로 이어짐).
- **스스로 평가 별:** 별에 기준을 다는 것은 필요 없다. 지금대로 둔다.
- **예상 표 조건:** 7주 독감 표는 A안(시작 조건 명시, 시작 코드와 같은 규칙)으로 정했다. 일반 규칙: 예상 표에는 시작 조건과 계산 규칙을 모두 적는다.
- **코드 조각:** 빈칸 코드는 앞뒤 2~3줄을 같이 보여 준다(5주).
- **디버거 안내:** 오류를 고치기 전 값을 물을 때는 어떤 오류를 먼저 고쳐야 하는지 명시한다(3주).
- **배지 부제:** 일관되게 통일한다. 개념 주차는 "~하기", 프로젝트 주차는 주차 성격.
- **힌트:** 소문자 처리는 조건을 늘리지 않고 입력을 받자마자 대문자로 바꾸는 방식으로 한다(2주).
- **오류 수정:** 힌트 줄 나눔(괄호 밖), 힌트 2칸 들여쓰기, 디버거 표 오타, Thonny 단축키(주석은 Ctrl+3), 평가표 기준을 고쳤다. 일반 규칙: 들여쓰기 4칸, 따라 쳐도 실행되는 코드
- **코드와 워크시트 일치:** 워크시트 코드는 파이썬 파일과 글자 하나까지 같아야 한다. 힌트 변수 이름은 starter와 같아야 한다.
- **인쇄:** 프린트할 때 잘리는 곳이 없어야 한다. 카드가 줄어드는 문제를 막는 CSS와 잘림 검사를 추가했다.
- **기준 문서화:** 워크시트의 틀을 먼저 잡는다. 피드백을 반영한 기준을 `docs/`에 만들고(커리큘럼도 이동), 기준이 확정된 뒤에 제작을 시작한다. 더 나은 대안이 있으면 선택지로 제시한다.
- **템플릿:** 기준 예시를 1주차 워크시트 대신 `docs/templates/worksheet-template.html`로 바꿨다. 주차마다 따로 덧붙인 스타일(nonum, tight, flow, cols2)을 공통 스타일로 합쳤다.
