## 결정 대기 (모두 Claude 제안, 미정)

저장소 주인이 정하기 전까지는 기준 문서에 규칙으로 쓰지 않는다. 지금 워크시트는 각 항목의 "현재 상태"대로 되어 있다.

### P1. 2단계 바꾸기 분량 [제안·대기]

- 현재 상태: 체크리스트 4~5개가 모두 "오늘의 완성 기준"이다. 7주는 수량, continue, 할인, 거스름돈까지 들어 있어 5~6학년에게 무겁다.
- 선택지
  - A (추천): 필수(★) 최대 3개 + 나머지는 "더 해 보기"로 표시한다. 완성 기준은 필수만이다.
  - B: 체크리스트를 3개로 줄이고 나머지는 3단계 새로 만들기로 옮긴다.
  - C: 지금대로 둔다.

### P2. 학기 제작 순서 [제안·대기]

- 현재 상태: 정해진 순서가 없다. 1학기는 한 번에 전체를 만들었다.
- 선택지
  - A (추천): 1주차 샘플을 만들어 승인받은 뒤 나머지 주차를 만든다. 다 만든 뒤 형식을 바꾸는 일을 막는다.
  - B: 기준 확정 후 학기 전체를 한 번에 만든다.

### P3. 정답지 형식 [제안·대기]

- 현재 상태: `answer_key.md`
- 선택지
  - A (추천): `answer_key.md` 유지
  - B: 인쇄용 `answer_key.html`(A4)을 추가한다.

### P4. 섹션별 시간 [제안·대기]

- 현재 상태: 커리큘럼에는 110분만 있다. 워크시트의 섹션 시간은 주차마다 제작 에이전트가 정한 값이다.
- 선택지
  - A (추천): 기본값을 정하고 주차마다 ±5분만 조정한다. 예: 미션·워밍업 15 / 따라 만들기 40 / 바꾸기·새로 만들기 35 / 도전·마무리 20
  - B: 시간은 교사 가이드에만 적고 워크시트에서는 뺀다.

### P5. 1학기 정비 범위 [제안·대기]

- 저장소 주인이 "정리가 끝나면 1학기 전체 파일을 수정한다"고 했다(2026-11-04). 그때 P1·P4 결과도 함께 반영할지 정한다.

### P6. 따라가기 확인 도구 [제안·대기]

- 현재 상태: 도구 없이 손으로 따라가기 + 실행 결과·`print()`로 확인한다.
- 선택지
  - A (추천): 지금대로 둔다. 어떤 편집기에서도 되고 설치가 필요 없다.
  - B: Python Tutor(pythontutor.com)를 확인 도구로 안내한다. 변수 상자가 그림으로 보인다. 인터넷이 필요하고 input() 코드는 불편하다.
  - C: 실제로 쓸 편집기를 정해 그 편집기에 맞춘 안내를 넣는다.

### P8. 단계별 코드 쓰기 방식 [제안·적용, 확인 필요]

- 배경: 저장소 주인 피드백 "전체 코드를 보여 주고 진행하기보다 기능별로 쪼개서 스텝 바이 스텝으로 작성하도록 유도"
- 지금 적용한 것(A): `mini_starter.py`는 단계 표시 주석만 있는 거의 빈 파일이다. 아이가 단계마다 새 줄 3~6줄을 이어 쓴다. `mini_solution.py` 하나에 `# 단계 N` 주석으로 단계를 나눈다. 빈칸 채우기는 바꾸기·힌트 같은 곳에만 쓴다.
- 선택지
  - A (적용 중, 추천): 위와 같다. 파일이 적고, 아이가 자기 파일 하나를 키워 가는 느낌이 난다.
  - B: 단계마다 확인 파일(`mini_step1.py`, `mini_step2.py` …)을 따로 둔다. 막힌 아이가 그 단계부터 다시 시작하기 쉽다. 대신 파일이 늘어난다.
  - C: 단계마다 짧은 코드에 빈칸 1~2개를 남겨 둔다. 타자 부담이 줄지만 "직접 작성" 느낌이 약해진다.

### P9. 쪽 수 [제안·적용, 확인 필요]

- 배경: "한 쪽 한 활동"과 "단계 하나 = 한 쪽"을 지키면 개념 주차가 8~9쪽이 된다. 쪽 수 상한을 8쪽에서 10쪽으로 늘렸다.
- 선택지
  - A (적용 중): 10쪽까지 허용한다. 종이는 늘지만 한 쪽이 단순해진다.
  - B: 짧은 단계는 두 단계를 한 쪽에 위아래로 두어 6~7쪽 안에 맞춘다.
  - C: 도전 프로젝트와 힌트 카드는 따로 인쇄하는 별지로 뺀다(본 워크시트 6~7쪽).

### P7. 확장 프로젝트의 자리 [제안·적용, 확인 필요]

- 배경: 커리큘럼의 확장 프로젝트는 "잘하는 학생이나 중고등학생"용이다. 대상이 5~6학년으로 정해졌다.
- 지금 적용한 것: 확장 프로젝트를 **도전 프로젝트**(미니 프로젝트를 일찍 끝낸 학생이 고르는 선택 활동)로 바꿔 부른다. 파일 이름(`extension_*`)은 그대로 둔다.
- 선택지
  - A (적용 중): 도전 프로젝트로 남긴다.
  - B: 워크시트에서 빼고 교사용 추가 자료로만 둔다.
