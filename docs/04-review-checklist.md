# 04. 점검 체크리스트

한 주차를 다 만들면 아래를 모두 통과해야 커밋한다.

## 1. 자동 검사

```bash
python tools/check_worksheet.py worksheets/semesterN/weekNN/lesson.html
```

이 도구가 확인하는 것:
- 교안: 활동 블록 순서, 블록마다 할 일 상자, 이름/날짜 칸, 외부 리소스는 Google Fonts만
- (예전 A4 형식이면 쪽 수, `.foot`, A4 안에서 넘침·잘림을 대신 본다)
- 공통 스타일이 템플릿과 같은지
- 특정 편집기 표현(Thonny, 단축키, 디버거, 변수 창)이 없는지
- (playwright가 있으면) 휴대폰(375px)·노트북(1024px)에서 가로로 넘치지 않는지, 인쇄할 때 끊기면 안 되는 칸이 한 쪽보다 크지 않은지, 인쇄 쪽 수(16쪽 이하)
- playwright 설치: `pip install playwright && python -m playwright install chromium`. 설치가 안 되면 구조 검사만 하고 그 사실을 보고한다.

파이썬 파일:
- 모든 `.py`가 `python -m py_compile`을 통과한다. 단, `warmup.py`와 빈칸이 있는 starter는 일부러 실행되지 않는다.
- solution과 확장 starter에 입력을 파이프로 넣어 끝까지 실행한다. random이 있으면 여러 번 실행한다.

## 2. 코드와 워크시트 대조

- [ ] 워밍업 코드가 `warmup.py`와 줄 번호까지 같다.
- [ ] 단계 쪽의 따라 쓸 코드가 `mini_solution.py`의 해당 단계 줄과 같다(질문 문구 포함). 빈칸을 쓴 곳은 번호가 파일 주석과 같다.
- [ ] `mini_solution.py`를 단계 N까지만 남겨도 실행된다.
- [ ] 워크시트의 "N번 줄" 안내가 실제 줄을 가리킨다.
- [ ] 힌트 코드의 변수 이름이 starter 파일에 있다. 새 변수는 힌트 1·2에서 소개했다.
- [ ] 시작 파일에 대한 설명(예: "8강까지만 해요")이 실제 코드와 맞다.
- [ ] 예상 표의 조건으로 시작 파일을 실행하면 정답지와 같은 답이 나온다.

## 3. 인쇄

- [ ] 실제 PDF로 출력해서 블록이 새 쪽에서 시작하고, 쓰는 칸이 쪽 사이에서 끊기지 않는다.
  - 검사할 때 인쇄 모드 흉내(emulate_media)를 켰다 끈 페이지로 PDF를 만들면 빈 쪽이 하나 더 생긴다. 새로 연 페이지로 출력한다.
- [ ] 화면(노트북·휴대폰)과 인쇄 모습을 눈으로 확인했다.

## 4. 사람 검토 (내용)

- [ ] 첫 블록(미션)에서 오늘 만들 것과 완성 모습이 먼저 보인다.
- [ ] 모든 활동 맨 위에 할 일 상자가 있고, 번호 붙은 행동이 1~3개다.
- [ ] 한 블록에 한 가지 활동만 있다. 위에서 아래로 한 줄로 이어진다(좌우 나란히 배치 없음).
- [ ] 단계 블록이 모두 같은 순서다: 단계 머리 → 할 일 → 도구 카드 → 따라 쓸 코드 → 실행하고 확인.
- [ ] 쓰는 칸이 칸 크기 기준([01-worksheet-format.md](01-worksheet-format.md)) 이상이다.
- [ ] 활동 색과 이모지가 고정 흐름 표와 같다.
- [ ] 단계마다 새로 쓰는 코드가 3~6줄이고, 앞 단계 코드를 다시 보여 주지 않는다.
- [ ] 개념만 모아 둔 블록이 없다. 개념은 따라 만들기 단계 안에서 필요할 때 도구 카드로 나온다.
- [ ] 단계마다 실행해서 눈에 보이는 결과가 나오고, 성공 체크가 있다.
- [ ] 5~6학년 눈높이: 문장이 짧다.
- [ ] 그 주차까지 배운 개념만 썼다. 커리큘럼 보완 메모를 반영했다.
- [ ] 블록마다 아이가 직접 쓰거나 그리거나 체크하는 칸이 있다.
- [ ] 입력값·조건이 정해져 있어서 예상 칸의 답이 하나로 정해진다.
- [ ] 바꾸기 체크리스트의 필수(★)가 3개 이하이고, 나머지는 "더 해 보기"로 나뉘어 있다.
- [ ] 교과 연계 사실이 정확하다.
- [ ] 말투와 표기 규칙을 지켰다(학생용 ~해요, 변수는 영어).
- [ ] README·교사 가이드·정답지·파이썬 주석에도 특정 편집기 표현이 없다.
- [ ] `answer_key.md`가 워크시트의 모든 정답 칸을 다룬다.
